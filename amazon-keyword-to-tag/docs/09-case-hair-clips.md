## 规则说明（样例 Sheet 原文要点）

- **0-1-3**：0=原始 ABA 搜索词；1=原子标签；3=组合标签+广告/Listing/视觉/选品动作  
- **机会等级**：S/A/B/C/D；品牌/IP/低相关单独处理  
- **优先级分**：ABA 排名基础分 + 商机/发质/形态/功能/趋势；品牌 IP 降权  
- **广告**：S/A 优先 Exact/Phrase；风格词 Broad/Phrase；发质需求单独 campaign；品牌词低预算独立  
- **Listing**：核心词进标题/五点；发质/功能进卖点图；风格进主图/A+；竞品/IP 不写 Listing  

此文件即 **ABA 通用版①交付形态** 的真实验证。
