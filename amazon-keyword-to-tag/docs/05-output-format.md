## 八、标签迁移重组机制

标签不只停在关键词层，必须迁移到运营动作（标签/元素迁移重组）。

| 标签类型 | 可迁移到哪里 |
|----------|--------------|
| 材质标签 | 标题、五点、后台属性、图片参数图 |
| 外观标签 | 主图、A+、视频、品牌风格 |
| 功能标签 | 标题、五点、广告关键词 |
| 痛点标签 | 五点、FAQ、评论反击、产品改良 |
| 人群标签 | 广告分组、图片模特、A+场景 |
| 场景标签 | 主图场景、节日活动、站外内容 |
| 情感标签 | A+品牌故事、视频脚本、礼品包装 |
| 价值认同标签 | 品牌定位、溢价、视觉调性 |
| 价格/性价比标签 | Coupon、Deal、广告转化词 |
| 技术标签 | 参数图、对比图、专业背书 |

### 经典案例

> 评论里大量出现 `hard to clean`  
> 不是只打一个「难清洗」标签，而应迁移成：  
> **产品改良：可拆洗结构**  
> **Listing 卖点：easy to clean**  
> **图片表达：dishwasher safe 图标**  
> **广告词：easy clean lunch box**

## 九、机会指数模型

> **Opportunity Score = 需求强度 × 供给缺口 × 自身匹配度 × 趋势加权 × 利润可行性**

### 分项

#### 1. Demand Score 需求强度

来源：搜索量、广告曝光、点击率、转化率、评论提及频次、站外讨论热度、节日/季节需求。

#### 2. Supply Score 供给强度

来源：竞品数量、头部 Review 数、评分壁垒、广告竞争、价格内卷、卖点同质化、图片同质化。

#### 3. Gap Score 缺口分

- 高频痛点但低解决率
- 评论吐槽多但竞品没解决
- 搜索词有需求但 Listing 覆盖少
- 站外有趋势但站内供给弱
- 人群/场景词增长但产品表达不足

#### 4. Fit Score 自身匹配度

供应链、成本、材质/技术/外观优势、差异化包装、品牌定位、合规风险。

#### 5. Trend Score 趋势分

站外内容增长、社媒热词、节日周期、类目上新、宏观消费趋势。

### 第一版加权公式

```text
机会指数 =
需求分 × 0.35
+ 供给缺口分 × 0.25
+ 自身匹配度 × 0.20
+ 趋势分 × 0.10
+ 利润/进入难度分 × 0.10
```

或按信号来源：

```text
综合机会指数 =
站内信号 × 70%
+ 站外趋势 × 20%
+ 品牌/线下/长期趋势 × 10%
```

ABA 通用机会等级见 `03`。

## 十、广告、运营、视觉三端应用

Broad 更适合探索，Exact 更适合高意图精准转化；打标结果应直接支持广告结构。

### 广告端

| 标签组合 | 广告动作 |
|----------|----------|
| 核心产品词 + 高转化 | Exact Campaign |
| 场景词 + 人群词 | Phrase Campaign |
| 情绪/需求词 | Broad 探索 |
| 痛点词 | 对比广告/竞品广告 |
| 节日礼品词 | 季节广告组 |

### 运营端

| 标签 | Listing 动作 |
|------|--------------|
| 高频功能词 | 标题/五点前置 |
| 高频材质词 | 标题/后台属性 |
| 高频痛点词 | FAQ/五点解释 |
| 高频人群词 | 图片/A+人群场景 |
| 高频情绪词 | 品牌故事/A+ |

### 视觉端

| 标签类型 | 视觉表达 |
|----------|----------|
| 安全 | 认证、材质、儿童使用图 |
| 高级感 | 质感、暗色背景、礼盒 |
| 亲子陪伴 | 家庭互动图 |
| 老人关照 | 大字、易用、安心 |
| 学习专注 | 桌面、孩子、安静环境 |
| 礼品属性 | 包装、节日、开箱感 |

## 十二、最终 8 问 + 一句话总结

成熟打标系统最终要回答的不是「有哪些标签」，而是**决策**：

1. 这个关键词属于什么产品、属性、功能、人群、场景？
2. 它是流量词、转化词、痛点词、礼品词，还是品牌价值词？
3. 它对应用户的哪种心理需求？
4. 它在购买路径的哪个阶段？
5. 它适合放标题、五点、A+、图片，还是广告？
6. 它是现有竞品都在打的红海词，还是有缺口的机会词？
7. 它能不能迁移成产品创新、视觉卖点或广告抓手？
8. 它和你自己的供应链、品牌定位、价格带是否匹配？

> **原子标签解决「看懂关键词」，组合标签解决「看懂需求」，机会指数解决「该不该做」。**
