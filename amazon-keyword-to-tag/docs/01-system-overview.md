# 01 · 系统总框架：Amazon Keyword-to-Tag Intelligence

## 定位

你要做的不是简单的「关键词分类表」，而是：

> **Amazon Keyword-to-Tag Intelligence System（亚马逊关键词原子级打标系统）**

核心目标：

> 把关键词、竞品页面、后台属性、评论、广告搜索词、站外趋势等数据，拆成「原子标签」，再组合成「人群–场景–需求–情绪–卖点–广告–视觉–机会」的可执行决策。

系统同时服务：**SEO、广告、视觉、评论洞察、选品和机会判断**。

一句话信条：

> **原子标签解决「看懂关键词」，组合标签解决「看懂需求」，机会指数解决「该不该做」。**

---

## 五层架构（概念层）

建议把系统分成 5 层（与 ChatGPT 体系一致）：

1. **数据层** — 采集与权重
2. **标签本体层** — 12 维词典（见 `02`）
3. **打标流水线层** — 清洗 / 原子拆解 / 匹配 / 置信度（见 `04`）
4. **决策层** — 组合意图、迁移重组、机会指数（见 `05`）
5. **应用层** — 广告 / 运营 Listing / 视觉 / 选品（见 `05`、`07`）

SIF 升级后，决策层再叠一条「需求中心路径」：词库 → TF → 供给匹配 → 广告框架 → 集中度拆分 → 价值验证（见 `06`）。

---

## 数据层：7 类来源

| 数据层 | 数据来源 | 主要用途 |
|--------|----------|----------|
| 类目层 | 类目树、类目属性、后台属性字段 | 建立基础标签边界 |
| 竞品前台层 | 标题、五点、A+、图片文案、变体、价格、评分、Review 数 | 抽取卖点、属性、场景、人群 |
| 后台属性层 | 材质、尺寸、容量、颜色、兼容性、适用人群等 | 标准化产品属性标签 |
| 评论层 | 好评、差评、Q&A、痛点、吐槽、期待 | 抽取情绪、痛点、真实需求 |
| 广告层 | Search Term、点击、转化、ACOS、CPC、曝光 | 判断购买意图和关键词价值 |
| 站外层 | TikTok、Google Trends、Pinterest、Reddit、社媒评论 | 捕捉趋势、创新声音、情绪需求 |
| 品牌/线下层 | 品牌定位、线下反馈、展会趋势 | 判断长期价值认同 |

## 第一版权重

> **站内 70% + 站外 20% + 品牌/线下/趋势 10%**

站内 70% 再细分：

| 站内子项 | 权重（占整体） |
|----------|----------------|
| 关键词 / 广告 | 30% |
| 竞品页面 | 20% |
| 评论 | 20% |

综合机会指数也可直接按信号来源：

```text
综合机会指数 =
站内信号 × 70%
+ 站外趋势 × 20%
+ 品牌/线下/长期趋势 × 10%
```

## 总路径图（对齐 Canvas）

```text
搭词库
→ TF 双词频（出现次数 + 搜索量加权）
→ 供给 0/1/3 反向匹配
→ 需求中心广告框架
→ 投放词与匹配模式
→ 搜索量集中度拆分
→ 价值验证三阶段
```

投放核心不是关键词，而是**消费者需求**（COSMO 洞察意图 + Rufus 对话匹配）。关键词只是需求的外显表达。

```text
词库 → 需求(TF+18类) → 供给匹配(0/1/3+Value) → 广告框架(需求→Campaign) → 验证决策(机会指数/动作)
```

## 双 Bot / 双 Skill 分工

| 版本 | 职责边界 | 主产出 |
|------|----------|--------|
| ① ABA通用 | 12 维、0-1-3、ABA 规则打标、机会 S/A/B/C/D、Excel | 打标结果 + 高机会清单 + 看板 + 词典 + 规则 |
| ② SIF价值升级 | 六步、TF、供给匹配、需求中心广告、集中度、价值验证 | 需求词频 + 匹配矩阵 + 广告结构 + Value Score |

上下游：

- → **AI选词bot**：已打标词库、组合意图、机会等级、推荐投放词
- → **AI广告托管bot**：需求→Campaign→AdGroup→词→匹配模式骨架
- → **广告健康**：价值验证指标口径与同价值点合并评估名单

## 需求端 vs 供给端

| 端 | 关注点 |
|----|--------|
| 需求端 | 搜索词、评论期待/痛点/满足、站外呼声、趋势、角色与待办 |
| 供给端 | 自家卖点、供应链、成本、差异化、品牌定位、合规 |

最终综合：进入难易程度、机会指数（竞争/需求供给）、市场趋势、自身匹配。
