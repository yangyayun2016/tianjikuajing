# 07 · 广告策略与推广计划公式（ChatGPT 轮次）

> 来源：ChatGPT share 中「亚马逊广告策略和推广计划制定」一轮。示例产品参数围绕空净/通用新品推演。

## 给定参数（样例）

| 参数 | 值 |
|------|-----|
| 售价 | $49.99 |
| CPC | $1.20 |
| CVR | 5% |
| 出单点击 | 20 个点击出 1 单（= 1/0.05） |
| CPA | CPC / CVR = 1.20 / 0.05 = **$24** |
| 预估 ACOS | CPA / 售价 = 24 / 49.99 ≈ **48.01%** |

说明：新品前期可用「全部毛利去做广告」——**ACOS 与毛利率持平**，即前期利润用来做广告。

---

## 核心公式

```text
CPC = ACOS × 售价 × CVR
CPA = CPC / CVR
ACOS = CPA / 售价
```

互相推导：

```text
ACOS = CPC / (售价 × CVR)
CVR = CPC / (ACOS × 售价)
日广告订单 = 日点击 × CVR
广告日订单 ≈ 广告日预算 / CPA
```

### 利润反推可承受 CPC（例）

> 产品利润只有 **$6**，转化率 **8%**，前期不考虑自然订单：  
> 需要 **1 / 0.08 = 12.5** 个点击出 1 单  
> 可承受 CPC = 利润 / 点击数 = 6 / 12.5 = **$0.48**（刚好把利润打完）

也可用：`CPC = ACOS × 售价 × CVR`，令 ACOS = 毛利率 = 6/49.99 ≈ 12%，CVR=8% → CPC ≈ 0.12 × 49.99 × 0.08 ≈ **$0.48**。

### CPC / CVR 预估方法

1. 市场调研得到同行平均 CPC，适当上调（多留 50–60% 空间）
2. 同品类历史 CPC 基础上适当上调
3. 新品期间波动大，采用**梯度预估**

梯度例：

- CPC=$2.5，CVR=5% 时，完成某日销目标对应广告费可能 **$105/天**
- CPC=$2.3，CVR=7% 时，对应广告费可能 **$69/天**

## 建议交付 Excel（ChatGPT 先例结构）

空净广告策略包曾含 6 个 Sheet：

1. **总览 Dashboard** — 12 周销量、广告费、ACOS、库存风险
2. **推广目标** — SKU/ASIN/竞品/目标排名/主推词分层
3. **推广计划** — 按周 Action、日销、Review、预算、库存
4. **广告计划** — 按周广告销量、费、点击、CPC、CVR、ACOS、预算分配
5. **关键词与广告结构** — 核心/长尾/竞品/自动/商品投放
6. **公式说明** — CPC/CPA/ACOS/CVR/利润反推

与打标系统衔接：主推词 / 核心 / 长尾 / 蓝海 / 品牌词应来自 ①② 打标结果的 S/A 级与需求 Campaign 骨架。
