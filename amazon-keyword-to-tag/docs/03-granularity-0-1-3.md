# 03 · 0-1-3 颗粒度法则与标签构成公式

## 0-1-3 定义

| 层级 | 含义 | 例子 |
|------|------|------|
| **0 raw** | 原始数据层，尚无可执行意义 | `leakproof kids water bottle for school` |
| **1 原子** | 单个可计算标签 | leakproof→功能；kids→人群；school→场景；water bottle→产品 |
| **3 组合** | ≥3 个原子 → 意图 + 运营动作 | 儿童+学校+防漏 → 开学季标题/主图/长尾 Exact |

系统**不应该只输出**「材质：硅胶 / 人群：儿童 / 场景：学校」，而应输出：

> **儿童学校场景下，家长对安全、防漏、易清洗的复合需求。**

这才有商业价值。

---

## 0 层：原始数据层

还没有可执行意义，只是原词、原句、原始评论。

例子：

> “leakproof kids water bottle for school”

这只是 raw keyword。

---

## 1 层：原子标签层

把关键词拆成单个可计算标签。

| 原词片段 | 原子标签 | 维度 |
|----------|----------|------|
| leakproof | 防漏 | 功能 |
| kids | 儿童 | 人群 |
| water bottle | 水杯 | 产品 |
| school | 学校 | 场景 |

发夹例：`claw clips for thick hair` → claw clips（产品）+ thick hair（发质/兼容）+（隐含）strong hold（功能需求）。

---

## 3 层：组合意图层

把 3 个以上原子标签组合成「可执行判断」，再转成运营动作：

| 组合标签 | 可执行方向 |
|----------|------------|
| 儿童 + 学校 + 防漏 | 标题关键词、主图场景、广告长尾词 |
| 妈妈 + 安全 + BPA free | 五点卖点、A+ 安全模块 |
| 老人 + 易用 + 大按键 | 产品设计、视觉放大参数 |
| 礼品 + 节日 + 高级感 | 礼盒包装、节日广告词 |
| 厚发 + 强抓力 + 大号抓夹 | Exact 独立预算、发质对比图、产品加固齿 |

---

## 标签构成公式

每个关键词按此公式拆：

> **产品对象 + 属性参数 + 功能特征 + 人群 + 场景 + 痛点/需求 + 情绪/价值 + 购买意图**

### 示例

原词：`premium stainless steel lunch box for kids school`

| 结构 | 内容 |
|------|------|
| 产品对象 | lunch box |
| 材质 | stainless steel |
| 价值感 | premium |
| 人群 | kids |
| 场景 | school |
| 潜在需求 | 安全、耐用、健康 |
| 购买意图 | 场景型 + 人群型 + 参数型 |

组合标签：

> 儿童学校餐盒 / 不锈钢健康材质 / 高端安全感 / 家长购买意图

---

## 置信度同样用 0/1/3

| 分数 | 含义 |
|------|------|
| 0 | 不命中或无证据 |
| 1 | 弱命中，只有单一来源证据 |
| 3 | 强命中，多来源重复出现 |

多来源示例：`leakproof` 同时出现在关键词 + 竞品标题 + 五点 + 评论好评 + 广告转化词 → 强标签，分数 3。

供给匹配分也用同一套 0/1/3（见 `06`）：0 无法满足 / 1 弱满足 / 3 强满足核心卖点。

---

## 与机会等级的衔接

| 机会等级 | 含义 | 典型动作 |
|----------|------|----------|
| S-核心必打 | 核心流量或强转化承接 | 标题 / Exact 优先 |
| A-高机会长尾 | 优先广告/Listing 测试 | Phrase / Exact 测试 |
| B-中机会测试 | 低预算测试或后台覆盖 | Broad / 后台 |
| C-低量补充 | 补充覆盖 | 低出价或否定观察 |
| D-观察/不主推 | 暂不主推 | 人工复核 |
| 品牌/IP/低相关 | 独立处理 | 品牌组或否定/授权确认 |

优先级分：基础分来自 ABA 搜索频率排名；叠加商机 KEYWORD、发质/功能、趋势风格；品牌/IP/低相关降权。
