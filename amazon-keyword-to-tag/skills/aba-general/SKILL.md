# 亚马逊关键词打标 · ABA关键词通用版本①

## When

用户上传 ABA / 关键词 Excel，要求「关键词打标」「原子标签」「机会等级」「标签词典」，且**尚未**要求完整 SIF 六步价值路径时，用本 skill。

需要需求词频、供给反向匹配、需求中心广告骨架、价值验证时，交接或并联读取：

→ `../sif-value-play/SKILL.md`（版本②）

学习库全文：`amazon-keyword-to-tag/docs/`（尤其 `01`–`05`、`09`）。

## 核心信条

> 原子标签解决「看懂关键词」，组合标签解决「看懂需求」，机会指数解决「该不该做」。

本版负责前半：看懂词、打标签、分级、Excel。后半价值路径归版本②。

## 12 维标签本体（必打）

1. 产品基础 — 类目/部件/配件/套装/包装/礼盒/替换兼容  
2. 物理属性 — 材质/颜色/外观/形状/尺寸/容量/重量/参数/工艺  
3. 功能 — 能解决什么功能问题  
4. 技术 — 靠什么技术实现  
5. 人群 — 谁买/谁用/谁送  
6. 场景 — 哪里用/什么时候用  
7. 需求 — 用户真正想解决什么  
8. 痛点 — 差评/Q&A/退货  
9. 情绪/情感 — 购买心理感受（马斯洛仅作上层映射）  
10. 价值认同 — 为什么愿意多付钱  
11. 购买意图 — 认知/比较/参数/场景/人群/礼品/交易  
12. 商业策略 — 流量抓手、Listing 优化点、机会指数等  

类目可扩展子标签（如发夹：产品形态、发质需求），但须映射回 12 维。

## 0-1-3 颗粒度

| 层 | 含义 |
|----|------|
| 0 | raw 原词/原句 |
| 1 | 原子标签（可计算） |
| 3 | ≥3 原子组合意图 + 可执行动作（广告/Listing/视觉/选品） |

置信度同用 0/1/3：无证据 / 单来源弱命中 / 多来源强命中。

标签公式：

> 产品对象 + 属性参数 + 功能特征 + 人群 + 场景 + 痛点/需求 + 情绪/价值 + 购买意图

## 流水线

1. 识别 sheet/列，**绝不编造搜索量**  
2. 清洗：小写、去重、单复数/同义词/单位归一、品牌与 IP 标记  
3. 建/更新类目 `tag_dictionary`（规则优先，情绪/价值用 LLM）  
4. 原子打标 → 组合标签 → 购买意图 → 机会等级  
5. 输出 Excel；不确定项标「待人工复核」

## 机会等级（ABA 通用口径）

| 等级 | 动作 |
|------|------|
| S-核心必打 | 标题/Exact 优先 |
| A-高机会长尾 | Phrase/Exact 测试 |
| B-中机会测试 | Broad/后台低预算 |
| C-低量补充 | 低出价或观察 |
| D-观察/不主推 | 人工复核 |
| 品牌/IP/低相关 | 独立组或否定；**Listing 不写竞品商标** |

权重参考：站内 70%（词广告30+竞品20+评论20）+ 站外 20% + 品牌/线下/趋势 10%。

## Excel 交付（必含）

1. 打标结果  
2. 高机会词清单  
3. 标签汇总_看板  
4. 标签词典  
5. 打标规则说明  
6. 原始ABA（保留）  

可选：商机 KEYWORD 打标、原始商机。

### 打标结果字段组

识别（排名/词/中文归类/相关性）· 原子维 · 组合/流量分层/意图 · 证据（Top3 点击转化份额）· 策略（广告/Listing/视觉/选品）· 决策（机会等级/优先级分）

## 迁移提示（交给运营，不代替②）

材质→标题/属性/参数图；痛点→五点/FAQ/改良；人群→广告组/模特图；场景→主图/节日；情绪→A+/礼盒；价值→定价/调性。

## 最终验收：能否回答 8 问

产品属性人群场景？流量/转化/痛点/礼品/品牌？心理需求？购买阶段？放标题五点A+图还是广告？红海还是缺口？能否迁移创新/视觉/广告？是否匹配供应链品牌价格带？
