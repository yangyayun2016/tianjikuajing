先做好以下几点  
1.确认关键词词库，核心关键词，主推大词和不同广告阶段要推的词，以及QA库和listing文案图片视频等。  
2. 设置充足的offer release date，避免亚马逊将我们产品定位到预售产品，浪费亚马逊给我们前期的流量扶持。  
3. 空出Search term，让亚马逊以我们卖点和标题的词库为主，避免这里的词影响核心词的权重。  
4. 商品定价，指定前期促销的一个策略，低价多优惠切入市场。  
5. 前台搜索ASIN+关键词，查看亚马逊是否收录这个关键词。  
  
  
商品到货第一周，这个周期不要太关注acos，尽量获得更多曝光。首先在自动广告里看亚马逊后台自动识别的关键词匹配，如果匹配不够精准，可以设置手动广泛和精准关键词进行校准。  
关键没问题之后，做一组低bid自动广告，固定竞价，每日预算5美金，0.5左右的竞价进行单量捡漏。  
其次做一组高bid自动广告，固定竞价，给足预算，快速获取流量入口，先观察一周。  
做一组固定竞价的大词广泛匹配，给足预算，1-3组关键词，跑长尾词，前台搜广告位位置，如果低于前三页，加竞价。  
做一组固定竞价的核心词手动广告，给足预算，占据流量坑位，出价高于建议竞价0.2左右。  
做10%off优惠券+10%off会员专享，前期进行促销，时间为一周。  
考虑vine计划。  
可以设置买一赠一，争取快速出单。  
考虑是否要加到老品做变体蹭流量。  
第一周保证至少上三组QA。  
记录差评，feedback，买家之声等。  
  
第二周。  
重新设置促销15%off优惠券+10%off会员专享.  
下载第一周广告报表，根据广告情况确认我们listing是否需要优化。  
根据第一周广告表现，关注点击率是否正常，将第一周高bid广告组调整为正常bid，适量降低预算。  
继续少量补充QA，做好数据记录。  
检查是否需要补充库存。对购买超过七天的订单进行邀评，也可以做一些真人测评，注意留评率。  
  
  
第三周：  
设置20%off优惠券+10%off会员专享，提高转化率。  
下第二周广告数据报表，进一步对listing作一些细微调整，优化广告，对于表现不好的词和ASIn进行加否，比如15次点击没有一次转化的先否掉，分出强关联词和弱关联词，保留强关联词可以用于后期广告加词。  
表现非常不好的词，降低bid或者先不做投放，转推其他的大词，广告表现好，则先不加词。  
自动广告里表现好的词单独拉出来做商品定位广告。  
完善关键词词库，继续优化listing。  
这个阶段可以补充Search term，将关键词逐渐插入listing中，不要做大幅度修改。  
检查后台是否有秒杀推荐，提报秒杀。  
检查是否需要补充库存。  
记录关键词排名，监控竞品，确定基本广告架构。  
  
  
第四周  
降低优惠力度，根据广告表现数据对广告进行进一步优化，新开的广告组让它有两周时间跑数据。  
将广告预算更多的给到手动广告，降低自动广告预算。  
继续检查秒杀情况。  
根据实际情况考虑是否要做站外，拓展流量入口，如果有条件，少量做一些真人测评补充，稳住review评分。  
维护listing，防跟卖收集客户反馈作为产品优化方向，做好售后工作。  
查看库存，记录数据，监控竞品调整方向。  
月底做复盘，制定下个月的销售计划和调货计划。  
  
  
中期，维护review，保证评分在4.3及以上，掉分了要及时补救。  
继续邀评，考虑如果有销量下滑，是否继续做一些优惠。  
定期优化链接，优化广告，记录数据，对数据进行分析总结，关键词要保证在大词排名是稳定靠前的。  
记录每周流量，转化率，订单量，review和排名等。  
  
后期，对产品进行评估，是否继续大力去推和稳住流量，确定下一步计划。  
产品推起来了且销量稳定上升，继续投入，但相对比前期力度小，如果销量下滑，分析下滑原因，指定对应的解决策略。  
前三个月保持数据记录，密切关注市场动向和竞品动向。  
后期一些站内外促销活动，保证库存稳定周转。

亚马逊运营整体策略

**三、前中后期的调整策略**

在链接打造的中后期，如果过度依赖广告也会导致产品利润不足，怎样稳步提升自然单占比才能从根源上解决这个问题。

广告单的占比：根本原因以及如何改变？根据公司模式不同进行调整

在精铺模式下：

不做刻意控制，因为控制点在竞价上，用可控的竞价保证广告单不亏钱。

在精品模式下：

关于自然单的占比控制节奏，可以参考👇以下的推广计划表中的比例节奏。不过这个数值，还是需要结合类目竞争情况和自身的既定目标进行设定。

![](https://picx.zhimg.com/v2-010ab14907e74d12b78f5bdaef83ad05_720w.jpg?source=d16d100b)

| 阶段 | 流量策略 |
| --- | --- |
| 新品期（1~2个月） | 新品期以广告订单为主逐步向自然订单过渡，这个阶段的关键词以高相关精准关键词做主攻对象，先拿下精准流量词，当投放词的自然排名上首页保持至少一周的时间后，阶梯性的降低广告竞价/预算，同时保持观察自然位的变化情况，如遇波动，及时回调； |
| 成长期（2~4个月） | 成长期以扩展中相关关键词为主，目标是拿下中相关的词的自然排名，目标定位在前三页； |
| 稳定期（5~6个月后） | 稳定期以扩词扩流为主，在稳定高相关、中相关词的基础上，扩展低相关词、类目流量、竞品流量； |
| 衰退期 | 可以参考精铺的模式，铺开广告词的入口，以保本cpc通投。 |

其他还有一些调整策略：

1.控制广告订单的占比，在前面从高相关到低相关的广告节奏下，同样需要持续对广告结构进行优化，进行优胜劣汰，将表现不好的广告活动预算，转移到表现好的推广活动上；

2.积极参与秒杀，秒杀的订单增量和持续时尚，不仅可以提升类目排名，还对提升关键词排名有较大的帮助；

3.结合站外推广提升链接权重获得更多类目流量及榜单流量。这里的站外推广并不是指的是参加服务商的FB群组投放，而是需要真正做到社媒运营，海外博客推广，申报秒杀网站等。
