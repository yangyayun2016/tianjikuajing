## 0️⃣ 什么是一个“好 Listing”：用户体验第一，并且是双读者，一个给亚马逊消费者看，一个是给亚马逊系统读

### **几个原则**

1. **第一眼能被用户看懂** ：前台（用户重点看）信息必须“一眼懂”：标题、主图、前 3 张图、五点前 2 条、A+ 首屏

> 用户第一，一个维度是，当其他需求和用户需求冲突时，优先保证用户体验，比如标题，五点优先保证用户能快速看明白，再考虑埋词,PS这点很重要 [mp.weixin.qq.com](https://link.zhihu.com/?target=https%3A//mp.weixin.qq.com/s%3F__biz%3DMzg2MTkxMDY5MA%3D%3D%26mid%3D2247487550%26idx%3D1%26sn%3Dd5817f43f5aa300df8edb65277ec2dc3%26scene%3D21%23wechat_redirect)  
> 引申： [亚马逊二段式标题测试](https://link.zhihu.com/?target=https%3A//mp.weixin.qq.com/s%3F__biz%3DMzg2MTkxMDY5MA%3D%3D%26mid%3D2247487550%26idx%3D1%26sn%3Dd5817f43f5aa300df8edb65277ec2dc3%26scene%3D21%23wechat_redirect)

1. **双读者** ：同时写给 **用户** 和 **亚马逊**

1. 用户可读、可信、敢买（信任桥梁）
2. 系统可识别（ **埋词** 正确、属性完整、GEO），同时符合亚马逊A9算法、Cosmo算法、Rufus

2. **Rufus** ： **前台表述 = 后台属性**

1. 关键参数、属性、说明 **无缺失，不互相矛盾（唯一性&统一性）**
2. 筛选主要竞品的 **Rufus** 问题，提前维护答案信息（参考自己的核心竞品ASIN 模拟提问）

3. **移动端优先：**

1. 实操：比如图片，先做移动端的图，再做PC端【dji、insta360等都是这么做的】
2. 移动端：PC 约 7:3，Listing打造优先考虑手机上的呈现效果
3. 最核心的还是图片： 图是给用户看的，文字主要给系统看的

## 1️⃣ AI打造完美Listing SOP 以及方法论 优化

> **AI使用方法论：**

1. 搞清楚输入是什么，输出是什么
2. 然后思考自己平时是用什么方法，从输入->输出的
3. 把输入、输出、方法，按照顺序写下来就是提示词

- 高价位 / 低价位
- 风格明显差异
- 同适配型号

### 1.2.2 评论分析

把评论交给 AI，分析

- 痛点（不满意什么）
- 期望（本来想要什么）
- 误用（用户怎么用错）
- 兼容性（哪些情况不适配）

> 重点不是比例，而是 **反复出现的问题类型** 。

### 1.2.3 关键词库/ **分析**

- 关键词库：卖家精灵、飞鱼、西柚都可以，任何数据软件都ok

- **意图（功能 / 兼容 / 场景 / 人群 / 问题）**
- **竞争强度（强 / 中 / 弱）**
- **价值（高 / 中 / 低）**

## 2️⃣ 复盘与迭代

> Listing 并不是“写完就结束”的一次性工作。 真正拉开差距的，是 **上线后的复盘与迭代能力** 。  
> **数据监控 → AI 验证 → 定位问题 → 定向优化 → 周期复盘 → 输出下一版方案**  
> 很系统的工作，等第一个部分大家用起来之后，单独分享  
> 基础是第一个部分的工作文档、数据全部记录+线上化

### 2.1 数据监控

- **核心指标** ：点击率（CTR）、转化率（CVR）、广告 ACOS/ROAS、自然排名、Review 数量&评分。
- **节奏** ：每日监控异常，7天/14天做周期复盘

### 2.2 AI效果验证

- **Rufus模拟问答** ：确认用户常问问题 Listing 是否覆盖，是否需要补充
- **关键词反查** ：反查 ASIN，看当前排名词是否与预期关键词池匹配
- **买家视角审查** ：用 AI 模拟不同用户人群（老人/术后/孕妇等），检查文案和图片是否满足痛点

### 2.3 迭代优化表

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 模块 | 触发指标 / 信号 | 典型表现 | 优化方向 | 本质判断 |
| 标题 | CTR 偏低 | 有曝光但点不开 | 调整关键词顺序；差异点前置；删干扰词 | 第一眼没看懂 |
| 五点（前两条） | CVR 偏低 | 点进来但不下单 | 强化数字化、场景化、直接利益点 | 核心顾虑未解决 |
| 五点（后三条） | 排名异常 / Rufus答不全 | 排名词偏离预期 | 补充语义词；回答常见问题 | 系统理解不完整 |
| 主图 | CTR 低 / 波动大 | 搜索页吸引力不足 | A/B 测试角度、构图、差异点 | 差异没被感知 |
| 附图 | CVR 偏低 | 看了但仍犹豫 | 补充使用场景、尺寸、结构 | 理解成本过高 |
| A+ | 新客转化不稳 | 高价或复杂产品 | 加对比模块、参数表、本土化文案 | 信任感不足 |
| 视频 | 有点击无转化 | 看了但没买 | 强化前5秒；动态解释优势 | 动机未被激发 |

> 原则： **一次复盘，只允许改 1–2 个模块，禁止全面重写。**  
> AB测试的逻辑，保证数据能正确归因

### 2.4 固定复盘节奏表（防止“凭感觉优化”）

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| 周期 | 执行角色 | 主要动作 | 使用工具 | 输出结果 |
| 每日 | 运营 | 查看异常（CTR / CVR / 花费） | 后台 / 广告报表 | 异常记录 |
| 每周 | 运营 + AI | 汇总数据，定位问题模块 | ChatGPT / 表格 | 周度分析结论 |
| 每月 | 负责人 | 对比竞品与趋势，更新关键词池 | 数据工具 + AI | 月度结构判断 |
| 每季度 | 团队 | 全链路复盘（标题/图/五点/A+/视频） | SOP + AI | 下一阶段方案 |

> 关键不是频率，而是： **每个周期，都必须产出“明确的下一步动作”。**

**什么是比例？**比例也叫横纵比，是图像宽度与高度的比例关系。第一个数字代表宽度，第二个数字代表高度。例如：

- YouTube 视频的最佳比例为 16:9
- Instagram 上的照片比例为 1:1
- 大部分Amazon 卖家共识的图片比例为1:1

**为什么比例很重要？**图像的横纵比很重要，因为产品的最佳构图需要特定的比例来实现，最终影响产品缩略图在搜索页面的外观。由于亚马逊只为每个listing提供有限的空间，因此选择最佳的比例来优化有限的空间是关键。更重要的的是，由于线上销售的原因，需要完全依靠主图和描述来进行销售。由于客户在购买之前无法在现实生活中看到或触摸产品，因此他们只能通过图像，因此主图是影响点击率的第一要素！亚马逊搜索页面上给予主图的比例也是最大的。**主图在搜索页的展示逻辑**先来看看亚马逊官方的图片最低要求：（2022.05.23引用自卖家后台Cell Phones & Accessories类目）：

- 商品必须至少填满 85% 的图片。
- 图片必须仅显示要出售的商品，可包含部分或不能包含其他道具，不能包含商标、水印或内嵌图片。
- 图片包含的文本内容只能是商品信息。主图片必须为背景是纯白色的商品照片（而不是画出来的图），且不能包含其他搭配品。
- 图片缩放时最长边必须在 1000 像素以上，最短边必须在 500 像素以上。
- 图片最长边不能超过 10000 像素。
- 首选 JPEG 格式的图片，但您也可使用 TIFF 和 GIF 格式的图片。

重点总结

- 让商品尽可能填满图片，而非让图片尽可能大，将空白区域限制在15%以内。
