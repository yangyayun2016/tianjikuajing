## 1. 模块：Benchmark 广告健康度总览（最近 30 天）

**目标：一眼看出“广告健康不健康”：贵不贵、点不点、新客值不值。**

### 1.1 指标字段

| 字段 | 说明 | 数据来源 / 计算方式 |
| --- | --- | --- |
| CTR（我方） | 你最近 30 天广告 CTR | 你广告报表：点击量 / 展示量 |
| CTR p50（类目基准） | 类目第 50 百分位 CTR | benchmark-data.xlsx 中 指标=CTR 行的 p50 基准值 |
| CTR 偏差 | CTR / CTR p50 - 1 | 派生计算，>0 表示高于类目中位线 |
| CPM（我方） | 你广告 CPM | 成本 / 展示量 × 1000 |
| CPM p50 | 类目第 50 百分位 CPM | benchmark 中 指标=CPM 行的 p50 基准值 |
| CPC（我方） | 平均点击成本 | 成本 / 点击量 |
| CPC p50 | 类目第 50 百分位 CPC | benchmark 若后续加上 CPC 行，就用 p50；没有就用你广告报表自己的中位数当参考 |
| 购买率（品牌新客）（我方） | 新客曝光转化率（近似新客 CR） | 广告报表中“新客订单数 / 展示量”（如果你有新客标记，没有就先不算） |
| 购买率（品牌新客）p50 | 基准新客购买率 | benchmark 指标=购买率（品牌新客） p50 |
| 单次购买成本（品牌新客）（我方） | 新客 CPA | 成本 / 新客订单量 |
| 单次购买成本（品牌新客）p50 | 类目新客 CPA 基准 | benchmark 指标=单次购买成本（品牌新客） p50 |
| 品牌新客购买量占比（我方） | 新客订单占总订单比 | 新客订单量 / 总订单量 |
| 品牌新客购买量占比 p50 | 类目新客占比基准 | benchmark 指标=品牌新客购买量占比 p50 |

### 1.2 使用场景

- CTR < p50：主图 / 标题 / 关键词匹配度 出问题 → 优化 Listing & 词组结构。
- CPC ≫ p50：出价太激进 / 词太卷 → 降价、减掉高 CPC 低转化词。
- 新客 CPA > 新客毛利：拉新模式不健康 → 重新测算价格 / 广告结构。
- 新客占比对比 p50：判断当前是“拉新期”还是“吃老客期”。

## 2. 模块：Brand Metrics 品牌漏斗（按月）

**目标：看你在“类目漏斗”里的身位：是否跑赢中位数 / 离头部有多远。**

### 2.1 字段清单（按月）

来自「旋转工具 品牌指标.xlsx / 旋转工具」：

| 字段 | 说明 | 数据来源 |
| --- | --- | --- |
| 国家 | 固定 US | 列 国家 |
| 开始日期 / 结束日期 | 月度范围 | 列 开始日期 / 结束日期 |
| 品类 | Rotary Tools 的类目路径 | 列 品类 |
| 指标组 | 总体类别指标（目前只有这一类） | 列 指标组 |
| 流域阶段/指标名称 | 例如“顾客转化率” | 列 指标名称/流域阶段 - 消费者活动 |
| 品类中位数（顾客转化率） | 月度中位转化率 | 列 品类中位数，同时文件里你有总结“月平均转化率 5.62%（中位数）” |
| 品类首要（顾客转化率） | 品类 95–99 分位平均 | 列 品类首要 + 你文中标记“22.54%（首页品类）” |
| 我方顾客转化率 | 你的品牌顾客转化率 | 需从 Amazon Brand Metrics 原始导出（这次文件没带数值，可以后续加） |

另外可以在这块顺带放一条：

- **类目整体转化率（2.89%）**：从「美国旋转工具 类目--整体转化率情况US工作簿.xlsx」里你写的标题“美国旋转工具rotary tool 整体转化率2.89%”。

### 2.2 使用场景

- 顾客转化率 < 品类中位数（5.62%）：说明你连“平均水平”都没到，优先改 Listing / 评价体系。
- 顾客转化率 已接近 5.62%，但离 22.54% 还有很大距离：说明你有基础，但要冲类目前排要继续做差异化和品牌心智（SB / 视频 / 站外内容）。
- 搭配类目整体 CR 2.89%：

- 若你自家 PDP CR < 2.89%：Listing 本身就有问题；
- 若 PDP CR > 2.89%，但顾客转化率依然低：更多是“品牌漏斗前端”的问题（品牌知名度 / 详情页点击率）。

### 3.2 你要新增的运营字段（结合你广告报表）

| 字段 | 说明 | 计算方式 |
| --- | --- | --- |
| 我方曝光 | 你在该词上的展示量 | 广告搜索词报告 |
| 我方点击 | 你在该词上的点击 | 搜索词报告 |
| 我方订单 | 该词带来的订单 | 搜索词报告 |
| 我方花费 | 该词花费 | 搜索词报告 |
| 我方CTR | 我方点击 / 我方曝光 | 派生 |
| 我方CVR | 我方订单 / 我方点击 | 派生 |
| 我方CPC | 我方花费 / 我方点击 | 派生 |
| 我方ACOS | 我方花费 / 该词销售额 | 派生 |
| 流量级别 | 一级/二级/三级流量词 | 按年搜索量分档（比如 Top 20% 视为一级） |
| 相关性 | 强 / 中 / 弱 / 不相关 | 你对产品适配度的判断，可加规则 |
| 策略标签 | 核心抢量 / 长尾守门 / 品牌防守 / 暂停 | 根据 ACOS + CVR + 流量级别打标签 |

### 3.3 使用场景

- 用 **搜索量 × 搜索转化率** 排序，优先挑出 **“高量高转”** 作为核心投放词；
- 对 top3 商品集中度高（点击份额 >70%，且都为 Dremel 等头部品牌）的词 → 标记为 **“高竞争防守词”**，只低价精准投放；
- 对点击份额分散、搜索转化率高的词 → 标记为 **“突破词”**，给到更高出价；
- 长尾高转化、搜索量不大的词 → 做低价稳定投放，撑稳利润。

- 图文 & 视频风格对比
- Review 和 QA 痛点分析（你之前已经在做）

## 7. 模块：利润 & ROI 测算（盈亏平衡）

**目标：用数字把“能烧多少钱广告”算清楚，形成 CPC / CPA 红线。**

（具体字段你模版里已经有，这里提取最关键给 Dashboard 用的）

| 字段 | 说明 | 数据来源 / 计算 |
| --- | --- | --- |
| 售价 | 当前售价 | 推广计划 / 实际售价 |
| 单件总成本 | 采购 + 头程 + FBA 费用 | 利润&ROI测算 sheet |
| 单客毛利（首单） | 售价 – 总成本 | 派生 |
| 目标毛利率 | 例如 30% | 你设定 |
| 允许广告成本（每单） | 售价 × (目标毛利率) – 其他成本 | 派生 |
| 盈亏平衡 ACOS | 允许广告成本 / 售价 | 派生 |
| 盈亏平衡 CPC | （允许广告成本 × 预期 CR） | 可反推，假设 CR≈ 类目 / Brand Metrics |
| 新客 LTV（如有） | 新客 6/12 个月贡献 | 若有复购数据可加 |

Dashboard 里可以做几条“红线”：

- ACOS > 盈亏平衡 ACOS ⇒ 赤字；
- CPC > 盈亏平衡 CPC ⇒ 需要提高 CVR 或调整结构。
