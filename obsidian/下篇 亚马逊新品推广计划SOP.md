# 一句话总结

这套亚马逊新品推广 SOP 的本质是：

**先用市场调研筛掉没机会的产品，再用竞品和关键词找到切入口，用利润和 CPC 测算验证能不能打，最后通过链接准备、广告架构、数据追踪和库存管理，把新品推广从“凭感觉试错”变成“按数据推进”的标准化流程。**

下面是基于你上传的《新品推广计划SOP表格使用说明》整理出的**亚马逊新品推广计划 SOP 完整版**。我按“做什么、怎么做、填什么、产出什么、注意什么”的方式重新归纳，方便直接拿来做团队执行标准。

# 亚马逊新品推广计划 SOP 总览

新品推广不是单纯“上架—开广告—等出单”，而是一套从**市场验证、竞品拆解、利润测算、链接准备、广告推广、数据追踪、库存管理、复盘调整**组成的闭环流程。

完整 SOP 分为五大模块：

|阶段|模块|核心目标|关键产出|
|---|---|---|---|
|1|市场调研|判断产品有没有市场空间、竞争强度、用户痛点和生命周期|市场分析报告、类目调研表、痛点卖点总结、生命周期判断|
|2|类目细分|找到可切入的细分类目、目标人群、关键词和对标竞品|竞品库、竞品分析表、关键词库、差异化方向|
|3|模拟预估|测算利润、成本、广告承受力、批次盈亏|利润预估表、货值预估表、评论部署成本、CPC平衡表、批次盈亏表|
|4|链接准备|准备上线前所有 Listing 和视觉素材|标题、五点、描述、搜索词、A+、品牌故事、Q&A、图片需求|
|5|推广计划|制定 3 个月新品推广节奏，并持续追踪优化|广告架构、运营追踪表、库存监控、周计划、备选预案|

# 一、市场调研模块

## 1. 模块目标

市场调研的目标是判断新品是否值得做。重点不是“我觉得这个产品好”，而是通过数据验证：

1. 市场容量够不够大。
    
2. 竞争是否已经严重固化。
    
3. 头部品牌是否垄断。
    
4. 用户有没有明确痛点。
    
5. 产品是否还有差异化空间。
    
6. 是否存在专利、版权、认证风险。
    
7. 产品生命周期处于早期、成长期、成熟期还是衰退期。
    

---

## 2. 市场分析报告

### 2.1 类目名称

填写准确的亚马逊类目名称。

如果产品涉及多个类目，需要分别填写，不能混在一起。

例如：

|产品|可能涉及类目|
|---|---|
|Back Brace|Back Braces、Posture Correctors、Waist Support|
|Dog Brush|Dog Grooming Supplies、Pet Brushes、Pet Hair Removers|

### 2.2 市场分析报告

需要粘贴或附上第三方工具导出的市场报告。

常用工具包括：

1. 卖家精灵。
    
2. Sorftime。
    
3. Helium 10。
    
4. Jungle Scout。
    
5. 其他类目分析插件。
    

报告需要重点查看：

|维度|作用|
|---|---|
|类目概览|判断整体市场规模|
|品牌集中度|判断是否被头部品牌垄断|
|上架时间分布|判断新品突围难度|
|价格分布|判断主流价格带|
|市场趋势|判断是否增长、下滑或季节性波动|
|评论分布|判断入场评论门槛|
|销量分布|判断不同排名对应销量|
|评分分布|判断用户满意度和痛点空间|

### 2.3 近似专利 / 版权记录

必须登记近似专利、外观专利、版权、商标风险。

记录形式可以是：

1. 查询截图。
    
2. 专利报告。
    
3. 竞品专利页面链接。
    
4. 知识产权风险备注。
    

重点判断：

|风险类型|检查内容|
|---|---|
|外观专利|外形、结构、包装是否近似|
|实用专利|功能结构是否侵权|
|商标|标题、五点、图片是否误用品牌词|
|版权|图片、说明书、图案、文案是否侵权|
|认证|是否涉及医疗、儿童、食品接触、电器等特殊合规|

# 二、市场调研表填写 SOP

## 1. 类目调研

### 1.1 序号

如果调研多个类目或多个垂直方向，需要编号。

例如：

|序号|类目|
|---|---|
|1|Back Braces|
|2|Posture Correctors|
|3|Waist Support Belts|

### 1.2 类目名称

填写完整类目名称，避免只写简称。

### 1.3 类目链接

填写亚马逊前台 BSR 类目链接，方便后续快速复查。

### 1.4 产品名称

填写当前计划开发或推广的产品名称。

### 1.5 市场容量

可以用以下指标之一衡量，但必须统一数据来源和统计口径：

1. 类目月销量。
    
2. 类目销售额。
    
3. 核心关键词搜索量。
    
4. BSR 榜单头部销量。
    
5. 第三方工具估算交易量。
    

**注意：所有类目必须使用同一数据源和同一维度，否则无法横向比较。**

### 1.6 垄断程度

判断头部品牌或头部链接是否占据过高市场份额。

可查看：

1. Top 10 销量占比。
    
2. Top 10 品牌占比。
    
3. Top 3 ASIN 点击占比。
    
4. ABA 热门搜索词 Top 3 占比。
    
5. BSR 榜单是否长期由固定品牌霸榜。
    

判断标准可以参考：

|垄断情况|特征|
|---|---|
|低垄断|榜单品牌分散，新品频繁出现|
|中垄断|有几个强品牌，但仍有新卖家机会|
|高垄断|头部品牌长期固定，新品很难进入|
|极高垄断|品牌、评论、价格、广告位都被头部控制|

### 1.7 类目分支

拆分类目内不同细分市场。

可以按以下维度拆：

|维度|示例|
|---|---|
|使用部位|腰部、背部、肩部、膝盖|
|用户群体|男性、女性、儿童、老人、运动人群|
|功能|支撑、矫正、缓解疼痛、塑形|
|使用场景|办公、运动、康复、户外、家用|
|外观结构|肩带式、背心式、腰带式|
|材质|透气网布、尼龙、硅胶、金属支撑|
|规格|单件、多件套、大中小码|
|价格带|低价、中价、高价、礼盒款|

### 1.8 BSR 分布

填写 BSR 榜单中各细分分支的产品分布。

要判断：

1. 哪类产品占比最高。
    
2. 哪类产品销量最好。
    
3. 哪类产品价格最高。
    
4. 哪类产品评论门槛最低。
    
5. 哪类产品是否已有大量同款。
    

### 1.9 新品榜分布

查看新品榜中快速上升的产品类型。

重点关注：

1. 哪类新品上升最快。
    
2. 是否存在新趋势。
    
3. 是否有低评论产品冲上来。
    
4. 是否说明类目仍有机会。
    
5. 新品是否靠差异化、低价、广告或站外起量。
    

---

## 2. 产品调研

### 2.1 价格带分布

统计市场价格分布。

建议拆成：

|价格带|产品数量|销量表现|评论门槛|竞争判断|
|---|--:|--:|--:|---|
|低价段|||||
|主流价格段|||||
|高价段|||||
|溢价段|||||

判断新品应该进入哪个价格带。

### 2.2 平均评分

查看类目平均评分。

如果市场平均评分很高，说明用户满意度较高，新品差异化难度较大。

如果大量竞品评分偏低，说明存在痛点改良机会。

### 2.3 低于 4.3 分的数量

统计低评分链接数量。

重点看这些低分产品的问题：

1. 材质差。
    
2. 尺寸不准。
    
3. 功能虚标。
    
4. 易坏。
    
5. 包装差。
    
6. 安装复杂。
    
7. 使用体验差。
    
8. 售后问题多。
    

这些就是后续差异化开发和 Listing 文案的机会点。

### 2.4 退货率

可以从后台选品指南针、市场报告或竞品数据中获取。

退货率高的类目要特别谨慎，因为会影响：

1. 利润。
    
2. 账户绩效。
    
3. 库存周转。
    
4. 广告回本周期。
    
5. 后续评分。
    

---

## 3. 销售量调研

需要统计不同排名区间的日销水平。

|排名区间|日销量作用|
|---|---|
|Top 1–10|判断头部容量和天花板|
|Top 30–50|判断腰部卖家销量|
|Top 80–100|判断新品初步进入榜单需要的销量|
|Top 150–200|判断冷启动目标是否现实|

核心用途：

1. 设定推广目标排名。
    
2. 反推日均销量目标。
    
3. 反推广告预算。
    
4. 反推库存备货数量。
    
5. 判断是否值得进入该类目。
    

---

## 4. 综合卖点与痛点调研

### 4.1 市场分析

综合盘点市场产品特征，包括：

1. 产品属性。
    
2. 功能场景。
    
3. 受众人群。
    
4. 结构设计。
    
5. 材质。
    
6. 规格。
    
7. 包装。
    
8. 使用方式。
    
9. 价格定位。
    
10. 品牌定位。
    

### 4.2 综合卖点

总结市场共同宣传的卖点。

例如：

1. Lightweight。
    
2. Breathable。
    
3. Adjustable。
    
4. Durable。
    
5. Pain Relief。
    
6. Easy to Use。
    
7. Ergonomic Design。
    
8. Premium Material。
    

### 4.3 综合痛点

从差评、QA、Review、退货反馈中提炼痛点。

常见痛点包括：

1. 尺寸不匹配。
    
2. 材质廉价。
    
3. 使用不舒适。
    
4. 容易断裂。
    
5. 效果不明显。
    
6. 气味大。
    
7. 安装麻烦。
    
8. 包装破损。
    
9. 说明书不清晰。
    
10. 与图片不符。
    

### 4.4 痛点能否改良规避

每个痛点都要判断是否能通过产品开发解决。

|痛点|是否可改良|改良方式|
|---|---|---|
|尺寸偏小|是|增加尺码表，调整版型|
|材质闷热|是|更换透气材料|
|功能效果弱|不一定|需要结构升级或重新定位|
|使用复杂|是|增加说明书、视频、结构优化|

### 4.5 差异化方向

可以从以下角度构思：

1. 颜色差异化。
    
2. 尺码差异化。
    
3. PCS 数量差异化。
    
4. 包装差异化。
    
5. 功能差异化。
    
6. 外观差异化。
    
7. 材质差异化。
    
8. 配件差异化。
    
9. 使用场景差异化。
    
10. 人群定位差异化。
    

---

## 5. 市场趋势与未来预测

### 5.1 季节性

判断类目是否有明显旺季和淡季。

需要记录：

1. 旺季月份。
    
2. 淡季月份。
    
3. 是否节日驱动。
    
4. 是否气候驱动。
    
5. 是否礼品属性。
    
6. 是否受平台大促影响。
    

### 5.2 合规认证

检查是否需要认证材料。

常见风险产品：

|产品类型|可能认证|
|---|---|
|儿童产品|CPC、CPSIA|
|食品接触类|FDA、LFGB|
|电子电器|FCC、CE、UL|
|医疗健康|FDA、医疗声明限制|
|美妆个护|成分、标签、合规声明|

需要预估：

1. 认证材料是否齐全。
    
2. 审核周期。
    
3. 审核失败风险。
    
4. 是否影响上架时间。
    

---

## 6. 产品生命周期分析

### 6.1 刚需 / 潮流判断

判断产品属于：

|类型|特征|
|---|---|
|长期刚需|稳定需求、复购或持续使用|
|功能型产品|解决明确问题，需求稳定|
|潮流型产品|爆发快，衰退也快|
|一次性产品|复购低，容易价格战|
|礼品型产品|季节性强，视觉要求高|

### 6.2 专利查询

通过专利判断：

1. 是否有侵权风险。
    
2. 是否有技术壁垒。
    
3. 是否存在升级空间。
    
4. 是否可以扩展周边产品。
    

### 6.3 BSR 同类数量

判断同类产品是否高度标准化。

同类数量越多，通常说明：

1. 类目成熟。
    
2. 差异化难度增加。
    
3. 价格战风险更高。
    
4. 生命周期可能偏后期。
    

### 6.4 BSR 同款数量

判断同款是否已经泛滥。

如果同款数量多，说明：

1. 供应链门槛低。
    
2. 卖家容易跟进。
    
3. 利润容易被打穿。
    
4. 需要更强差异化或品牌化。
    

### 6.5 新品榜同类数量

如果新品榜同类多，说明类目仍有新品进入机会。

如果新品榜长期被老品牌或固定款式占据，说明突围难度较高。

### 6.6 新品榜同款数量

如果新品榜同款数量多，说明市场正在快速同质化，需要谨慎。

# 三、类目细分模块

## 1. 模块目标

类目细分的目标是找到真正适合新品切入的市场位置。

要解决四个问题：

1. 我们应该卖给谁？
    
2. 我们应该对标谁？
    
3. 我们应该打哪些关键词？
    
4. 我们凭什么比竞品更值得买？
    

---

## 2. 竞品信息收集

可以使用卖家精灵或其他工具导出竞品信息。

必须包含以下字段：

|字段|作用|
|---|---|
|Listing|查看标题、图片、五点、A+、Review|
|配送方式|判断 FBA / FBM / 自配送|
|库存数量|判断销售节奏和补货压力|
|上架时间|判断新品周期和老品壁垒|
|大小类排名|判断类目位置|
|价格 & 促销|判断价格策略|
|星级评分|判断用户满意度|
|日销 / 月销|判断销量目标|
|变体数量|判断变体打法|
|店铺概况|判断品牌力和铺货模式|

---

## 3. 竞品分析

### 3.1 类型

竞品要明确分类：

|类型|含义|对标重点|
|---|---|---|
|同款|外观、功能、结构高度接近|价格、评论、图片、广告|
|同类|满足相似需求但形态不同|卖点、用户、关键词|
|周边关联|使用场景相关但不是直接竞品|关联流量、捆绑机会|

### 3.2 卖点

分析每个竞品的突出卖点。

要从以下位置提取：

1. 标题。
    
2. 五点。
    
3. A+。
    
4. 主图。
    
5. 视频。
    
6. Review 高频词。
    
7. QA。
    

### 3.3 痛点

和类目痛点不同，这里要分析具体竞品的痛点。

来源包括：

1. 差评。
    
2. 3 星评论。
    
3. QA。
    
4. 退货原因。
    
5. 图片评论。
    
6. 视频评论。
    

### 3.4 店铺概况 / 品牌影响力

打开竞品店铺查看：

1. 是否垂直类目。
    
2. 是否泛铺货。
    
3. 产品数量。
    
4. 是否有品牌故事。
    
5. 是否有品牌旗舰店。
    
6. 是否有类目矩阵。
    
7. 是否在关联流量中自我防守。
    

### 3.5 店铺产品数

登记店铺上架商品数量。

判断：

|情况|说明|
|---|---|
|产品数少但销量高|可能是精品品牌|
|产品数多且类目杂|可能是铺货卖家|
|产品集中在一个垂直类目|品牌专业度较强|
|多个相关产品矩阵|有关联流量防守能力|

### 3.6 关联流量防守占比

检查竞品详情页是否有自品牌占坑。

重点看：

1. Newer Model。
    
2. Frequently Bought Together。
    
3. 关联销售。
    
4. 关联视频。
    
5. Posts。
    
6. A+ 对比图。
    
7. 品牌旗舰店入口。
    
8. Sponsored Brands。
    
9. Sponsored Products。
    

如果竞品自品牌占坑多，新品抢流量难度更高。

### 3.7 价格曲线

用 Keepa 查看竞品历史价格。

重点判断：

1. 是否长期稳定价。
    
2. 是否频繁降价。
    
3. 是否大促拉升。
    
4. 是否低价冲量后涨价。
    
5. 是否常年 Coupon。
    
6. 是否存在明显清货。
    

### 3.8 评论构成

查看评论来源和构成。

需要判断：

1. 是否 Vine 评论多。
    
2. 是否早期评论集中出现。
    
3. 是否评论增长异常。
    
4. 是否存在测评痕迹。
    
5. 是否图片 / 视频评论比例高。
    
6. 是否评论质量支撑转化。
    

### 3.9 流量占比

分别查看竞品流量来源：

|流量类型|分析重点|
|---|---|

## 2. 关键词归类方法

关键词可以按以下维度分类：

|类型|示例|
|---|---|
|核心大词|back brace|
|精准词|lower back brace for women|
|功能词|posture corrector|
|痛点词|back pain relief|
|人群词|back brace for men|
|场景词|back support for work|
|材质词|breathable back brace|
|规格词|plus size back brace|
|竞品词|品牌名、竞品型号|
|长尾词|adjustable lower back support belt|

## 3. 关联度判断

不要主观认为关键词相关，必须前台验证。

验证方法：

1. 搜索关键词。
    
2. 查看首页自然结果。
    
3. 查看广告结果。
    
4. 判断搜索结果是否与自身产品一致。
    
5. 判断用户搜索这个词时是否可能购买你的产品。
    

## 4. 广告压力指数

公式：

**广告压力指数 = CPC ÷（售价 × 转化率）**

用途：

1. 判断关键词广告是否打得动。
    
2. 判断 CPC 是否超出利润承受范围。
    
3. 筛选优先投放词。
    
4. 避免盲目打高竞争大词。
    

一般来说：

|广告压力|判断|
|---|---|
|低|可以优先测试|
|中|需要控制预算和出价|
|高|谨慎投放|
|极高|不适合新品早期硬打|

|---|---|
|美国|USD|
|英国|GBP|
|德国 / 法国 / 意大利 / 西班牙|EUR|
|日本|JPY|

### I–J 列：产品货值

I 列填写 RMB 拿货成本。

J 列根据汇率自动换算成外币成本。

### K–P 列：商品尺寸

K、L、M 填写 cm 单位：

1. 长。
    
2. 宽。
    
3. 高。
    

N、O、P 自动换算成 inch。

### Q–S 列：泡重 / 实重 / 计费重

|字段|说明|
|---|---|
|Q 泡重|根据包装尺寸自动计算|
|R 实重|手动填写实际重量|
|S 计费重|自动取泡重和实重较高值|

亚马逊和物流计算重量时通常按较高者计费，所以计费重非常关键。

### T 列：头程运费每公斤

向货代咨询近期价格。

参考范围：

|渠道|参考价格|
|---|---|
|空运|约 45–60 元 / kg|
|快船|约 11–20 元 / kg|
|慢船|约 6–12 元 / kg|

实际价格会受到：

1. 发货地到货代费用。
    
2. 外箱膨胀。
    
3. 货代复测误差。
    
4. 产品重量误差。
    
5. 合仓入库配置费。
    
6. 旺季物流涨价。
    

### U–V 列：头程运费

单件头程运费逻辑：

**单件头程运费 = 每公斤物流单价 × 单件计费重**

### W–X 列：佣金比例 / 佣金

W 列填写类目佣金比例。

常见佣金比例约 15%，但要以后台对应类目为准。

X 列自动根据售价计算佣金。

### Y–Z 列：VAT 税率 / VAT 税费

欧洲站需要填写 VAT。

美国站通常不填 VAT，但要根据站点实际情况处理。

### AA 列：亚马逊配送费用

也就是 FBA 尾程派送费。

可通过四种方式获取：

1. 前台搜索同款 / 同类产品估算尾派费。
    
2. 后台收入计算器搜索同类商品。
    
3. 后台收入计算器手动定义商品尺寸重量。
    
4. 下载 FBA 物流费用表，对照尺寸重量计算。
    

### AB 列：仓储费

表格按约 2% 自动估算。

实际仓储费会受：

1. 产品尺寸。
    
2. 仓储月份。
    
3. 旺季附加费。
    
4. 库龄。
    
5. 是否长期仓储。
    

### AC–AG 列：广告、促销、优惠券占比

白色单元格填写比例。

绿色单元格自动计算成本。

这里通常包括：

1. 广告占比。
    
2. Coupon。
    
3. Prime 专享折扣。
    
4. 促销折扣。
    
5. 站内活动折扣。
    

### AH 列：折扣销售额

扣除所有促销折扣后的最终成交价。

后续利润计算要基于这个成交价，而不是原始售价。

### AI 列：销售成本

销售成本通常包括：

1. 销售佣金。
    
2. 税费。
    
3. FBA 尾程配送费。
    
4. 广告支出。
    

这是平台直接扣除的成本。

### AJ 列：回款额

公式逻辑：

**回款额 = 折扣销售额 - 销售成本**

### AK 列：投入成本

公式逻辑：

**投入成本 = 产品货值 + 头程运费**

这是产品卖出前已经投入的成本。

### AL 列：毛利润

公式逻辑：

**毛利润 = 回款额 - 投入成本 - 仓储费等杂费**

这是单件产品最终利润，单位为对应站点外币。

### AM 列：ROI 投资回报率

用于判断投入产出。

表格中用于评估投产是否达标。

### AN 列：毛利率

公式逻辑：

**毛利率 = 毛利润 ÷ 售价**

参考标准：

|指标|参考线|
|---|---|
|毛利率|30%以上相对安全|
|投产比|大于 1.7 可视为及格参考|

注意：不同类目差异很大，这不是绝对标准。

### AO–AP 列：供应商 / 对标

填写：

1. 供应商名称。
    
2. 供应商链接。
    
3. 对标竞品链接。
    
4. 对标 ASIN。

# 九、CPC 平衡表 SOP

## 1. 模块目标

CPC 平衡表用于判断：

1. 产品利润能承受多少广告点击成本。
    
2. 当前关键词 CPC 是否可打。
    
3. 转化率需要达到多少才不会亏。
    
4. 广告预算是否合理。
    

## 2. 手动填写字段

白色单元格填写：

1. 产品定价。
    
2. 单件利润。
    
3. 预估转化率。
    

## 3. 核心逻辑

假设广告盈亏平衡：

**单件利润全部用于广告投放**

那么：

**最高可承受 CPC = 单件利润 × 转化率**

例如：

产品售价 129.99 美金，单件利润 29.29 美金。

|转化率|含义|最高 CPC|
|---|---|---|
|10%|10 次点击出 1 单|约 2.93 美金|
|5%|20 次点击出 1 单|约 1.46 美金左右|

然后用这个最高 CPC 去对比关键词库中的实际 CPC。

如果关键词平均 CPC 高于可承受 CPC，新品硬打会亏损。

---

## 4. 预算反推逻辑

假设目标：

1. 进入小类前 200。
    
2. 日均 3 单。
    
3. 单件利润 29.29 美金。
    

则每日可承受广告预算约：

**29.29 × 3 = 87.87 美金**

可以按 90 美金估算。

如果平均 CPC 为 2 美金：

**90 ÷ 2 = 45 次点击**

如果 45 次点击要出 3 单：

**45 ÷ 3 = 15 次点击出 1 单**

即需要约 6.7% 转化率，接近 7%。

这可以用来判断：

1. 预算是否够。
    
2. 转化率目标是否现实。
    
3. 图片和 Listing 是否需要加强。
    
4. 是否应该避开高 CPC 大词。
    
5. 是否先从长尾精准词切入。

## 3. 备选预案

新品推广实际结果可能偏离预期，所以必须提前准备预案。

### 3.1 如果曝光低

可能原因：

1. 关键词相关性弱。
    
2. 出价太低。
    
3. 广告结构不合理。
    
4. 类目节点不准确。
    
5. Listing 收录不足。
    

调整方向：

1. 提高核心词出价。
    
2. 增加自动广告。
    
3. 检查关键词埋词。
    
4. 调整类目。
    
5. 增加相关长尾词。
    

### 3.2 如果点击低

可能原因：

1. 主图不吸引。
    
2. 价格无优势。
    
3. Coupon 不明显。
    
4. 星级 / 评论不足。
    
5. 标题卖点不清晰。
    

调整方向：

1. 优化主图。
    
2. 增加 Coupon。
    
3. 优化标题前半段。
    
4. 对比竞品价格。
    
5. 增加 Review 部署。
    

### 3.3 如果转化低

可能原因：

1. Listing 承接差。
    
2. 图片没有打中痛点。
    
3. 价格偏高。
    
4. 评论不足。
    
5. 关键词不精准。
    
6. 产品痛点未解决。
    

调整方向：

1. 优化副图和 A+。
    
2. 调整广告词。
    
3. 否掉不相关词。
    
4. 调整价格或 Coupon。
    
5. 补充 Q&A。
    
6. 增加视频。
    

### 3.4 如果 ACOS 高

可能原因：

1. CPC 过高。
    
2. 转化率低。
    
3. 词太泛。
    
4. 预算分散。
    
5. 广告打到不精准流量。
    

调整方向：

1. 降低泛词出价。
    
2. 保留转化词。
    
3. 否定无效词。
    
4. 拆分广告组。
    
5. 把预算集中到高转化词。
    

### 3.5 如果库存风险高

可能情况：

1. 卖得太快，可能断货。
    
2. 卖得太慢，可能积压。
    
3. 海运到货慢。
    
4. 广告放量节奏和库存不匹配。
    

调整方向：

1. 快断货：降预算、提价、控制 Coupon。
    
2. 滞销：加促销、做站外、清理低效广告。
    
3. 补货中：用空运补少量安全库存。
    
4. 旺季前：提前备货。

# 十六、完整执行闭环

最终 SOP 应该形成这个闭环：

1. 市场调研：判断能不能做。
    
2. 类目细分：判断从哪里切入。
    
3. 竞品分析：判断对标谁。
    
4. 关键词库：判断打哪些流量。
    
5. 利润预估：判断单件赚不赚钱。
    
6. 货值预估：判断备货压力。
    
7. 评论部署：判断冷启动成本。
    
8. CPC 平衡：判断广告能不能打。
    
9. 批次盈亏：判断整批货是否值得推。
    
10. Listing 准备：提高转化基础。
    
11. 图片 / A+ 准备：提高点击和转化。
    
12. 广告架构：规划推广路径。
    
13. 运营追踪：持续监控数据。
    
14. 库存监控：避免断货或积压。
    
15. 周计划复盘：及时调整策略。
    
16. 最终复盘：决定放量、优化、补货或淘汰。

# 十七、新品推广最终判断标准

一个新品是否值得继续推进，可以看以下指标：

|维度|通过标准|
|---|---|
|市场容量|有足够搜索量或销售额|
|竞争格局|新品仍有突围机会|
|垄断程度|头部没有完全封死|
|评论门槛|新品可追赶|
|利润空间|毛利率最好 30% 以上|
|广告压力|CPC 在可承受范围|
|差异化|有明确改良点|
|供应链|成本、质量、交期稳定|
|合规风险|无明显侵权和认证阻碍|
|库存模型|首批货数量和周期合理|
|推广预算|能支撑至少 1–3 个月测试|
|数据反馈|点击、转化、排名有改善趋势|

3.1 **利润预估**

![](file:///C:\Users\ADMINI~1\AppData\Local\Temp\ksohtml9816\wps28.jpg) 

• **A 列～F 列，产品基本信息，**填写产品一些备注信息，包括发货批次，比如新品第一次发货测品，就填第一批，准备补货就填第二批；同一批次如果发不同渠道，是要分行填写的，因为头程成本的不同会影响最终利润；按不同渠道填写发货数量。再填上产品名称、ASIN或者附上图片，如果自己产品比较多的话，这些基础信息都可以一目了然。

• **I 列、J 列【产品货值】**，在 I 列填写你的拿货 RMB 成本，J 列会自动根据汇率换算成外币；

• **K 列-P 列【商品尺寸**】，K、L、M 填写产品内盒包装尺寸，填写 cm 单位的长、宽、高，N、O、P 会自动换算成 inch 英寸单位；

• **Q 列【泡重】，R 列【实重】，S 列【计费重】**，Q列会根据前面尺寸信息自动计算泡重，R 列手动填上实重，因为亚马逊计算重量会按实重、泡重（体积重）数值高的抓取计算，S列会自动抓取更高值纳入计费重； 这些信息都可以在对接供应商的过程中获取然后来填写。

• **T 列【头程运费（每公斤）】**，咨询一下货代近期的物流价格，填写上每公斤的价格就好，空运价格大概在45-60 元/公斤，快船价格大概在 11-20 元/公斤，慢船价格大概在 6-12 元/公斤；

• **U 列、V列【头程运费】**，单件产品头程运费的预估其实不复杂，就是物流每公斤单价*产品单件重量（S列计费重）。实际发货的过程中，一是从发货地到货代会产生费用，二是货代测量阶段，会遇到外箱膨胀，以及产品重量误差参差不齐，这些都会导致实际产生的物流费用与预估的有偏差，三是今年新规之后创建货件如果合仓会产生额外入库配置费。

• **W 列、X列【佣金比例】**在后台打开 https://sellercentral.amazon.com/help/hub/reference/GTG4BAWSY39Z98Z3可以查询自己产品所属类目的销售佣金比例，常见都是 15%；X列会自动按你的 G 列售价计算销售佣金；

• **Y、Z列【VAT 税率、VAT 税费】**，欧洲站会涉及 VAT 税费，注意填写税率和税费

• **AA列【亚马逊配送费用 USD】**，也就是常说的尾程派送费，有 4 种计算方法：

￮ 1.亚马逊前台搜索查询同款同类产品的尾派费，

￮ 2.后台搜索框输入收入计算器搜索同类商品查看，

￮ 3.后台搜索框输入收入计算器定义商品填写自己商品的数值查看，

￮ 4.下载亚马逊 FBA 物流费用表，对照尺寸和重量分段自行对应计算。

• **AB列【仓储费】**，按照 2%自动代入估算。

• **AC~AG列是广告、促销、优惠券占比**，白色单元格填入比例，绿色单元格自动计算成本。

• **AH列【折扣销售额】**，这里是扣除的所有的促销折扣得出的最终成交价，计算最终利润都是要基于这个值；

• **AI列【销售成本】**（销售佣金+税费+尾程派送费+广告支出），也就是平台费用，产品售出后并不进入到回款，而直接由亚马逊扣除的成本；

• **AJ列【回款额】**，就是折扣销售额减去销售成本，这个是销售后会获得的回款数值；

• **AK列【投入成本】**（产品货值+头程运费），也就是货物发出一直到产品卖出前就要消耗的前期成本；

• **AL列【毛利润】**，回款额减去投入成本和仓储费等杂费最后得出的就是我们最常关注的所谓卖出一件商品可以获得的利润这里是外币单位；

• **AM列【ROI投资回报率】** ，就是投入成本除以净销售额获得的投资回报比率；

• **AN列【毛利率】**，就是毛利润除以售价；

通常毛利率 30%以上，投产比大于 1.7 是及格线，当然不同类目不同产品情况各异，这个标准没有绝对，仅供参考。

除了直观的查看最终毛利率和投产比，环节中产生的投入成本和销售成本也是非常值得分析参考的，尤其这是红海竞争中“抠”出优势的关键所在。

• **AO列【供应商】、AP列【对标】，**可以标注填写供应商和竞品对标的链接。

这个表的逻辑是假设广告推广是盈亏平衡的情况，那就意味着产品利润正好全部用于广告投放，在对应转化率下能支持最高的 CPC 竞价水平是如何。

比如示例中行车记录仪产品售价129.99 美金，快船利润是29.29美金，那么如果广告转化率 10%，就是 10 次点击就可以出 1 单，那么 CPC 最高 2.93以内都可以保证广告是盈利的不亏钱；如果转化率只有 5%，就是 20 次点击可以出 1 单，最高 CPC 出价 1.36 可以达到盈亏平衡不亏钱。

再以此标准去对照词库的关键词 CPC，可以大致预估出产品推广的广告压力。

再进一步，参考同类竞品的市场情况，拟定第一步想要进入的小类排名和日均单量，比方说我希望先进到小类前 200 名，日均 3 单。那么我每天预算可以达到净利润 29.29*3 单，90美金左右，那么就可以设定90美金每天的预算，如果平均cpc 2美金左右，90除以2，可以支撑每天点击45次左右，点击45次出3单，平均15次出1单，代表保证7%转化率，可以实现广告推广是盈亏平衡的。

于是，我们可以反复推演和测算我们的广告推广需要投入多少预算，能承受的转化率和 acos，以及需要优化的方向。前面的词库搭建，搭配起来也能帮助我们寻求更适合打广告的关键词。

￮ 1.亚马逊前台搜索查询同款同类产品的尾派费，

￮ 2.后台搜索框输入收入计算器搜索同类商品查看，

￮ 3.后台搜索框输入收入计算器定义商品填写自己商品的数值查看，

￮ 4.下载亚马逊 FBA 物流费用表，对照尺寸和重量分段自行对应计算。

• **AB列【仓储费】**，按照 2%自动代入估算。

• **AC~AG列是广告、促销、优惠券占比**，白色单元格填入比例，绿色单元格自动计算成本。

• **AH列【折扣销售额】**，这里是扣除的所有的促销折扣得出的最终成交价，计算最终利润都是要基于这个值；

• **AI列【销售成本】**（销售佣金+税费+尾程派送费+广告支出），也就是平台费用，产品售出后并不进入到回款，而直接由亚马逊扣除的成本；

• **AJ列【回款额】**，就是折扣销售额减去销售成本，这个是销售后会获得的回款数值；

• **AK列【投入成本】**（产品货值+头程运费），也就是货物发出一直到产品卖出前就要消耗的前期成本；

• **AL列【毛利润】**，回款额减去投入成本和仓储费等杂费最后得出的就是我们最常关注的所谓卖出一件商品可以获得的利润这里是外币单位；

3.4 **CPC平衡表格**

这个表的逻辑是假设广告推广是盈亏平衡的情况，那就意味着产品利润正好全部用于广告投放，在对应转化率下能支持最高的 CPC 竞价水平是如何。

比如示例中行车记录仪产品售价129.99 美金，快船利润是29.29美金，那么如果广告转化率 10%，就是 10 次点击就可以出 1 单，那么 CPC 最高 2.93以内都可以保证广告是盈利的不亏钱；如果转化率只有 5%，就是 20 次点击可以出 1 单，最高 CPC 出价 1.36 可以达到盈亏平衡不亏钱。

再以此标准去对照词库的关键词 CPC，可以大致预估出产品推广的广告压力。

再进一步，参考同类竞品的市场情况，拟定第一步想要进入的小类排名和日均单量，比方说我希望先进到小类前 200 名，日均 3 单。那么我每天预算可以达到净利润 29.29*3 单，90美金左右，那么就可以设定90美金每天的预算，如果平均cpc 2美金左右，90除以2，可以支撑每天点击45次左右，点击45次出3单，平均15次出1单，代表保证7%转化率，可以实现广告推广是盈亏平衡的。

于是，我们可以反复推演和测算我们的广告推广需要投入多少预算，能承受的转化率和 acos，以及需要优化的方向。前面的词库搭建，搭配起来也能帮助我们寻求更适合打广告的关键词。

# 亚马逊新品运营全链路 SOP

## 0. SOP 总原则

亚马逊新品运营不能从“上架开广告”开始，而要从**市场验证**开始。

完整路径是：

**市场调研 → 类目细分 → 竞品分析 → 关键词库 → 成本利润预估 → 批次盈亏模拟 → 链接准备 → 广告架构 → 推广执行 → 数据追踪 → 库存管理 → 复盘迭代**

核心原则：

1. **先判断能不能做，再判断怎么做。**
    
2. **先算清楚能不能赚钱，再决定发多少货。**
    
3. **先准备好转化承接，再放广告流量。**
    
4. **每一个推广动作都必须有数据依据。**
    
5. **每一周都要复盘，偏离目标必须有调整方案。**
    
6. **所有 Review 获取、站外推广、折扣活动必须遵守亚马逊平台规则，避免虚假评论、空包、诱导好评等违规操作。**

# 二、市场调研 SOP

## 1. 目标

市场调研不是为了收集数据，而是为了回答 6 个问题：

1. 这个产品有没有真实市场需求？
    
2. 市场容量是否足够支撑目标销量？
    
3. 竞争是否已经严重固化？
    
4. 新品是否还有突围机会？
    
5. 用户是否存在未被满足的痛点？
    
6. 这个产品是否值得进入下一阶段？
    

---

## 2. 类目赛道选择

一个产品可能对应多个类目，必须同时调研多个潜在类目。

### 操作步骤

1. 在亚马逊前台搜索核心关键词。
    
2. 记录首页主要竞品所在类目。
    
3. 进入 BSR 榜单查看类目结构。
    
4. 用卖家精灵、Helium 10、Sorftime、Jungle Scout 等工具导出市场报告。
    
5. 对比不同类目的容量、竞争、价格、评论门槛和新品机会。
    
6. 选择主攻类目和备选类目。
    

### 记录字段

|字段|说明|
|---|---|
|类目名称|精确到小类目|
|类目链接|BSR 榜单链接|
|市场容量|月销量 / 月销售额 / 搜索量|
|类目趋势|上升 / 稳定 / 下滑|
|旺季月份|如 6–8 月、Q4|
|竞争强度|低 / 中 / 高|
|垄断程度|低 / 中 / 高|
|新品机会|有 / 一般 / 弱|
|结论|主攻 / 备选 / 放弃|

## 3. 市场容量分析

市场容量不能只看搜索量，要同时看**流量、成交和销售额**。

### 核心指标

|指标|判断目的|
|---|---|
|类目月销量|判断真实需求|
|类目月销售额|判断市场规模|
|核心关键词搜索量|判断流量入口|
|Top 10 日销量|判断市场天花板|
|Top 30–50 日销量|判断腰部卖家水平|
|Top 80–100 日销量|判断新品进入门槛|
|Top 150–200 日销量|判断冷启动目标|

### 判断标准

|情况|结论|
|---|---|
|高流量 + 高成交|市场容量好，但竞争可能强|
|高流量 + 低成交|用户兴趣高，但转化可能有阻力|
|低流量 + 高成交|小而精准，适合细分切入|
|低流量 + 低成交|谨慎进入|
|Top 100 日销过高|推广预算压力大|
|Top 100 日销较低|新品可能更容易进入榜单|

### 必查内容

|项目|检查方式|
|---|---|

|头部竞品评论量|前台统计|
|头部竞品价格控制力|Keepa 价格曲线|

### 判断标准

|垄断程度|特征|决策|
|---|---|---|
|低|榜单卖家分散，新品频繁出现|可进入|

|市场均值|类目价格稳定|
|中高价 + Coupon|产品有一定差异化|
|高价定位|品牌感强、图片强、功能升级|
|低价冲量后提价|冷启动阶段需要销量|

## 2. 评分与 4.3 临界点

4.3 分是重要视觉临界点，低于 4.3 往往会影响点击和转化。

### 必查数据

|字段|作用|
|---|---|
|类目平均评分|判断用户满意度|
|低于 4.3 的链接数量|判断痛点机会|
|4.5 以上链接占比|判断竞争质量|
|评分最低竞品问题|提炼避坑点|
|差评集中原因|产品开发改良方向|

### 差评分类

|差评类型|处理方式|
|---|---|
|材质差|换材质或强化描述|
|尺寸不准|优化尺码表和图片|
|易坏|加强结构和质检|
|安装难|增加说明书和视频|
|效果不符|调整文案，避免夸大|
|包装破损|优化包装|
|气味大|更换材料或增加通风处理|

## 4. 关联度验证

每个关键词都要前台搜索验证。

### 验证方法

1. 搜索关键词。
    
2. 看首页自然结果。
    
3. 看广告结果。
    
4. 判断搜索结果是否与自身产品一致。
    
5. 判断用户搜索该词时是否会购买你的产品。
    
6. 判断该词是否存在误导风险。
    

### 关联度判断

|关联度|标准|用法|
|---|---|---|
|高|首页大部分都是同类产品|标题、精准广告|
|中|有部分相关产品|五点、词组广告|
|低|搜索意图不一致|不投放或否词|
|无关|完全不是目标需求|否定关键词|

## 5. 广告压力指数

公式：

**广告压力指数 = CPC ÷（售价 × 转化率）**

### 用途

1. 判断词能不能打。
    
2. 判断 CPC 是否超出利润承受力。
    
3. 找出高性价比关键词。
    
4. 避免新品早期硬打高竞争大词。
    

### 处理建议

|广告压力|动作|
|---|---|
|低|优先测试|
|中|控预算测试|
|高|降出价或放后期|
|极高|暂不投放|

5. 仓储费。
    
6. VAT / 税费。
    
7. Coupon。
    
8. 促销折扣。
    
9. 广告成本。
    
10. 退货成本。
    
11. 站外成本。
    
12. 视频和素材成本。
    
13. 合规认证成本。
    

---

## 2. 利润预估字段

|字段|说明|
|---|---|
|批次|第一批 / 第二批|
|产品图片|方便识别|
|站点|US / UK / DE|
|产品名称|英文 / 中文|
|ASIN|有则填写|
|售价|目标售价|
|汇率|对应站点汇率|
|RMB 货值|采购成本|
|外币货值|汇率换算|
|包装尺寸|长宽高|
|泡重|体积重|
|实重|实际重量|
|计费重|泡重和实重取高|
|头程每公斤|货代报价|
|单件头程|计费重 × 单价|
|佣金比例|类目佣金|
|佣金金额|售价 × 佣金|
|VAT|欧洲站重点|
|FBA 配送费|收入计算器 / 费用表|
|仓储费|按尺寸和周期估算|
|广告占比|预估广告成本|
|Coupon 占比|优惠券成本|
|促销占比|折扣成本|
|折后销售额|实际成交价|
|销售成本|平台扣费 + 广告|
|回款额|折后销售额 - 销售成本|
|投入成本|货值 + 头程|
|毛利润|回款额 - 投入成本 - 杂费|
|ROI|投入产出|
|毛利率|毛利润 ÷ 售价|
|供应商|供应商信息|
|对标竞品|竞品链接|

---

## 3. 核心公式

**折后销售额 = 售价 - Coupon - 促销折扣**

**销售成本 = 佣金 + FBA 配送费 + VAT + 广告成本**

**回款额 = 折后销售额 - 销售成本**

**投入成本 = 产品货值 + 头程运费**

**毛利润 = 回款额 - 投入成本 - 仓储费等杂费**

**毛利率 = 毛利润 ÷ 售价**

---

## 4. 判断标准

|指标|建议标准|
|---|---|
|毛利率|最好 30% 以上|
|ROI|大于 1.7 可作为参考|
|广告后利润|不能长期为负|
|退货后净利|仍需可接受|
|低价促销后利润|不应严重亏损|
|首批综合净利|至少有清晰回本路径|

# 十、CPC 与广告承受力 SOP

## 1. 目标

判断产品能承受什么 CPC，避免盲目烧广告。

---

## 2. 核心公式

**最高可承受 CPC = 单件利润 × 广告转化率**

例如：

|单件利润|转化率|最高 CPC|
|--:|--:|--:|
|30 美金|10%|3 美金|
|30 美金|5%|1.5 美金|
|20 美金|10%|2 美金|
|20 美金|5%|1 美金|

---

## 3. 预算反推

假设：

1. 目标日销 3 单。
    
2. 单件利润 30 美金。
    
3. 平均 CPC 2 美金。
    
4. 目标盈亏平衡。
    

每日可承受广告预算：

**30 × 3 = 90 美金**

可获得点击：

**90 ÷ 2 = 45 次点击**

需要转化率：

**3 ÷ 45 = 6.67%**

结论：如果 Listing 转化率达不到 6.67%，该广告模型会亏损。

---

# 十一、批次盈亏 SOP

## 1. 目标

判断整批货最终赚不赚钱，而不是只看单件利润。

---

## 2. 批次盈亏字段

|模块|字段|
|---|---|
|基础信息|批次、站点、产品、汇率|
|发货信息|空运数量、海运数量、总库存|
|广告信息|日预算、月预算、推广天数、广告总支出|
|销售预测|日均销量、销售周期、销售额|
|站外|单次成本、次数、总支出|
|视频|单价、数量、总支出|
|评论与信任建设|Vine、合规评价获取成本|
|退货|退货率、退货量、退货处理费、弃置费|
|回款|批次销售回款额|
|利润|批次销售利润额|
|净利|批次净利润额|
|综合投入|货值、头程、广告、视频、站外、合规成本|

---

## 3. 决策标准

|批次结果|决策|
|---|---|
|净利润健康，排名上升|补货放量|
|微亏但关键词排名明显提升|可继续测试|
|销量增长但利润差|优化成本和广告|
|利润好但销量弱|加强推广和转化|
|持续亏损且无排名改善|停止加投|
|库存积压严重|清仓或重启链接|
|退货率高|暂停补货，排查产品问题|

## 3. 出价原则

|阶段|出价策略|

4. 消耗高但无订单词。

# 十四、推广节奏 SOP

## 第 1 周：上线与打标

### 目标

1. Listing 正常上线。
    
2. 广告开始获取曝光。
    
3. 检查关键词收录。
    
4. 初步获取点击数据。
    
5. 验证主图 CTR。
    

### 动作

1. 检查前台页面。
    
2. 检查标题、图片、价格、Coupon。
    
3. 开自动广告。
    
4. 开少量精准长尾词。
    
5. 检查广告是否正常曝光。
    
6. 检查关键词是否收录。
    
7. 每日记录曝光、点击、CPC、CTR。
    

### 判断

|数据表现|动作|
|---|---|

|曝光高点击低|优化主图、价格、Coupon|
|点击高无转化|检查页面承接和关键词相关性|
|CPC 过高|降出价，换长尾词|

### 目标

1. 找到有效搜索词。
    
2. 开始手动广告。
    
3. 否定无效词。
    
4. 控制预算浪费。
    

### 动作

1. 下载搜索词报告。
    
2. 有转化词加入精准广告。
    
3. 高点击无转化词降价或否定。
    
4. 不相关词加入否定。
    
5. 表现好广告组加预算。
    
6. 表现差广告组暂停或重组。
    

---

## 第 3 周：拓词与推排名

### 目标

1. 扩大有效流量。
    
2. 推动核心词排名。
    
3. 测试竞品流量。
    
4. 开始优化自然单占比。
    

### 动作

1. 增加长尾词广告。
    
2. 开 ASIN 投放。
    
3. 测试类目投放。
    
4. 对有转化词提高预算。
    
5. 观察核心词自然排名。
    
6. 根据转化数据调整 Coupon。
    

---

## 第 4 周：阶段复盘

### 目标

1. 判断新品是否值得继续推。
    
2. 判断是否补货。
    
3. 判断是否优化 Listing。

1. 曝光。
    
2. 点击。
    
3. CTR。

11. 星级。

13. BSR。

1. 放大有效广告。
    
2. 降低无效消耗。
    
3. 提高自然单。
    
4. 稳定排名。
    
5. 决定补货或止损。
    

### 动作

1. 高转化词加预算。
    
2. 低效词降价。
    
3. 优化图片和 A+。
    
4. 增加视频广告。
    
5. 适度做站外引流。
    
6. 观察 TACOS 是否下降。
    
7. 检查库存是否支撑放量。

### 目标

1. 降低广告依赖。
    
2. 提高自然订单占比。
    
3. 优化净利润。
    
4. 建立长期运营模型。
    

### 动作

1. 控制 ACOS。
    
2. 优化广告分层。
    
3. 保留盈利广告。
    
4. 下调亏损广告。
    
5. 优化价格。
    
6. 规划补货。
    
7. 判断是否拓展变体。
    
8. 判断是否开发周边产品。

# 十七、未达目标应急 SOP

## 1. 曝光不达标

### 可能原因

1. 关键词未收录。
    
2. 出价过低。
    
3. 类目不准确。
    
4. 广告预算太低。
    
5. Listing 权重低。
    

### 处理

1. 检查关键词收录。
    
2. 提高核心词出价。
    
3. 增加自动广告。
    
4. 调整类目节点。
    
5. 优化标题和 Search Terms。
    

---

## 2. 点击不达标

### 可能原因

1. 主图弱。
    
2. 价格高。
    
3. Coupon 不明显。
    
4. 标题缺乏吸引力。
    
5. Review 数太少。
    
6. 星级低。
    

### 处理

1. 更换主图。
    
2. 增加 Coupon。
    
3. 调整标题前半段。
    
4. 对比竞品价格。
    
5. 增强图片卖点。
    

---

## 3. 转化不达标

### 可能原因

1. 关键词不精准。
    
2. 副图没有打中痛点。
    
3. A+ 不充分。
    
4. Review 不足。
    
5. 价格无优势。
    
6. 产品卖点不清晰。
    

### 处理

1. 否定无关词。
    
2. 优化副图。
    
3. 增加 Q&A。
    
4. 优化 A+。
    
5. 调整价格或 Coupon。
    
6. 增加视频。
    

---

## 4. ACOS 过高

### 可能原因

1. CPC 高。
    
2. CVR 低。
    
3. 词太泛。
    
4. 预算分散。
    
5. 广告结构混乱。
    

### 处理

1. 降低泛词出价。
    
2. 提取转化词单独建组。
    
3. 否定无效词。
    
4. 暂停高花费无单广告。
    
5. 集中预算到高转化词。
    

---

## 5. 库存偏离预期

### 快断货

1. 降低广告预算。
    
2. 提高售价。
    
3. 减少 Coupon。
    
4. 空运补少量货。
    
5. 控制站外活动。
    

### 滞销

1. 增加 Coupon。
    
2. 做站外促销。
    
3. 降低价格。
    
4. 优化 Listing。
    
5. 清理低效广告。
    
6. 评估是否清仓。

# 十九、关键决策节点

## 节点 1：是否立项

必须满足：

1. 市场容量足够。
    
2. 垄断程度可接受。
    
3. 有明确细分机会。
    
4. 有可执行差异化。
    
5. 无明显专利和认证风险。
    
6. 初步利润可接受。
    

---

## 节点 2：是否发货

必须满足：

1. 样品质量通过。
    
2. 利润测算通过。
    
3. 批次盈亏可接受。
    
4. 认证资料准备好。
    
5. Listing 素材排期明确。
    
6. 首批库存数量合理。
    

---

## 节点 3：是否加大推广

必须满足：

1. CTR 达标。
    
2. CVR 有改善。
    
3. 有转化关键词。
    
4. ACOS 可控或排名明显提升。
    
5. 库存可支撑。
    
6. 退货和差评无异常。
    

---

## 节点 4：是否补货

必须满足：

1. 日销稳定。
    
2. 净利润健康。
    
3. 关键词排名上升。
    
4. 库存周转合理。
    
5. 退货率可接受。
    
6. 广告模型可持续。
    

---

## 节点 5：是否淘汰

出现以下情况应考虑淘汰：

1. 持续高 ACOS。
    
2. 转化长期低迷。
    
3. 退货率高。
    
4. 差评集中且难改良。
    
5. 利润被广告吃光。
    
6. 价格战严重。
    
7. 同质化加速。
    
8. 补货后无法回本。
    
9. 类目趋势下滑。
    
10. 存在合规或侵权风险。

# 二十一、精简执行口诀

这套 SOP 可以浓缩成一句话：

**先看市场，再拆类目；先看竞品，再找差异；先建词库，再算利润；先备链接，再开广告；先看数据，再做调整；先控库存，再决定补货。**

最终目标不是把一个新品“推上去”，而是建立一套可复制的判断体系：

**产品能不能做、该怎么做、要花多少钱、多久能回本、什么时候加投、什么时候止损，都必须有数据支撑。**
