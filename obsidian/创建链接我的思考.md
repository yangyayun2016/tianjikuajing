## 一、模型总体结构

采用**加权加法模型**，总分0-100分，分数越高代表该关键词越值得投入。

\[
Score = w_1 \cdot M + w_2 \cdot C + w_3 \cdot T + w_4 \cdot S
\]

- **M**：市场需求力 (0-100)  
- **C**：竞争环境力 (0-100)  → 注意：竞争越激烈分数越低  
- **T**：转化潜力 (0-100)  
- **S**：战略适配度 (0-100)  

默认权重（可自定义）：  
\[
w_1=0.30,\quad w_2=0.25,\quad w_3=0.25,\quad w_4=0.20
\]

## 二、各维度详细算法

### 1. 市场需求力 M（权重0.30）

| 子指标 | 权重 | 说明 | 数据来源 |
|--------|------|------|----------|
| 月搜索量 (SV) | 0.50 | 搜索量越大需求越强 | 亚马逊ABA / 第三方工具 |
| 搜索量趋势 (Trend) | 0.30 | 最近3个月增长率 | 时间序列分析（模块21） |
| 季节性韧性 (Season) | 0.20 | 是否全年平稳或旺季长 | 季节性模式分析（模块23） |

**计算步骤：**

- **SV标准化**：  
  取类目下所有关键词的月搜索量，按百分位映射到0-100分。  
  \[
  M_{SV} = \min\left(100, \frac{\log(SV+1)}{\log(SV_{max}+1)} \times 100\right)
  \]  
  或更简单：使用百分位排名 `PERCENTRANK(SV)` × 100。

- **趋势得分**：  
  计算近3个月搜索量变化率 \( r = (SV_{last} - SV_{first}) / SV_{first} \)  
  \[
  M_{Trend} = \begin{cases}
  50 + \min(50, r \times 100) & r > 0 \\
  50 + \max(-50, r \times 100) & r \le 0
  \end{cases}
  \]  
  即：增长10% → 60分；下降10% → 40分；上限100，下限0。

- **季节性韧性得分**：  
  - 无明显季节波动（CV < 0.2）：100分  
  - 有稳定旺季（如每年6-8月）：70分  
  - 只有单一短促高峰（如黑五）：40分  
  - 极端不稳定（断崖式）：10分  

\[
M = 0.5 \times M_{SV} + 0.3 \times M_{Trend} + 0.2 \times M_{Season}
\]

---

### 2. 竞争环境力 C（权重0.25）  
**注意**：本维度取值越高代表竞争越**不激烈**（越有利），因此需要对原始竞争指标做反向处理。

| 子指标 | 权重 | 说明 | 数据来源 |
|--------|------|------|----------|
| 关键词竞争得分 (CompScore) | 0.40 | 模块02，原始分0-100（越高越激烈），需取反 | 竞争力得分分布 |
| 品牌集中度 (BrandConc) | 0.30 | 前3品牌点击份额之和，越高越难进入 | 竞争格局地图（模块15） |
| 广告竞品密度 (AdDensity) | 0.30 | 搜索结果页广告位占比 + 竞品数量 | 竞争广告分析（模块30） |

**计算步骤：**

- **竞争得分取反**：  
  \[
  C_{Comp} = 100 - CompScore_{原始}
  \]  
  例如原始80分（激烈）→ 反向20分（不推荐）。

- **品牌集中度得分**：  
  \[
  C_{Brand} = \max(0, 100 - BrandConc \times 100)
  \]  
  若前3品牌集中度60%，则得40分。

- **广告竞品密度得分**：  
  统计搜索结果TOP20中广告ASIN数 \( N_{ad} \)  
  \[
  C_{Ad} = \max(0, 100 - N_{ad} \times 5)
  \]  
  若10个广告ASIN，得50分；超过20个则0分。

\[
C = 0.4 \times C_{Comp} + 0.3 \times C_{Brand} + 0.3 \times C_{Ad}
\]

---

### 3. 转化潜力 T（权重0.25）

| 子指标 | 权重 | 说明 | 数据来源 |
|--------|------|------|----------|
| 搜索意图得分 (Intent) | 0.50 | 购买意图越强分数越高 | 搜索意图分析（模块18） |
| 平均转化率预估 (CVR) | 0.30 | 类目/关键词的平均转化率 | 内部数据 / 行业基准 |
| 点击率吸引力 (CTR) | 0.20 | 搜索结果页点击分布 | 品牌分析 / 自身经验 |

**计算步骤：**

- **意图得分**：  
  - 购买型（buy now, for men, best）：100分  
  - 信息型（how to, why）：20分  
  - 导航型（brand name）: 40分  
  - 比较型（vs, or）：70分  
  可通过NLP分类器自动打分。

- **转化率预估**：  
  采用类目平均转化率基准，如：  
  \[
  T_{CVR} = \min(100, \frac{CVR_{keyword}}{CVR_{avg\_category}} \times 100)
  \]  
  但限制最大100分。

- **CTR吸引力**：  
  根据关键词的ABA点击份额排名，前10%得100分，10%-30%得70分，30%-50%得40分，50%以后得20分。

\[
T = 0.5 \times Intent + 0.3 \times T_{CVR} + 0.2 \times T_{CTR}
\]

---

### 4. 战略适配度 S（权重0.20）  
**军事思维重点**：是否符合自身“兵力”优势。

| 子指标 | 权重 | 说明 | 数据来源 |
|--------|------|------|----------|
| 产品相关性 (Relevance) | 0.50 | 关键词与自身产品的语义相似度 | 关键词特征分析（模块17）+ 卖家输入 |
| 利润空间 (Profit) | 0.30 | 扣除佣金、运费、PPC后的毛利率 | 财务模块 |
| 差异化机会 (Diff) | 0.20 | 是否存在未被竞品覆盖的属性词 | 竞争力矩阵（模块12）/ 特征分析 |

**计算步骤：**

- **相关性得分**：  
  由卖家在系统中对该关键词打标签（核心/相关/弱相关/无关）：  
  - 核心（产品主词）：100  
  - 相关（修饰属性）：70  
  - 弱相关（仅场景）：40  
  - 无关：0  
  也可用NLP计算词向量余弦相似度后映射。

- **利润空间得分**：  
  \[
  S_{Profit} = \min(100, \frac{\text{毛利率}}{50\%} \times 100)
  \]  
  毛利率30%得60分，50%以上满分。

- **差异化机会**：  
  若该关键词下TOP10商品中，缺失某个你自己的产品的独特卖点（如“防水”“可拆卸”），则得100分，否则得30分。

\[
S = 0.5 \times Relevance + 0.3 \times S_{Profit} + 0.2 \times Diff
\]

## 五、示例（洗澡类产品关键词）

假设关键词：**“shower head high pressure”**

- SV=12000，类目最大=50000 → M_SV= log(12001)/log(50001)*100 ≈ 82分  
- 趋势：增长15% → M_Trend=65分  
- 季节性平稳 → M_Season=90分  
**M=0.5*82+0.3*65+0.2*90=79.5分**

- 竞争得分原始70分 → C_Comp=30分  
- 品牌集中度45% → C_Brand=55分  
- 广告竞品数8 → C_Ad=60分  
**C=0.4*30+0.3*55+0.3*60=46.5分**

- 购买意图强 → Intent=100分  
- CVR预估8%（类目平均5%）→ T_CVR=100分（上限）  
- CTR吸引力属前20% → T_CTR=85分  
**T=0.5*100+0.3*100+0.2*85=97分**

- 产品完全相关 → Relevance=100分  
- 毛利率45% → S_Profit=90分  
- 差异化机会：高压是卖点但竞品都有 → Diff=30分  
**S=0.5*100+0.3*90+0.2*30=83分**

**综合得分** = 0.3*79.5 + 0.25*46.5 + 0.25*97 + 0.2*83  
= 23.85 + 11.625 + 24.25 + 16.6 = **76.325分 → A级**

## 一、意图类别定义（四类 + 可扩展）

| 类别 | 代码 | 典型特征 | 购买意图得分 | 示例 |
|------|------|----------|--------------|------|
| **导航型** | NAV | 包含品牌名/网站名，用户想找特定店铺 | 40 | `nike shoes`, `apple airpods`, `anker official` |
| **信息型** | INF | 疑问词、how to、why、区别、原理 | 20 | `how to clean shower head`, `what is aero press` |
| **比较型** | CMP | vs, or, 对比词，用户在做购买决策 | 70 | `iphone vs samsung`, `creatine or protein` |
| **交易型** | TRN | 直接购买意图、形容词（best, for men, cheap）、无修饰词 | 100 | `buy running shoes`, `best blender`, `shower head high pressure` |

> 购买意图得分可直接映射到打分模型中的 `Intent` 指标。

## 二、技术路线选择

考虑到你要搭建飞书SaaS系统，兼顾**实时性、准确性与可维护性**，我采用 **分层分类架构**：

```
输入关键词 → 规则引擎（快速命中） → 词典匹配 → 未命中 → 轻量级机器学习模型（FastText / 逻辑回归） → 输出类别 + 置信度
```

**优势**：  
- 规则保证常见词100%准确  
- 机器学习覆盖长尾、新词  
- 实际响应时间 < 50ms

## 三、规则引擎设计（优先级从高到低）

### 规则1：品牌导航词识别
维护一个品牌词表（可从亚马逊品牌分析中自动抽取Top 500品牌）。  
若关键词包含品牌名，且排除以下情况（品牌+购买词仍归为交易型），则判为NAV。

```python
# 例外：品牌 + 购买修饰词 → 仍归为交易型
if brand in keyword and any(buy_word in keyword for buy_word in ['buy', 'deal', 'sale', 'cheap']):
    return 'TRN'
else:
    return 'NAV'
```

### 规则2：信息型疑问词匹配
若包含以下词根 → INF：  
`how, what, why, when, where, which, who, guide, tutorial, instructions, difference between, vs (单独出现时视为比较型)`

### 规则3：比较型关键词匹配
若包含以下模式 → CMP：  
`vs, versus, or, compared to, versus, better than, alternative to`

### 规则4：交易型强信号
若包含以下购买词 → TRN：  
`buy, purchase, deal, coupon, cheap, discount, best, top, review (但review单独出现且无产品词时可能是信息型), for men, for women, for kids, under $50, high quality`  

同时，**纯产品词**（无任何疑问/比较/品牌，如 `shower head`）也判为TRN。

### 规则5：默认兜底
若以上均未命中 → 使用机器学习模型预测。

## 五、整体分类流程（Python伪代码）

```python
class SearchIntentClassifier:
    def __init__(self):
        self.brand_set = load_brands()          # 预加载品牌词表
        self.buy_signals = ['buy','purchase','deal','cheap','best','top']
        self.info_signals = ['how','what','why','guide','tutorial']
        self.compare_signals = ['vs','versus','or','compared','better than']
        # 加载训练好的 FastText 模型
        self.model = fasttext.load_model('intent_model.bin')
    
    def classify(self, keyword):
        kw = keyword.lower().strip()
        # 规则层
        # 1. 导航型
        for brand in self.brand_set:
            if brand in kw:
                if any(sig in kw for sig in self.buy_signals):
                    return 'TRN', 1.0
                else:
                    return 'NAV', 1.0
        # 2. 信息型
        if any(sig in kw for sig in self.info_signals):
            return 'INF', 1.0
        # 3. 比较型
        if any(sig in kw for sig in self.compare_signals):
            return 'CMP', 1.0
        # 4. 强交易型信号
        if any(sig in kw for sig in self.buy_signals):
            return 'TRN', 1.0
        # 5. 纯产品词：无任何修饰且长度适中 -> 交易型
        if len(kw.split()) <= 4 and not any(sig in kw for sig in ['how','vs','brand']):
            return 'TRN', 0.9
        
        # 机器学习层
        pred_label, prob = self.model.predict(kw)
        return pred_label[0][9:], prob[0]   # 去除 __label__ 前缀
```

## 模块04：市场演化时间线分析

### 4.1 核心定义
追踪目标市场在过去一段时间（如12个月）内的结构性变化，包括价格带漂移、品牌更替、新品渗透等，用于判断市场是走向集中还是分散，是升级还是降级。

### 4.2 分析维度
- 价格演化：均价、价格带分布的变化趋势
- 品牌演化：Top5品牌份额变化、新品牌进入速度
- 产品演化：功能词（如“智能”“可调压”）出现频率变化
- 新品成功率：新ASIN进入Top100的比例随时间变化

### 4.3 关键指标
- 价格移动平均（MA3）
- 品牌集中度变化率（ΔHHI）
- 新品存活率（上架90天后仍在Top100的比例）

### 4.4 算法逻辑
```python
# 按月聚合数据
monthly_avg_price = df[df.month == m].price.mean()
price_moving_average = monthly_avg_price.rolling(3).mean()

# 品牌集中度：HHI = sum(share_i^2)
HHI_change = (HHI_current - HHI_prev) / HHI_prev

# 新品存活率
survival_rate = (new_asins_still_in_top100 / total_new_asins_launched_90d_ago)
```

### 4.5 数据来源
- ABA历史搜索词报告（按月）
- 产品数据库（ASIN价格、上架日期）
- 品牌分析报告

### 4.6 战术价值
- 若价格上升且品牌集中度下降 → 市场扩容机会
- 若价格下降且新品存活率低 → 价格战红海，谨慎进入
- 识别“品类升级”拐点（如从普通花洒转向高压花洒）

### 4.7 SaaS集成
- 时间轴滑块，可拖动查看任意时间段
- 自动标注关键事件（如旺季、竞品大促）

### 5.4 算法逻辑

```python
# 词云数据准备
word_cloud_data = keywords[['keyword', 'search_volume']].copy()
# 可选：去除停用词、品牌词单独标注颜色

# 突现词检测（基于时间序列的z-score）
def burst_score(ts):
    mean = ts.rolling(90).mean()
    std = ts.rolling(90).std()
    return (ts.iloc[-1] - mean.iloc[-1]) / std.iloc[-1]
```

## 模块06：排名变化分析

### 6.1 核心定义
监控特定关键词下TOP20商品的排名变化情况，识别排名波动剧烈的关键词和稳定霸榜的商品。

### 6.2 分析维度
- 稳定性：排名变化的标准差
- 变动幅度：最大上升/下降名次
- 波动频率：单位时间内排名变化的次数

### 6.3 关键指标
- 排名波动指数（Rank Volatility Index, RVI）
- 平均排名变化绝对值（Mean Absolute Change, MAC）

### 6.4 算法逻辑
```python
# 对每个关键词，计算其下ASIN排名的日变化
daily_rank_changes = df.groupby(['keyword', 'asin'])['rank'].diff().abs()
RVI = daily_rank_changes.mean()  # 值越大，该关键词下排名越不稳定
MAC = daily_rank_changes.abs().mean()
```

### 6.5 数据来源
- 每日SERP快照（爬虫或API）
- 排名追踪工具数据

### 6.6 战术价值
- 高RVI关键词 → 容易通过短期操作（如降价、增加广告）快速提升排名
- 低RVI关键词 → 头部壁垒高，需长期投入

### 6.7 SaaS集成
- 折线图展示关键词下Top3 ASIN的排名轨迹
- 预警：当关键词RVI超过阈值时触发通知

## 模块08：智能排名热力图

### 8.1 核心定义
以热力图形式展示不同关键词下不同排名区间的竞争强度。横轴为关键词，纵轴为排名区间，颜色深浅代表该位置被点击或竞品占据的密度。

### 8.2 分析维度
- 关键词维度：长尾词vs大词
- 排名区间：1-3, 4-10, 11-20, 21-50等
- 竞争强度：点击份额或广告出价密度

### 8.3 关键指标
- 每个(关键词, 排名区间)的点击份额之和
- 或广告出价中位数

### 8.4 算法逻辑

## 模块20：关键词语义聚类分析

### 20.1 核心定义
利用NLP技术（词向量或BERT）将关键词自动分组到语义相似的簇中，每个簇代表一个“主题”或“细分需求”。例如“shower head high pressure”和“strong flow shower head”属于同一簇。

### 20.2 分析维度
- 簇大小：包含关键词数量
- 簇内平均搜索量
- 簇内平均竞争度
- 簇代表性词（距离中心最近的词）

### 20.3 关键指标
- 聚类数（由轮廓系数或肘部法则确定）
- 簇间平均距离
- 簇纯度（若有人工标签）

### 20.4 算法逻辑
```python
from sentence_transformers import SentenceTransformer
from sklearn.cluster import HDBSCAN

model = SentenceTransformer('all-MiniLM-L6-v2')
embeddings = model.encode(keywords)
clusterer = HDBSCAN(min_cluster_size=5, metric='euclidean')
clusters = clusterer.fit_predict(embeddings)

# 获取每个簇的代表词
representative_keywords = []
for cluster_id in set(clusters):
    if cluster_id == -1: continue
    cluster_indices = np.where(clusters == cluster_id)[0]
    cluster_embs = embeddings[cluster_indices]
    center = cluster_embs.mean(axis=0)
    distances = np.linalg.norm(cluster_embs - center, axis=1)
    rep_idx = cluster_indices[np.argmin(distances)]
    representative_keywords.append(keywords[rep_idx])
```

- 关键词列表（可来源于ABA搜索词报告）

### 20.6 战术价值

- 发现未被充分覆盖的需求主题（簇平均竞争度低但搜索量高）

### 21.1 核心定义

### 21.4 算法逻辑

## 模块24：战略优先级矩阵分析

### 24.1 核心定义
结合“战略重要性”（如与核心产品相关性、利润贡献潜力）和“行动紧迫性”（如排名下降速度、竞品逼近速度）两个维度，将关键词或ASIN划分到四个优先级象限：立即行动、计划行动、监控、低优先级。

### 24.2 分析维度
- X轴：战略重要性（综合得分中的战略维度S，或自定义）
- Y轴：行动紧迫性（排名下降速度、竞品广告覆盖率变化）

### 24.3 关键指标
- 战略重要性得分（0-100）
- 紧迫性得分（0-100）：排名下降速率（正数越大会员紧迫）+ 竞品广告新增数量

### 24.4 算法逻辑
```python
urgency = 0.6 * rank_decline_rate + 0.4 * new_ad_competitors
# rank_decline_rate: 过去7天排名下降名次/7（上限30）
# new_ad_competitors: 过去7天新增广告竞品数量（上限10）

# 标准化
urgency_norm = min(100, urgency / 30 * 100)  # 假设最大下降30名

# 四象限
if importance >= 70 and urgency_norm >= 70:
    priority = '立即行动'
elif importance >= 70 and urgency_norm < 70:
    priority = '计划行动'
elif importance < 70 and urgency_norm >= 70:
    priority = '监控'
else:
    priority = '低优先级'
```

### 24.6 战术价值
- 立即行动区：核心产品的主关键词排名在掉 → 立即增加广告或降价
- 计划行动区：高重要性但稳定 → 按计划优化Listing

## 模块25：风险机会矩阵分析（威胁/竞争劣势分析）

### 25.1 核心定义
评估每个关键词或细分市场的风险（竞争加剧、排名下滑风险）和机会（增长潜力、差异化空间），形成风险-机会矩阵，用于制定风险对冲和机会捕捉策略。

### 25.2 分析维度
- 风险得分：竞争得分上升速度、自身排名波动性、广告CPC涨幅
- 机会得分：搜索量增长率、新品成功率、价格上升空间

### 25.3 关键指标
- 风险得分 = 0.4*comp_increase_rate + 0.3*rank_volatility + 0.3*cpc_growth_rate
- 机会得分 = 0.4*search_growth + 0.3*new_product_success_rate + 0.3*price_margin_expansion

### 25.4 算法逻辑
```python
# 所有指标先标准化到0-100
risk = (comp_increase_norm + rank_volatility_norm + cpc_growth_norm) / 3
opportunity = (search_growth_norm + new_success_norm + margin_expansion_norm) / 3

# 矩阵四象限
if risk >= 60 and opportunity >= 60:
    strategy = '双高：积极应对，抓住机会同时控制风险（如加大投入但监控CPC）'
elif risk >= 60 and opportunity < 60:
    strategy = '高风险低机会：考虑收缩或退出'
elif risk < 60 and opportunity >= 60:
    strategy = '低风险高机会：全力投入，抢占先机'
else:
    strategy = '双低：维持现状或观察'
```

### 25.5 数据来源
- 竞争得分历史（模块02）
- 排名波动（模块06）
- CPC趋势（广告报告）
- 搜索增长（模块21）
- 新品成功率（模块04）

### 25.6 战术价值
- 风险矩阵是军事思维中“避实”的量化工具
- 机会矩阵是“击虚”的依据
- 双高区域需谨慎评估自身资源

### 25.7 SaaS集成

## 模块27：行动优先级分析

### 27.1 核心定义
基于“影响程度”（对总业绩的贡献潜力）和“实施难度”（所需时间、成本、资源）两个维度，对可能的行动项（如优化某个关键词的Listing、增加广告预算、改进产品主图）进行排序，输出高性价比行动清单。

### 27.2 分析维度
- 影响程度：预估提升ROI或销售额的百分比
- 实施难度：所需人力工时、外部成本、风险等级

### 27.3 关键指标
- 影响得分（1-10）
- 难度得分（1-10，分数越高越难）
- 优先级得分 = 影响得分 / 难度得分

### 27.4 算法逻辑
```python
actions = [
    {'name':'优化A关键词的标题', 'impact':6, 'effort':2, 'cost':0},
    {'name':'为B关键词增加1000美元预算', 'impact':8, 'effort':1, 'cost':1000},
    ...
]
for a in actions:
    a['priority_score'] = a['impact'] / (a['effort'] + a['cost']/500)  # 考虑成本
sorted_actions = sorted(actions, key=lambda x: x['priority_score'], reverse=True)
```

## 模块28：投资回报率分析（ROI）

### 28.1 核心定义
对每个关键词或广告活动，计算投资回报率（ROI = （销售额 - 成本）/ 成本），并分解影响ROI的因素（CPC、转化率、客单价等），指导优化方向。

### 28.2 分析维度
- 广告ROI（仅计算广告花费）
- 综合ROI（包含运营成本、PPC、优惠券等）
- 边际ROI（增加1美元预算能带来多少额外利润）

### 28.3 关键指标
- ROI（%）
- ROAS（广告花费回报）
- 盈亏平衡CPC

### 28.4 算法逻辑
```python
# ROI计算
total_sales = keyword_orders * avg_price
ad_cost = keyword_clicks * avg_cpc
other_cost = product_cost + shipping + coupon  # 来自财务模块
total_cost = ad_cost + other_cost
ROI = (total_sales - total_cost) / total_cost

# 盈亏平衡CPC
avg_conversion_rate = keyword_orders / keyword_clicks
avg_margin_per_order = avg_price - product_cost - shipping
break_even_cpc = avg_conversion_rate * avg_margin_per_order
```

### 28.5 数据来源
- 广告报告（花费、点击、订单）
- 财务模块（产品成本、运费、毛利率）

### 28.6 战术价值
- 识别ROI为负的关键词，暂停或降低出价
- 对高ROI关键词增加预算
- 计算出价上限，避免盲目竞价

### 28.7 SaaS集成
- 自动计算每个关键词的ROI，并排序展示
- ROI趋势图（周/月）
- 设置ROI预警（如低于0%时发送通知）

## 模块29：竞争格局分析（市场/流量竞争格局分析）

### 29.1 核心定义

### 29.2 分析维度

- 品牌搜索流量占比 vs 非品牌搜索占比
- 头部品牌流量来源结构（它们更依赖广告还是自然）

### 29.3 关键指标
- 各流量渠道占比（%）
- 品牌搜索比例（反映品牌认知度）
- 自然排名进入前3的关键词数量

### 29.4 算法逻辑
```python
# 估算品牌流量来源（基于ABA）
brand_traffic = df[df.keyword.str.contains(brand_name)]['click_share'].sum()
total_traffic = df['click_share'].sum()
brand_search_ratio = brand_traffic / total_traffic

# 广告依赖度 = 广告流量 / 总流量
ad_dependency = sum(df[df.is_ad]['click_share']) / total_traffic
```

### 29.5 数据来源

- 如果市场高度依赖广告（ad_dependency > 50%），则进入门槛低但需要持续烧钱

## 模块30：竞争广告分析

### 30.1 核心定义

- 广告位变化：某竞品是否在特定关键词上持续占据首位广告位
- 广告活动新鲜度：新广告词出现的频率

### 30.3 关键指标
- 广告密度（广告ASIN数/总ASIN数）
- 竞品广告词重叠率 = (共同关键词数 / 自身关键词数)
- 广告占据首位时长（小时/天）

### 30.4 算法逻辑
```python
# 广告密度
ad_density = df[df.is_ad].shape[0] / df.shape[0]

# 竞品广告词重叠
self_keywords = set(keywords_self_ad)
competitor_keywords = set(keywords_comp_ad)
overlap_rate = len(self_keywords & competitor_keywords) / len(self_keywords)

# 检测新进入的竞品广告词
new_ad_keywords = current_comp_ads - historical_comp_ads
```

- 每日SERP快照（标注广告位）
- 广告API（如果有权限）

### 30.6 战术价值
- 广告密度高的关键词 → 避免盲目提价，可转向差异化词
- 重叠率高的竞品 → 考虑否词或调整匹配方式

### 30.7 SaaS集成

- 监控自身与指定竞品的重叠率变化曲线
- 当竞品在核心关键词上新增广告时，发送实时预警

下面这版可以作为你后续 **亚马逊关键词打标系统 V2：SIF价值打法版** 的核心路径和逻辑算法。

核心思想先定下来：

> **关键词不是投放核心，消费者需求才是投放核心。**  
> 关键词只是消费者需求的外显表达；打标的目的不是把词分好类，而是把“需求”识别出来，再用自己的产品供给去匹配需求，最后形成广告、Listing、视觉、选品的统一打法。

这和你上传的 SIF 价值打法文件里的逻辑一致：文件中明确强调“投放广告的核心不是关键词，而是具体的消费者需求”；同时提出要先搭建词库、通过词频统计整理需求分类，再用产品卖点反向匹配需求，并以消费者需求为中心搭建广告框架。

```text
→ 需求分类
→ 需求大小评估
→ 产品供给匹配
→ 价值点验证
→ 广告结构搭建
→ 投放词与匹配模式规划
→ 按搜索量集中度拆分广告活动
→ 数据回流
→ Listing / 视觉 / 产品 / 广告迭代
```

一句话：

> **先从关键词里还原需求，再用产品卖点匹配需求，最后围绕已验证需求放大流量。**

# 二、第一步：搭建词库，收集消费者需求

这一阶段不是简单收集关键词，而是收集 **目标市场里的需求表达**。

## 1. 词库来源

建议至少包含：

|数据来源|作用|

|站外热词|趋势、审美、情绪、流行元素|
|自己产品卖点|后续供给匹配用|

SIF 文件里第一步就是“搭建词库（收集消费者需求）”，并强调词库本质上代表目标市场。

|是否有效词|有效 / 低相关 / 剔除|

# 三、第二步：通过词频统计整理消费者需求分类

这一步是 SIF 价值打法的关键：  
**不要先按广告活动分词，而是先按消费者需求分词。**

文件第 18 页的核心就是：通过词频统计整理消费者需求分类，例如人群、颜色、尺寸、主题元素、品牌、节日、其他需求等。

---

## 1. TF 是什么？

你提到的 TF，完整叫：

> **TF / Term Frequency / 词频**

在关键词打标里，TF 可以理解为：

> 某个词根、元素、属性、需求点，在整个关键词词库中出现的频率。

例如 hair clips 词库里：

```text
claw clips for thick hair
large claw clips
matte claw clips
small claw clips
flower claw clips
```

其中：

- claw 出现 5 次
    
- clips 出现 5 次
    
- thick hair 出现 1 次
    
- large 出现 1 次
    
- matte 出现 1 次
    
- flower 出现 1 次
    

这就是基础词频。

---

## 2. 词频分两种

你这里建议做两套词频。

## A. 出现次数词频

公式：

```text
出现次数词频 TF_count(t) =
包含某个词 / 标签 t 的关键词数量
```

例如：

|词|出现关键词数|
|---|---|
|claw|120|
|thick hair|36|
|matte|18|
|flower|12|

它回答的是：

> 这个需求在词库里被提到了多少次？

---

## B. 搜索量加权词频

只看出现次数不够，因为有些词出现少，但搜索量很大。

公式：

```text
搜索量加权词频 TF_weighted(t) =
Σ 关键词搜索量 × 是否包含标签 t
```

如果没有搜索量，只有 ABA 排名，可以用排名权重替代：

```text
ABA权重 = 1 / ln(ABA排名 + 1)
```

然后：

```text
搜索量加权词频 =
Σ ABA权重 × 是否包含标签 t
```

它回答的是：

> 这个需求背后有多大的真实搜索需求？

---

## 3. 词频统计表字段

建议生成一张 **消费者需求词频表**：

|字段|说明|
|---|---|
|词根/元素|thick hair / claw / flower / black|
|中文翻译|厚发 / 抓夹 / 花朵 / 黑色|
|搜索需求分类|目标受众 / 功能特征 / 风格款式 / 颜色|
|出现次数词频|出现次数|
|出现次数占比|出现次数 / 总关键词数|
|搜索量加权词频|按搜索量或 ABA 权重加权|
|搜索需求占比|该词加权搜索量 / 总加权搜索量|
|代表关键词|典型关键词|
|相关产品卖点|自己产品是否能承接|
|是否适合投放|是 / 否 / 待验证|
|备注|侵权、低相关、季节性等|

# 五、第三步：用自己产品卖点反向匹配市场需求

这一步是 **价值打法的核心算法**。

SIF 文件第 19 页明确讲的是：用自己产品的卖点，也就是供给，反向匹配市场需求，并评估需求大小。

也就是说：

> 不是市场有什么词就全部打，而是先判断：  
> 这个需求，我的产品能不能满足？  
> 满足得强不强？  
> 这个需求大不大？  
> 竞争强不强？  
> 值不值得投？

---

## 1. 建立“供给卖点表”

以 hair clips 为例：

|自己产品卖点|对应需求分类|可承接关键词|
|---|---|---|
|大号抓夹|尺寸大小|large claw clips|
|强抓力|功能特征|strong hold hair clips|
|适合厚发|目标受众/发质需求|claw clips for thick hair|
|哑光质感|风格款式/外观|matte claw clips|
|花朵造型|主题元素|flower hair clips|
|多件套|参数/套装|hair clips pack|
|女孩可用|目标受众|hair clips for girls|
|婚礼造型|使用场景|wedding hair clips|

---

## 2. 供给匹配评分

建议用 0-1-3 颗粒度：

|分值|含义|示例|
|---|---|---|
|0|无法满足|用户搜 metal clip，但产品是塑料|
|1|弱满足/间接满足|用户搜 thick hair，产品可用但无强抓力设计|
|3|强满足/核心卖点|产品主打 strong hold for thick hair|

公式：

```text
供给匹配分 Supply Fit =
0 / 1 / 3
```

---

## 3. 需求价值评分

建议综合：

```text
需求价值分 =
搜索需求强度 × 供给匹配分 × 转化潜力 × 利润可行性 × 竞争修正
```

第一版可以简化为：

```text
Value Score =
需求分 × 0.4
+ 供给匹配分 × 0.3
+ 评论痛点强度 × 0.15
+ 转化信号 × 0.1
+ 利润/可做性 × 0.05
```

其中：

```text
需求分 =
搜索量加权词频 × 0.7
+ 出现次数词频 × 0.3
```

# 六、评论分析如何并入需求判断

评论不是单独看的，它要和关键词需求打通。

## 评论打标维度

|评论内容|标签类型|作用|
|---|---|---|
|“doesn’t hold thick hair”|痛点|厚发抓力不足|
|“too small”|尺寸痛点|需要 large/jumbo|
|“cute design”|情绪/风格|可爱外观被认可|
|“breaks easily”|质量痛点|耐用性机会|
|“great for wedding”|场景|婚礼使用场景|
|“my daughter loves it”|人群/情感|女孩/亲子购买|

评论分析要输出三类结果：

```text
1. 已验证价值：用户明确满意的点
2. 未满足需求：用户抱怨但竞品没解决的点
3. 情绪需求：用户为什么喜欢或讨厌
```

然后反向补到关键词标签里。

例如：

```text
关键词：claw clips for thick hair
评论痛点：doesn’t hold thick hair
自己卖点：strong hold
最终判断：高价值需求词，适合主推
```

# 七、第四步：以消费者需求为中心搭建广告框架

SIF 文件第 20 页讲的是：以消费者需求为中心搭建广告框架，而不是以关键词本身为中心。

广告结构应该从：

```text
关键词 → 广告活动
```

升级为：

```text
需求点 → 广告活动 → 广告组 → 关键词 → 匹配模式
```

---

## 广告结构模板

```text
产品组合 / Portfolio
  └── 需求大类 Campaign
        └── 需求细分 Ad Group
              └── 关键词 Keyword
                    └── 匹配模式 Match Type
```

例如 hair clips：

```text
Campaign 1：厚发强抓力需求
  Ad Group 1：claw clips for thick hair
  Ad Group 2：large claw clips
  Ad Group 3：strong hold hair clips

Campaign 2：造型风格需求
  Ad Group 1：flower hair clips
  Ad Group 2：butterfly hair clips
  Ad Group 3：y2k hair clips

Campaign 3：人群需求
  Ad Group 1：hair clips for girls
  Ad Group 2：baby hair clips
  Ad Group 3：toddler hair clips

Campaign 4：场景需求
  Ad Group 1：wedding hair clips
  Ad Group 2：party hair clips
  Ad Group 3：school hair clips
```

# 八、第五步：整理需求点对应关键词，规划投放词和匹配模式

SIF 文件第 21 页强调：整理需求点对应的关键词，并规划投放词和匹配模式。

## 匹配模式建议

|需求状态|关键词类型|匹配模式|目的|
|---|---|---|---|
|高需求 + 高匹配|核心转化词|Exact 精准|价值验证/控转化|
|中高需求 + 长尾|场景/人群/功能词|Phrase 词组|拓展精准流量|
|需求不确定|宽泛需求词|Broad 广泛|探索新搜索词|
|已验证价值点|大词/核心词|Exact + Phrase|放量|
|竞品强相关|竞品 ASIN / 品牌词|商品投放|抢竞品流量|
|未知需求|自动广告|Close/Substitutes|挖词和语义扩展|

---

## 关键词投放分层

|层级|关键词类型|示例|投放动作|
|---|---|---|---|
|S 层|高需求高匹配核心词|claw clips for thick hair|精准投放，单独预算|
|A 层|高机会长尾词|matte large claw clips|词组/精准测试|
|B 层|中机会探索词|cute hair clips|词组/广泛|
|C 层|低相关或不确定词|salon tools|小预算探索|
|R 层|风险词|IP/授权/竞品商标|谨慎或否定|

# 九、第六步：按搜索量集中度拆分广告活动

SIF 文件第 22 页提到：如果同一个价值点下某些关键词搜索量过大，为了防止流量过于集中，可以把大的卖点词单独拆出来做一个广告活动，也就是类似 SKAG；但最终评估时，要把同一价值点下的数据合并评估。

---

## 搜索量集中度算法

对每一个需求点，计算：

```text
单词搜索占比 =
某关键词搜索量 / 该需求点总搜索量
```

```text
Top3 搜索集中度 =
该需求点下 Top3 关键词搜索量 / 该需求点总搜索量
```

---

## 拆分规则

|情况|操作|
|---|---|
|单个关键词占比 ≥ 30%|单独 Campaign / SKAG|
|Top3 关键词占比 ≥ 60%|Top3 单独拆组|
|搜索量分散|按需求主题合并广告组|
|词量少但转化强|Exact 小预算验证|
|搜索量大但供给弱|谨慎测试，不主推|
|搜索量小但评论痛点强|长尾精准测试|

---

## 示例

需求点：厚发强抓力

|关键词|搜索量占比|操作|
|---|--:|---|
|claw clips for thick hair|42%|单独 Campaign|
|large claw clips|22%|单独 Ad Group|
|strong hold hair clips|12%|合并测试|
|hair clips for thick hair|10%|合并测试|
|jumbo claw clips|8%|合并测试|

最终评估时，不只看单个词，而是看整个需求点：

```text
厚发强抓力需求整体表现 =
所有 thick hair / strong hold / large claw clips 相关广告数据合并评估
```

# 十、价值验证路径

SIF 文件第 23 页提出：价值打法始于关键词，但不止于关键词；先做价值验证，再基于已验证价值做流量拓展，最后做流量泛化。

可以整理成三阶段。

---

## 阶段 1：价值验证

目标：

> 验证这个需求点是否真的能为你的产品带来点击和转化。

操作：

```text
关键词投放：
- Exact 精准
- Phrase 词组

预算：
- 小预算
- 控制变量
- 按需求点分组
```

核心指标：

|指标|判断|
|---|---|
|CTR|用户是否被吸引|
|CVR|产品是否满足需求|
|CPC|流量成本|
|ACOS|盈利可行性|
|Search Term|是否拓展出相似需求|

---

## 阶段 2：基于已验证价值的流量拓展

当某个需求点验证成功后，再扩展：

```text
搜索页投放：
- 关键词精准
- 关键词词组

商品详情页投放：
- 目标 ASIN
- 高度相似竞品
- 已验证流量来源 ASIN
```

例如：

```text
已验证价值点：thick hair strong hold
拓展方向：
- claw clips for thick hair
- large claw clips
- jumbo claw clips
- strong hold hair clips
- 竞品 ASIN 商品投放
```

---

## 阶段 3：流量泛化

目标：

> 不是只吃一个关键词，而是把需求点扩展成更大的流量池。

操作：

```text
- Broad 广泛匹配
- 自动广告
- 商品投放扩展
- 类目投放
- 相似竞品投放
- Listing 文案强化
- 主图/A+强化需求表达
```

---

# 十一、关键词打标最终算法

可以把整个系统算法写成这样。

## 输入数据

```text
Keyword_i:
- keyword
- search_volume 或 ABA_rank
- click_share
- conversion_share
- source
- category
- related_asin
```

## Step 1：关键词清洗

```text
normalize(keyword):
  小写化
  去符号
  单复数归一
  同义词归一
  品牌词识别
  IP词识别
  无效词过滤
```

---

## Step 2：需求元素抽取

```text
extract_elements(keyword):
  提取品类词
  提取人群词
  提取场景词
  提取功能词
  提取风格词
  提取颜色词
  提取材质词
  提取尺寸词
  提取主题元素词
  提取品牌词
  提取节日/季节词
```

---

## Step 3：需求分类打标

```text
for each element:
  match tag_dictionary
  assign demand_category
```

输出：

```text
关键词 = claw clips for thick hair

标签：
品类名称 = claw clips
目标受众/发质 = thick hair
功能特征 = strong hold 隐含需求
购买意图 = 精准需求词
```

---

## Step 4：词频统计

```text
TF_count(tag) =
Σ 是否出现 tag
```

```text
TF_weighted(tag) =
Σ keyword_weight_i × 是否出现 tag
```

如果有搜索量：

```text
keyword_weight_i = search_volume_i
```

如果只有 ABA 排名：

```text
keyword_weight_i = 1 / ln(ABA_rank_i + 1)
```

---

## Step 5：需求强度评分

```text
Demand Score =
标准化搜索量加权词频 × 0.6
+ 标准化出现次数词频 × 0.25
+ 转化信号 × 0.15
```

转化信号可以来自：

```text
ABA购买份额
广告CVR
广告订单数
评论正向提及
```

---

## Step 6：供给匹配评分

```text
Supply Fit =
3：强匹配，是产品核心卖点
1：弱匹配，产品可以承接但不是核心优势
0：不匹配，产品无法满足
```

---

## Step 7：价值机会评分

```text
Value Opportunity Score =
Demand Score × 0.4
+ Supply Fit × 0.3
+ Review Pain Gap × 0.15
+ Competition Advantage × 0.1
+ Profit Feasibility × 0.05
```

---

## Step 8：广告动作判断

```text
if Demand高 and SupplyFit=3:
    S级核心价值词，Exact + Phrase，独立预算

if Demand中高 and SupplyFit=3:
    A级长尾机会词，Phrase + Exact测试

if Demand高 and SupplyFit=1:
    B级谨慎测试，先小预算验证

if Demand低 and SupplyFit=3:
    C级低量精准词，适合Listing收录/低预算

if SupplyFit=0:
    不主推，可否定或仅观察

if IP/品牌风险:
    风险词，谨慎投放或剔除
```

# 十三、核心总结

SIF 价值打法下，亚马逊关键词打标的最新路径不是：

```text
收集关键词 → 分类 → 投广告
```

而是：

```text
收集关键词
→ 还原消费者需求
→ 用词频判断需求大小
→ 用产品卖点判断供给匹配
→ 用评论验证痛点和价值
→ 按需求点搭建广告结构
→ 按搜索量集中度拆分广告活动
→ 用广告数据验证价值
→ 把已验证价值迁移到关键词、商品投放、自动广告、Listing、视觉和产品开发
```

最终公式可以记成一句话：

```text
关键词价值 =
消费者需求强度 × 产品供给匹配度 × 广告验证结果 × 可规模化程度
```

也就是：

> **始于关键词，落到需求；始于投放，回到产品价值。**
