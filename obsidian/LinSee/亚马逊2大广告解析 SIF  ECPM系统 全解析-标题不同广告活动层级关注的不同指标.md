广告：曝光量(E)，点击量(C)，点击竞价(B)，广告订单量(O)，单价(P)，利润率(R)

CPC的扣费原理是什么?  你的CPC=下一位的Ad Rank/你的质量得分+0.01=(下一位的Bid*下一位的质量得分)/你的质量得分+0.01, （货币单位是: 本地货币, 美国-美金，欧洲-欧元,英国-英镑）

  

点付花费：CPC=花费/点击量  

1.每点击一次的广告花费  

2.在保障有曝光量和点击量的前提下，尽可能的控制出价  

3.热门产品CPC高

4.CPA每一个广告订单的成本，=广告花费/广告订单

  

曝光量：

1.曝光量即是流量，展现次数    

2.设置了推荐竞价，在产品没问题的情况下，一般会有曝光        

3.曝光量不是越高越好，所对应的流量点击率越高越好

  

点击量：

1.点击率=点击量/曝光量    

2.点击率高代表找到的流量对产品越感兴趣    

3.点击率高如果Acos和转化率也很好，则获取到了优质的用户    

4.点击率高如果Acos和转化率不好，则代表listing有明显的缺陷:主图和内容不符/受众与产品定位不符，则需要重点调整

  

订单量:

Acos=花费/收入    (广告花费/广告销售额)

1.核心考核指标，花出去的钱带来的多少回报（需要考虑广告ROI ,广告花费占比，毛利率与CPA）    

2.点击未带来订单成交，投入产出比接近0      

3.客单价高的产品，成交量少，但因为收入高，Acos指标也会很好

4.转化率英文全称Conversion Rate，即转化率。计算公式为:广告订单量/点击量=O/C

  

点击率(点击通过率)英文全称Click Through Rate，即点击通过率，是亚马逊站内广告曝光量与买家广告点击的比例。计算公式为:点击量/曝光量=C/E

  

投资回报率英文全称Return on investment,即投资回报率，是广告投放效果回报和成本投入比，通常来说，这个值越高越好。计算公式为:广告订单利润/广告投资总额=(广告订单量*单价*利润率)/(点击量*点击竞价)=(O*P*R)/(C*B)

  

广告支出回报率英文全称Return on ad spend，即广告支出回报率，是广告销售收入与亚马逊站内广告的花费的比例，是ACOS的倒数，通常来说，这个值越高越好。计算公式为:广告销售额/广告花费=(广告订单量*单价)/(点击量*点击竞价)=O*P/C*B

自动投放控制功能

1.紧密匹配(Close match)

买家使用与您的商品紧密相关的搜索词进行搜索时，亚马逊会向其显示您的广告。(基于关键词)

2.宽泛匹配(Loose match)买家使用与您的商品并不紧密相关的搜索词进行搜索时，亚马逊会向其显示您的广告。(基于关键词)3.同类商品(Substitutes)

买家使用与您的商品类似的商品的详情页面时，亚马逊会向其显示您的广告。(基于商品)4.关联商品(Complements)

买家使用与您的商品互补的商品的详情页面时，亚马逊会向其显示您的广告。(基于商品)

如果您的商品在搜索结果页中表现更好，应该偏重使用紧密匹配和宽泛匹配如果您的商品在商品页中表现更好，应该偏重使用同类商品和关联商品。

  

竞价策略，你可以从三种竞价策略中进行选择。选择最适合你广告活动目标的策略。此设置适用于你广告活动中的所有竞价。

  

①动态竞价-仅限向下调整

当您选择"动态竞价·仅限向下调整“策暗时，对于不太可能转化为销售的点击，亚马逊将实时降低您的竞价。2019年1月之前创建的任何广告活动都采用了这一策略。运作方式 假设您正在推广手表，且您针对关键词“运动手表”的竞价为E1。如果亚马逊发现我们预测您的广告转化为销售的可能性降低(例如，相关性较低的搜索查询、效果不佳的展示位置等)，我们可能会将您用于相应竞拍的竞价降低至f0.20。

  

②动态竞价-向上或向下调整

当您选择"动态竞价-向上或向下调整“策略时，对于更有可能转化为销售的点击，亚马逊将实时提高您的竞价;而对于不太可能转化为销售的点击，亚马逊将降低竞价。对于搜索结果首页顶部位置的展示位置，我们不会将莞价提高超过100%;而对于所有其他展示位置，我们不会将竞价提高超过50%。由于此策略会根据转化率的比例向上或向下调整您的竞价，因此与其他两种策略相比，您的广告支出可以实现更高的转化率。运作方式，假设您正在推广手表，且您针对关键词“运动手表”的竞价为$1。如果亚马逊发现您的广告更有可能转化为销售(例如，出现在高度相关搜索查询中的广告、效果良好的展示位置等)，我们可能会将用相应竟拍的竞价设置为$1.40。如果亚马逊发现您的广告不太可能转化为销售的其他情况，我们可能会将您用于相应竟拍的竞价降低至$0.20。对于搜索结果首页顶部位置上的广告，亚马逊当前可将您的竞价$1调整为最大$2，而将所有其他展示位置上的广告竞价调整为最大$1.50。

③固定竞价

当您选择"国定竞价“策略时，亚马逊将针对所有广告机会使用您的确切竞价，而不会根据转化率调整您的竞价。与动态竞价策略相比，您使用此策略的广告支出可能获得更多曝光量，但转化率较低。

## Xflow OS 核心理念

  

### 我们的使命

> **让卓越可复制** — 通过标准化的SOP与实战智慧，帮助每一个品牌拿到结果。

  

### 核心差异化

| 传统培训 | Xflow OS SOP |

|---------|-------------|

| 卖"藏宝图"（理论） | 卖"全地形越野车"（工具+SOP）+ "专业向导"（专家） |

| 泛泛而谈 | 精确到天、责任到人 |

| 信息差 | 透明化、可执行 |

  

### 四阶段执行体系

```

T-1 准备期（发货前）    →  市场调研、盈利模型分析、利润测算

   ↓

T-2 预热期（发货后-上架前）→ 视觉开发、文案埋词、关键词库建立

   ↓

T-0 激活期（上架后）    →  划线价设置、属性自检、QA与初级评论布局

   ↓

T+1 爆发期（推广中）    →  站外辅助、关键词上首页、广告透明计划

```

- **X Flow（流程）**: 交互式Checklist、时间轴控制、责任到人

- **Y Method（方法论）**: 每个环节背后的逻辑与思考

## 🔷 层级1：广告活动（Campaign）

### 可修改设置

| 设置项 | 操作要点 |
|-------|---------|
| **预算** | 根据广告活动效果（ACoS、CR）决定是否补充预算 |
| **竞价策略** | 动态竞价-仅降低 / 动态竞价-提高和降低 / 固定竞价 |
| **广告位溢价** | 针对三大广告位分别设置溢价百分比 |

### 关注指标

```
┌────────────────────────────────────────────────────────────┐
│                                                            │
│  📌 关注指标①：超预算时间                                     │
│  └→ 过早超预算 → 根据ACoS、CR决定是否补充预算                  │
│  └→ 判断逻辑：效果好(ACoS低/CR高) → 加预算                    │
│              效果差(ACoS高/CR低) → 不加，优化后再说             │
│                                                            │
│  📌 关注指标②：点击量                                        │
│  └→ 点击量高低与预算直接相关                                   │
│  └→ ⚠️ 建议：广告前期先保证足够点击量，设置充足预算               │
│  └→ 数据不够时不要急于优化，先跑量                              │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

## 🔷 层级2：广告位（Placement）

### 三大广告位属性对比

| 广告位 | 曝光量 | 点击率 | 转化率 | ACoS |
|:-----:|:-----:|:-----:|:-----:|:----:|
| 🥇 **搜索结果顶部（首页）** | 低 | **高** | **高** | 低 |
| 🥈 **产品页面** | **大** | 较大 | 中等 | 中等 |
| 🥉 **搜索结果其余位置** | **大** | 较大 | 中等 | 中等 |

### 广告位优化决策树

```
📍 搜索结果顶部（首页）& 产品页面：

  点击量不高 + 转化率高 + ACoS稳低
      │
      ▼ ✅ 操作：提高广告位溢价 → 扩大该位置曝光和点击
      
  点击量高 + 转化率低 + ACoS偏高
      │
      ▼ ❌ 操作：降低广告位溢价 / 竞价策略改为"动态竞价-仅降低"


📍 搜索结果其余位置：

  点击量不高 + 转化率高 + ACoS稳低
      │
      ▼ ✅ 操作：提高投放竞价 / 匹配方式改为"扩大"
      │        （变相扩大该位置曝光和点击）
      
  点击量高 + 转化率低 + ACoS偏高
      │
      ▼ ❌ 操作：降低广告位溢价 / 竞价策略改为"动态竞价-仅降低"
```

### ⭐ 核心关注指标

```
│                                                              │
│  📌 关注指标②：转化率                                          │

│  │ • 竞价高 + 转化率低 + 售价低 → ACoS飙升               │        │
│  │ • 竞价合理 + 转化率高 + 售价高 → ACoS可控              │        │

│                                                                 │
```

## 🔷 指标1：曝光量（Impressions）

### 影响曝光量的两大因素体系

```
                        曝光量
                     ┌────┴────┐
                广告因素         产品因素
              ┌───┴───┐           │
         ┌────┴────┐  │     LISTING中是否
         │         │  │     有埋此关键词
    广告竞价    其他因素│      (参考)
    ┌──┴──┐        │
 基本竞价  广告位竞价 │
    │              │
 竞价策略           │
                   │
         ┌─────────┼──────────┐
     关键词排名  关键词搜索量  自动广告是否
                            出现相关搜索词
                   │
              ┌────┼────┐
            预算   否词
```

### 广告因素详解

| 因素 | 具体内容 | 影响逻辑 |
|------|---------|---------|
| **广告竞价** | 基本竞价 + 广告位竞价 + 竞价策略 | 竞价越高 → 广告排名越靠前 → 曝光越多 |
| **关键词排名** | 关键词在广告搜索结果中的位置 | 排名越高 → 曝光越大 |
| **关键词搜索量** | 该关键词的市场搜索热度 | 搜索量越大 → 潜在曝光池越大 |
| **自动广告相关词** | 自动广告中是否出现相关搜索词 | 相关性越强 → 亚马逊分配的曝光越多 |
| **预算** | 每日/活动预算上限 | 预算耗尽 → 曝光立即停止 |
| **否词** | 否定关键词设置 | 否词过多 → 曝光减少（需谨慎） |

### 产品因素

| 因素 | 影响逻辑 |
|------|---------|
| **Listing中是否埋词** | Listing未包含目标关键词 → 亚马逊不会为该词分配广告曝光 |

> **💡 关键认知**：Listing是广告的基础。如果Listing中没有埋入关键词，即使出价再高，亚马逊也可能不给曝光。

## 🔷 指标2：点击率CTR（Click-Through Rate）

### CTR影响因素全景图

```
                              点击率 CTR
                ┌───────────────┼───────────────┐
           广告因素            产品因素         其他外部因素
         ┌───┴───┐        ┌───┴───┐            │
    ┌────┴──┐    │   ┌────┴──┐    │      ┌─────┴─────┐

  /广告位        /匹配       /品牌        跟卖/时间段
```

### 一、广告因素对CTR的影响

| 广告因素 | 影响机制 | 优化方向 |
|---------|---------|---------|
| **广告竞价/广告位** | PPC出价低 → 广告位靠后 → 刷会变差 → 展示质量不好 → CTR低 | 适当提高竞价，争取优质广告位 |
| **广告预算** | 当CPC过高 + 预算超低 → 曝光效果越低 → CTR受影响 | 预算要匹配CPC水平 |
| **否词** | 否词太多 → 否掉了大流量词 → 曝光大幅减少 → CTR数据失真 | 否词要精准，不要过度否定 |
| **投放词选择** | 词的精准度直接影响CTR | 见下方详细分析 |

### 投放词选择与匹配方式详解

```
┌──────────────────────────────────────────────────────────────┐
│                     投放词选择策略                              │
│                                                              │
│  📌 大词策略                                                  │
│  └→ 一般用广泛匹配，低价去跑                                    │

│  │ 广泛匹配    │ 流量大，精准度低 → CTR相对较低      │            │
│  │ 词组匹配    │ 流量中，精准度中 → CTR适中          │            │
```

## 🔷 指标3：ACoTs广告花费占比

### 核心公式

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  📌 ACoS = 广告花费 ÷ 广告销售额 × 100%                       │
│                                                              │
│  📌 ASoTs = 广告销售额 ÷ 总销售额 × 100%                      │
│      (广告销售占比)                                            │
│                                                              │
│  📌 ACoTs = ACoS × ASoTs                                     │
│      (广告花费占总销售额的比例)                                  │
│                                                              │
│  ──────────────────────────────────────────────              │
│                                                              │
│  💡 ACoTs = 广告花费 ÷ 总销售额 × 100%                        │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### ACoTs的核心判断逻辑

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  场景：ACoS很高，但是...                                       │
│                                                              │
│  ✅ 如果广告订单占比控制得非常好                                  │
│  └→ 广告费用占比（ACoTs）达到可以接受的范围                       │
│  └→ 那么即使ACoS高，整体也是健康的                              │
│                                                              │
│  ──────────────────────────────────────────────              │
│                                                              │
│  💡 核心认知：                                                │
│  ACoS高 ≠ 一定不好                                           │
│  要看ACoTs（广告花费占总销售额的比例）是否可接受                    │
│                                                              │
│  ──────────────────────────────────────────────              │
│                                                              │
│  📈 良性循环逻辑：                                             │
│                                                              │
│  通过广告提高关键词排名                                         │
│       ↓                                                      │
│  关键词转化率提升                                              │
│       ↓                                                      │
│  关键词的自然排名逐步提升                                       │
│       ↓                                                      │
│  自然订单占比增加                                              │
│       ↓                                                      │
│  ASoTs下降（广告销售占比降低）                                   │
│       ↓                                                      │
│  ACoTs自然下降 → 广告投入更健康                                 │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### ACoTs健康度判断参考

| ACoTs范围 | 健康状态 | 建议动作 |
|:---------:|:------:|---------|
| < 5%   | 🟢 非常健康 | 可适当扩大广告投入 |
| 5%-10% | 🟡 正常 | 保持现有策略，持续优化 |
| 10%-15% | 🟠 需关注 | 检查ACoS和ASoTs，针对性优化 |
| > 15%   | 🔴 警告 | 需立即优化或缩减广告预算 |

```
│  📊 判断标准：             │  📊 判断标准：                     │
│  单次点击成本 ≤ 盈亏平衡CPC │  自然单占比持续上升                │
│  即可持续投放              │  广告ACoTs逐步下降                │
│                          │                                  │
└──────────────────────────┴──────────────────────────────────┘
```

### ⭐ 精铺模式关键公式

```
┌──────────────────────────────────────────────────┐
│                                                  │
│  盈亏平衡CPC = 产品售价 × 利润率 × 转化率          │
│                                                  │
│  💡 只要实际CPC ≤ 盈亏平衡CPC                     │
│  → 广告单就不亏钱                                 │
│  → 无需刻意控制广告单占比                          │
│                                                  │
└──────────────────────────────────────────────────┘
```

```
          │
          ▼
```

```
│  └→ 后果：排名持续下滑，前期广告投入打水漂                      │
```

## 📘 Skill 5：广告结构优化（持续性技能）

> 贯穿所有阶段的核心动作：持续对广告结构进行优胜劣汰

### 预算转移策略

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  📊 广告结构优化 — 优胜劣汰原则                                 │
```

# 📘 Skill 3：ECPM自然排名底层算法（最核心理论）

## 3.1 ECPM公式详解

```
┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  📐 ECPM（Effective Cost Per Mille）= 千次展现的预估收益            │
│                                                                  │
│  ┌────────────────────────────────────────────────────┐          │
│  │                                                    │          │
│  │  ECPM = 1000次展现 × CTR × CVR × 客单价 × 抽佣比例   │          │
│  │         + FBA费用                                   │          │
│  │                                                    │          │
│  └────────────────────────────────────────────────────┘          │
│                                                                  │
│  📊 变量分类：                                                    │
│                                                                  │
│  ┌────────────────────┬────────────────────────────────┐         │
│  │     常数（固定值）    │        随机变量（离散值）         │         │
│  ├────────────────────┼────────────────────────────────┤         │
│  │ • 1000次展现        │ • CTR（点击率）                  │         │
│  │ • 客单价            │ • CVR（转化率）                  │         │
│  │ • 抽佣比例          │                                │         │
│  │ • FBA费用           │ 在不同竞争环境、不同消费者决策下   │         │
│  │                    │ 存在随机性 → 称为随机变量          │         │
│  └────────────────────┴────────────────────────────────┘         │
│                                                                  │
│  💡 平台逻辑（利益即态度）：                                        │
│  把亚马逊当做老板 → 所有ASIN都是打工仔                              │
│  哪个ASIN给老板创造更多价值（ECPM更高）                              │
│  → 老板就给他更好的排名（自然位更靠前）                               │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

## 3.2 期望与方差：对随机变量的定量评估

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  📐 如何对CTR/CVR这类随机变量进行定量计算？                      │
│  → 引入 期望（Expectation）和 方差（Variance）                  │
│                                                              │
│  ══════════════════════════════════════════════════           │
│                                                              │
│  📌 期望（E）= 这组离散数值的集中位置/平均水平                    │
│  ┌──────────────────────────────────────────────┐            │
│  │ 类比：一名学生10次考试的平均分                    │            │
│  │ → 代表他的真实水平                               │            │
│  │ → 期望值越高越好 ✅                              │            │
│  └──────────────────────────────────────────────┘            │
│                                                              │
│  📌 方差（σ²）= 离散数值的波动程度                               │
│  ┌──────────────────────────────────────────────┐            │
│  │ 类比：10次考试成绩的稳定程度                      │            │
│  │ → 方差大 = 发挥不稳定，时高时低                    │            │
│  │ → 方差小 = 每次成绩在小范围内波动                   │            │
│  │ → 方差越小越好 ✅                                │            │
│  └──────────────────────────────────────────────┘            │
│                                                              │
│  ══════════════════════════════════════════════════           │
│                                                              │
│  📐 排名评估公式（简化版）：                                     │
│                                                              │
│  ┌────────────────────────────────────────┐                  │
│  │                                        │                  │
│  │  max(期望, 方差) = 期望 - r × 方差       │                  │
│  │                                        │                  │
│  │  r > 0，代表偏好系数                     │                  │
│  │  r越大 → 越看重稳定性                    │                  │
│  │  平台算法调整 = 改变r值                   │                  │
│  │                                        │                  │
│  └────────────────────────────────────────┘                  │
│                                                              │
│  ⭐ 要提升排名：                                               │
│  → 提高期望（提升CTR/CVR的平均水平）                             │
│  → 降低方差（让CTR/CVR更加稳定）                                │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 3.3 期望与方差的影响因素

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  📐 期望的定义：                                               │
│                                                              │
│  期望 = f(P, Q)                                              │
│                                                              │
│  P = Product（产品）                  Q = Query（搜索词）       │
│  ┌──────────────────────┐          ┌──────────────────┐      │
│  │ • 产品主图            │          │ • 搜索词与产品的   │      │
│  │ • 文案精准度           │          │   相关性          │      │
│  │ • 评价星级和数量        │          │ • 关键词匹配精准度 │      │
│  │ • 价格合理性           │          │                  │      │
│  │                      │          │                  │      │
│  │ → 决定CTR/CVR的高低    │          │ → 决定CTR/CVR    │      │
│  └──────────────────────┘          └──────────────────┘      │
│                                                              │
│  💡 指导意义：                                                │
│  产品素质天然决定CTR/CVR的高低                                  │
│  → 从数学底层证明了"7分选品3分运营"的正确性                      │
│  → 主图/文案/评价/价格的构建能力至关重要                         │
│                                                              │
│  ══════════════════════════════════════════════════           │
│                                                              │
│  📐 方差的定义：                                               │
│                                                              │
│  方差 = f(点击数)                                             │
│                                                              │
│  ┌──────────────────────────────────────────────┐            │
│  │ • 点击次数太少 → 时高时低 → 方差大               │            │
│  │ • 点击次数不断增加 → 方差不断收敛变小             │            │
│  │                                              │            │
│  │ 类比：10次考试成绩不稳定                        │            │
│  │ → 考20次、50次、200次...                       │            │
│  │ → 次数越多，波动越小，越接近真实水平             │            │
│  └──────────────────────────────────────────────┘            │
│                                                              │
│  💡 指导意义：                                                │
│  通过快速增加点击次数 → 降低方差                                │
│  → 使"期望 - r×方差"的数值更大                                 │
│  → 间接提升排名                                              │
│                                                              │
│  ⭐ 这就从数学层面解释了：                                      │
│  "关键词上首页"策略有效的原因                                   │
│  → 通过大量点击 → 短期内降低方差                                │
│                                                              │
│  ⚠️ 但注意：                                                 │
│  期望才是决定因素，方差只是次要因素                               │
│  点击次数增加只是帮助算法更快了解真实CTR                          │
│  真实CTR/CVR还是由产品硬实力决定                                │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 3.4 ECPM排名完整推导

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  📐 完整排名推导流程                                           │
│                                                              │

│       │                                                      │
│       ▼                                                      │

│       │  （计算期望和方差）                                     │

│  Step 3: 代入公式 max = 期望 - r × 方差                        │
│       │  （得到每个SKU的综合评分）                               │
│       ▼                                                      │
│  Step 4: 将综合评分代入ECPM公式                                 │
│       │  ECPM = 1000 × CTR评分 × CVR评分 × 客单价              │
│       │         × 抽佣比例 + FBA费用                           │
│       ▼                                                      │
│  Step 5: 按ECPM值排序 → 得到自然排名先后                        │
│                                                              │
│  ══════════════════════════════════════════════════           │
│                                                              │
│  🎯 最终结论：                                                │
│  目标是提升排名 → 攻坚方向清晰：                                │
│                                                              │
│  ┌────────────────────────────────────────┐                  │
│  │                                        │                  │
│  │  攻坚点①：提升CTR（点击率）              │                  │
│  │  └→ 主图/价格/评论/标签/文案             │                  │
│  │                                        │                  │
│  │  攻坚点②：提升CVR（转化率）              │                  │
│  │  └→ 选词精准度/产品力/页面质量/评论      │                  │
│  │                                        │                  │
│  │  攻坚点③：快速积累点击次数                │                  │
│  │  └→ 降低方差/让系统更快认识你             │                  │
│  │                                        │                  │
│  └────────────────────────────────────────┘                  │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```
