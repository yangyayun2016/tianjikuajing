# 一、知识库总定位

这个 Obsidian 库不是单纯“资料收藏夹”，而是一个：

**亚马逊业务操作系统 = 知识沉淀 + SOP 执行 + 问题复盘 + 经验库 + AI 工具库 + 项目管理 + 数据分析方法库**

核心目标：

1. 新人能快速上手亚马逊运营。
2. 老员工能沉淀经验，避免重复踩坑。
3. 广告、运营、选品、产品开发、客服、供应链之间知识打通。
4. 每个问题都能追溯：问题 → 原因 → 解决方案 → SOP → 案例。
5. AI 工具不只是收藏，而是融入 Listing、广告、选品、客服、复盘等流程。

# 1️⃣ 捡漏打法（核心体系）

👉 来自你的文档：

## 本质（你这段是重点）

```text
广告位 = 出价 × 转化率（CTR × CVR）
```

👉 结论：

```text
低竞价 ≠ 低曝光
高转化可以弥补低竞价
```

---

## 捡漏打法完整模型

```text
流量分层
→ 低竞价切入
→ 数据清洗（否词）
→ 筛选高转化词
→ 权重反哺
→ 自然流量提升
```

---

## 自动广告漏斗模型（你文档核心）

```text
Close Match → 核心转化
Loose Match → 流量拓展
Substitute → 竞品流量
Complementary → 关联流量
```

---

## 捡漏打法SOP（可直接放Obsidian）

```markdown
# 捡漏广告打法 SOP

## 适用
- 有自然单
- 有转化基础
- ACOS过高产品

## 操作步骤
1. 拆分自动广告为4组
2. 设置低竞价（20%-50%建议价）
3. 分层匹配类型
4. 每周清洗无效流量
5. 筛选高转化词迁移

## 核心指标
- CTR > 1%
- CVR > 类目平均
- ACOS < 30%

## 禁忌
- 无转化产品不要用
- 不清洗词库
```

```markdown
# SOP：新品冷启动

## 一、适用场景
适用于新品刚上架后的 0-30 天运营启动阶段，目标是完成基础流量获取、转化验证、广告建模和后续放量前评估。

## 二、目标
1. 完成新品基础曝光和首批点击积累
2. 验证 Listing 是否具备基础转化能力
3. 验证核心关键词方向是否正确
4. 建立后续广告优化和 Review 积累基础

## 三、前置条件
- [ ] Listing 已完整发布
- [ ] 主图、五点、A+、价格已确认
- [ ] 基础关键词库已准备
- [ ] 广告账户结构已确认
- [ ] 库存可支撑 30 天测试
- [ ] 产品无明显合规风险

## 四、输入资料
- Listing 页面
- 核心关键词清单
- 竞品价格带与 Review 情况
- 首批广告预算
- 目标售价、毛利率、目标 ACOS

## 五、执行步骤
### Step 1：上架前检查
1. 检查标题、五点、图片、A+ 是否完整
2. 检查类目、属性、变体是否正确
3. 检查价格是否处于合理测试区间
4. 检查 Coupon 是否需要同步开启

### Step 2：建立启动广告
1. 建立自动广告
2. 建立基础手动广告
3. 建立品牌防御广告（如有品牌基础）
4. 设置初始预算和初始 Bid
5. 确保命名统一

### Step 3：观察前 3-7 天数据
重点观察：
- 曝光是否启动
- CTR 是否过低
- CVR 是否有基础成交
- CPC 是否过高
- 搜索词是否偏离产品

### Step 4：判断 Listing 是否具备基础转化
判定重点：
1. 有曝光没点击：优先怀疑主图、价格、Review
2. 有点击没转化：优先怀疑 Listing 说服力、关键词精准度、价格
3. 有转化但 ACOS 高：优先怀疑 CPC 过高或结构错误

### Step 5：进入第二阶段
1. 保留有效广告组
2. 清理明显无效词和无效流量
3. 将有转化词迁移到更精准组
4. 根据数据决定是否进入放量期

## 六、判断标准
- 至少形成基础曝光
- 至少出现首批点击
- 至少有一部分流量与产品强相关
- 至少验证出一批可持续观察关键词
- 没有出现明显流量方向错误

## 七、常见错误
- 一开始就开太多复杂广告
- 没有关键词库就直接投放
- 上架即高预算粗放跑量
- Listing 未准备好就强行放量
- 首周频繁改标题、主图、价格

## 八、风险点
- 没有评论支撑时转化波动大
- 预算太小导致数据不成型
- 价格过高导致点击后不转化
- 关键词不准导致垃圾流量积累

## 九、输出结果
- 新品冷启动结论
- 初始广告结构
- 首批有效关键词
- 第一阶段问题清单
- 第二阶段优化待办
```

## 15）捡漏打法 SOP

你的资料把捡漏打法定义为：不是“低价碰运气”，而是通过**流量分层→数据清洗→权重反哺**构建精准流量池；并提出“广告位分配 = 出价 × 预估转化率（CTR×CVR）”，以及自动广告四阶漏斗、手动倒金字塔和否定词三级防御体系。

```markdown
# SOP：捡漏打法

## 一、适用场景
适用于：
- 已有一定转化基础的产品
- 自然单不错的产品
- 高 ACOS 核心词想降成本
- 想从低竞价流量区截取精准流量

## 二、目标
1. 用更低 CPC 获取可成交流量
2. 通过流量清洗形成高质量词池
3. 用低成本流量反哺广告权重和自然流量

## 三、前置条件
- [ ] 产品本身具备基础转化
- [ ] Listing 没有明显硬伤
- [ ] 已有初始广告数据或类目认知
- [ ] 可接受低速起量

## 四、执行步骤
### Step 1：建立自动四阶漏斗
拆为：
- 紧密匹配
- 宽泛匹配
- 同类商品
- 互补商品

### Step 2：设置低竞价梯度
- 竞价不要完全一样
- 低竞价测试不同阶段
- 避免组间互抢

### Step 3：建立手动倒金字塔
- Broad：找入口

### Step 4：做三级否定防御
1. 实时低 CTR 否定
2. 周期性点击无转化否定

- CTR

- CPC

### Step 6：升级高价值流量
- 高转化词迁移
- 高相关 ASIN 放大

## 五、判断标准
- ACOS 下降
- CPC 低于常规组
- 自然流量占比提升
- 流量质量持续改善

## 六、风险点
- 产品转化差时容易跑废
- 竞价过低可能完全没曝光
```

## 16）海王打法 SOP

你的 PDF 里强调：海王打法以 **低 CPC、大覆盖、多 SKU/类目触达** 为基础，更适合流量型、配件型、场景型商品；并按 0-1、1-100 两阶段放大，先在低 CPC 下跑出基础曝光，再逐步放大预算和组数。页面 2-3 还明确了：更适合 AUTO 和 SBV 等偏拓量入口，且精铺/垂直类目在 ACOS、客单、自然单占比上要结合产品阶段看。

```markdown
# SOP：海王打法

## 一、适用场景
适用于：
- SKU 多
- 变体多
- 场景型/搭配型产品
- 配件型产品
- 想低 CPC 大范围试探流量

## 二、目标
1. 用大量 SKU 或类目入口触达更多流量
2. 找到最有价值的类目/词/ASIN 入口
3. 建立低成本扩流基础

## 三、执行步骤
### Step 1：准备测试池
准备：
- 多个 SKU
- 多个类目
- 多个关键词或词根
- 多个关联方向

### Step 2：设置低 CPC 试探
参考建议价，但不要低到完全无效。

### Step 3：设置较高总预算
预算高的目的是防止系统提前截断，而不是强行烧钱。

### Step 4：0-1 阶段观察
关注：
- 是否有曝光
- 哪些组被系统收录
- 哪些入口有点击
- 哪些入口成本更低

### Step 5：1-100 阶段放大
对有效入口：
- 增加组数
- 增加预算
- 提高局部 Bid
- 让有效入口逐步吃量

### Step 6：精细化维护
当跑出有效入口后：
- 加强对应词/类目/ASIN
- 无效入口暂停
- 避免盲目无限扩组

## 四、判断标准
- 找到有效触达入口
- 总体 CPC 低
- 有一定点击与转化基础
- 能筛出值得长期维护的类目或 ASIN

## 五、风险点
- 关联度低会完全不给曝光
- 组数过多维护难度高
- 低流量下 ACOS 好看但转化弱，容易误判
```

```markdown id="j0r3d4"
# 广告打分系统：总评分模型

## 一、模型目标
通过统一的广告评分模型，把广告表现标准化，便于横向比较和自动判断。

## 二、总分结构
广告总分 = 100 分

- 曝光能力：20 分
- CTR点击能力：20 分
- CVR转化能力：25 分
- ACOS成本控制：25 分
- CPC合理性：10 分

## 三、总分公式
总分 = 曝光分 + CTR分 + CVR分 + ACOS分 + CPC分

## 四、等级划分
- A：85-100
- B：70-84
- C：55-69
- D：40-54
- U：0-39

## 五、等级解释
### A级
广告结构健康，适合扩量、扩词、提预算

### B级
广告整体可用，但有局部问题，需要做结构性优化

### C级
广告处于临界状态，需要针对问题做较强干预

### D级
广告低效，需明显调整结构、Bid 或打法

### U级
广告不健康，建议重建或暂停

## 六、输出结果格式
示例：
- 广告总分：78
- 广告等级：B
- 问题类型：CTR偏低、CPC偏高
```

```markdown id="4o8e9q"
# 广告打分系统：曝光评分规则

## 一、目标
评估广告是否具备基本曝光能力。

## 二、评分规则
- Impressions < 100：0分
- 100 - 1,000：5分
- 1,000 - 10,000：10分
- 10,000 - 50,000：15分
- > 50,000：20分

## 三、补充判断
曝光高不代表广告好，只表示广告具备流量进入能力。

## 四、异常解释
### 曝光很低
可能原因：
- Bid 过低
- 关键词太小
- 相关性差
- 广告组结构太弱
- 商品标签不准

### 曝光很高但整体分低
说明广告可能在烧泛流量，需要结合 CTR/CVR 看质量

## 五、建议动作
- 曝光低：提高 Bid / 改结构 / 改打法
- 曝光高但 CTR 低：重点看主图、价格、关键词精准度
```

```markdown id="lu9fyz"
- 70% - 100%：8分
- < 70%：10分

## 三、意义
CPC合理性不等于广告一定好，但能说明流量获取效率。

## 四、异常解释
- CPC 很高：可能竞品竞争加剧，或首页位溢价过高
- CPC 很低：可能流量质量差，也可能是优质捡漏流量

## 五、建议动作
- 结合 CVR 看 CPC 是否值得
- 若 CVR 高且 CPC 高，未必要急于降 Bid
- 若 CVR 低且 CPC 高，必须及时处理
```
