# 📘 Skill 1：广告位对自然位的拉升（助力）动作

## 1.1 广告位拉升自然位的底层逻辑

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  🔗 广告位 → 自然位 的传导链条                                 │
│                                                              │
│  广告投放关键词                                                │
│       │                                                      │
│       ▼                                                      │
│  广告位获得曝光（搜索结果顶部/商品页面/其余位置）                 │
│       │                                                      │
│       ▼                                                      │
│  买家点击（提升该关键词下ASIN的点击数据）                        │
│       │                                                      │
│       ▼                                                      │
│  买家转化下单（广告订单 → 积累关键词下的转化权重）                │
│       │                                                      │
│       ▼                                                      │
│  eCPM提升 = 1000 × CTR↑ × CVR↑ × 客单价 × 抽佣比例 + FBA         │
│       │                                                      │
│       ▼                                                      │
│  系统给予更好的自然排名位置                                     │
│       │                                                      │
│       ▼                                                      │
│  自然位上升 → 自然曝光增加 → 自然点击增加 → 自然订单增加          │
│       │                                                      │
│       ▼                                                      │
│  SIF提升（搜索量×a + 更好位置×b + 更长曝光时长×c）               │
│       │                                                      │
│       ▼                                                      │
│  正向飞轮启动 🔄                                                │
│                                                              │
│  ════════════════════════════════════════════════             │
│                                                              │
│  ⭐ 核心理解：                                                │
│  广告位不是"替代"自然位，而是"助力"自然位                       │
│  广告出单的本质 = 给系统"交作业"证明你值得更好的自然位置          │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 1.2 广告位拉升自然位的三种助力动作

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  🎯 三种助力动作                                               │
│                                                              │
│  ┌──────────────────────────────────────────────────┐        │
│  │                                                  │        │
│  │  助力①：直接转化拉升 ⭐⭐⭐⭐⭐                     │        │
│  │  ┌──────────────────────────────────────┐        │        │
│  │  │ 广告精准投放某关键词                     │        │        │
│  │  │ → 该词下产生转化（出单）                 │        │        │
│  │  │ → 该词下的ECPM值提升                    │        │        │
│  │  │ → 该词下的自然排名提升                   │        │        │
│  │  │                                      │        │        │
│  │  │ 💡 这是最直接、最有效的助力方式          │        │        │
│  │  │ 选词精准 + 转化率高 → 助力效果最大       │        │        │
│  │  └──────────────────────────────────────┘        │        │
│  │                                                  │        │
│  │  助力②：点击数据积累（降低方差）⭐⭐⭐⭐            │        │

│  │  │ 广告带来大量点击                        │        │        │

│  │  │ 💡 短期冲击大量点击 → 快速降低方差       │        │        │

│  │  └──────────────────────────────────────┘        │        │
│  │                                                  │        │

│  │  │ → 整体链接权重增加                      │        │        │
│  │  │ → 间接提升所有关键词的自然排名            │        │        │
│  │  │                                      │        │        │
│  │  │ 💡 涨潮效应：整体单量上升               │        │        │
│  │  │ 连没做广告的词的自然排名也可能跟着上升    │        │        │

│  │                                                  │        │
```

# 📘 Skill 2：广告位和自然位的稳定性分析

## 2.1 稳定性为什么重要

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  📊 稳定性 = 曝光时长 = SIF的核心因子                           │
│                                                              │
│  ┌──────────────────────────────────────────────────┐        │
│  │                                                  │        │
│  │  排名稳定 → 曝光时长长 → SIF高 → 自然流量多        │        │
│  │  排名波动 → 曝光时长短 → SIF低 → 自然流量少        │        │
│  │                                                  │        │
│  │  ════════════════════════════════════              │        │
│  │                                                  │        │
│  │  📐 从eCPM方差角度理解：                           │        │
│  │                                                  │        │
│  │  排名稳定 = CTR/CVR方差小                         │        │
│  │  → max = 期望 - r×方差(小)                        │        │
│  │  → 综合评分高 → 系统给你持续的好排名                │        │
│  │                                                  │        │
│  │  排名波动 = CTR/CVR方差大                         │        │
│  │  → max = 期望 - r×方差(大)                        │        │
│  │  → 综合评分低 → 系统不信任你，排名忽上忽下          │        │
│  │                                                  │        │
│  └──────────────────────────────────────────────────┘        │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 2.2 广告位稳定性分析

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  📢 广告位稳定性 — 影响因素与诊断                               │
│                                                              │
│  ┌──────────────────────────────────────────────────┐        │
│  │                                                  │        │
│  │  📌 影响广告位稳定性的因素                         │        │
│  │                                                  │        │
│  │  因素①：预算是否充足                              │        │
│  │  ┌──────────────────────────────────────┐        │        │
│  │  │ • 预算过早耗尽 → 广告停止展示            │        │        │
│  │  │ • 下午就超预算 → 晚高峰没有广告位        │        │        │
│  │  │ → 广告位"断断续续" → 极不稳定            │        │        │
│  │  │                                      │        │        │
│  │  │ ✅ 解决：保证预算能覆盖全天24小时         │        │        │
│  │  │ 如果预算有限 → 分时段投放/降低竞价       │        │        │
│  │  └──────────────────────────────────────┘        │        │
│  │                                                  │        │
│  │  因素②：竞价水平                                  │        │
│  │  ┌──────────────────────────────────────┐        │        │
│  │  │ • 竞价过低 → 广告位靠后 → 不稳定        │        │        │
│  │  │ • 竞价刚好在边界 → 忽前忽后             │        │        │
│  │  │ • 竞价充足 → 广告位稳定靠前              │        │        │
│  │  │                                      │        │        │
│  │  │ ✅ 解决：竞价要"高于临界值"              │        │        │
│  │  │ 不要卡在"有时第一有时第五"的边界位置      │        │        │
│  │  └──────────────────────────────────────┘        │        │
│  │                                                  │        │
│  │  因素③：竞价策略（杠杆模式）                       │        │
│  │  ┌──────────────────────────────────────┐        │        │
│  │  │ • 动态提高和降低 → 波动最大             │        │        │
│  │  │ • 动态仅降低 → 波动中等                  │        │        │
│  │  │ • 固定竞价 → 波动最小                   │        │        │
│  │  │                                      │        │        │
│  │  │ ✅ 需要稳定性时 → 选固定竞价             │        │        │
│  │  │ 需要灵活性时 → 选动态策略                │        │        │
│  │  └──────────────────────────────────────┘        │        │
│  │                                                  │        │
│  │  因素④：广告质量分（隐性因素）                     │        │
│  │  ┌──────────────────────────────────────┐        │        │
│  │  │ • CTR高 → 系统认为广告质量好 → 位置更稳  │        │        │
│  │  │ • CTR低 → 系统认为广告质量差 → 位置不稳  │        │        │
│  │  │ • CVR高 → 加强稳定性                    │        │        │
│  │  └──────────────────────────────────────┘        │        │
│  │                                                  │        │
│  └──────────────────────────────────────────────────┘        │
│                                                              │
```

# 📘 Skill 3：看订单 — 自然订单与广告订单比值分析

## 3.1 订单结构诊断框架

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  📊 订单结构 = 链接健康度的核心体检指标                          │
│                                                              │
│  ┌──────────────────────────────────────────────────┐        │
│  │                                                  │        │
│  │  总订单 = 自然订单 + 广告订单                      │        │
│  │                                                  │        │
│  │  自然单占比 = 自然订单 ÷ 总订单 × 100%             │        │
│  │  广告单占比 = 广告订单 ÷ 总订单 × 100%             │        │
│  │                                                  │        │
│  │  ════════════════════════════════════              │        │
│  │                                                  │        │
│  │  📊 健康度诊断标准：                                │        │
│  │                                                  │        │
│  │  自然单占比 │ 健康状态      │ 诊断                │        │
│  │  ──────────┼──────────────┼─────────────────── │        │
│  │  > 70%    │ 🟢 非常健康    │ 广告是辅助           │        │
│  │  50~70%   │ 🟡 健康        │ 自然和广告平衡       │        │
│  │  30~50%   │ 🟠 需关注      │ 仍然依赖广告         │        │
│  │  < 30%    │ 🔴 危险        │ 过度依赖广告         │        │
│  │                                                  │        │
│  │  ⚠️ 注意：新品期自然单占比低是正常的                │        │
│  │  需要看"趋势"而不只是看"数值"                     │        │
│  │  → 自然单占比在上升 = 良性                        │        │
│  │  → 自然单占比停滞或下降 = 需要排查                 │        │
│  │                                                  │        │
│  └──────────────────────────────────────────────────┘        │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

> **💡 终极总结**：
>
> 广告与自然的平衡是亚马逊运营**最难但最有价值**的技能：
>
> 1. **理解助力逻辑** — 广告是"助力器"，不是"替代品"
> 2. **重视稳定性** — 稳定的排名 >> 偶尔冲高的排名（因为曝光时长）
> 3. **定性+定量分析CVR** — 对比类目/竞品/自身历史，三层穿透
> 4. **杠杆策略匹配阶段** — 冲刺期用提高降低，稳定期用仅降低/固定
> 5. **都在前5的决策** — 看价格、销量敏感度、类目、CVR、战略目标五维判断
> 6. **动态平衡方法** — "试探10%-观察3天-数据验证-决策调整"循环
> 7. **每天都在变** — 平衡点不是一成不变的，需要持续校准
>
> **掌握这项平衡术 = 掌握亚马逊运营的"核心艺术"** 🎨

> **💡 终极总结**：
>
> SB/SBV广告最容易被误解和误用：
>
> 1. **不要指望SB/SBV拉关键词排名** — 这是SP的任务
> 2. **不要指望SB/SBV做新品收录** — 这靠Listing埋词和SP自动广告
> 3. **SB/SBV的真正价值** — 品牌曝光、品牌收录、整体链接权重和转化率提升
> 4. **评估方式完全不同** — 不看关键词ACoS，看品牌搜索量和整体数据
> 5. **使用时机有讲究** — 前期以SP为主导，中后期逐步加入SB/SBV
> 6. **三者协同才是最优** — SP攻城拔寨 + SB制空权 + SBV特种打击
>

# 📘 Skill 1：ASIN自然位滚动率 — 理解关键词的竞争动态

## 1.1 什么是自然位滚动率

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  📐 ASIN自然位滚动率 的定义                                    │
│                                                              │
│  ┌──────────────────────────────────────────────────┐        │
│  │                                                  │        │
│  │  定义：                                          │        │
│  │  根据某关键词下的自然位数量和自然位ASIN数量         │        │
│  │  等数据综合计算得出的指标                          │        │
│  │                                                  │        │
│  │  本质含义：                                       │        │
│  │  该关键词下，自然排名位置中ASIN的"更替速度"         │        │
│  │  = 首页的ASIN是否经常在变？还是长期稳定不变？       │        │
│  │                                                  │        │
│  │  ════════════════════════════════════              │        │
│  │                                                  │        │
│  │  📐 计算要素：                                     │        │
│  │                                                  │        │
│  │  ① 自然位数量                                     │        │
│  │  └→ 该关键词搜索结果中有多少个自然排名位置           │        │
│  │  └→ 去掉广告位后，剩下的纯自然位有多少个            │        │
│  │                                                  │        │
│  │  ② 自然位ASIN数量                                 │        │
│  │  └→ 在一定时间周期内                               │        │
│  │     出现在这些自然位上的不同ASIN有多少个             │        │
│  │                                                  │        │
│  │  ③ 滚动率 = ASIN变化频率                           │        │
│  │  └→ 如果自然位有20个，但不同ASIN有80个出现过        │        │
│  │     → 滚动率高 = 位置在频繁更替                    │        │
│  │  └→ 如果自然位有20个，不同ASIN只有22个              │        │
│  │     → 滚动率低 = 位置非常稳固                      │        │
│  │                                                  │        │
│  └──────────────────────────────────────────────────┘        │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

# 📘 Skill 2：自然位滚动率 vs SIF 对比分析

## 2.1 两大指标的对比

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  📊 自然位滚动率 vs SIF — 两个不同维度的指标                     │
│                                                              │
│  ┌──────────────────────────────────────────────────┐        │
│  │                                                  │        │
│  │             自然位滚动率            SIF             │        │
│  │            (市场竞争动态)    (我方流量获取效果)       │        │
│  │                                                  │        │
│  │  ─────────────────────────────────────────────── │        │
│  │                                                  │        │
│  │  衡量对象   该关键词下所有         我方ASIN在        │        │
│  │            ASIN的更替情况        该关键词下的表现     │        │
│  │                                                  │        │
│  │  视角       市场视角              自身视角           │        │
│  │            "这个战场乱不乱"      "我在这个战场表现如何"│        │
│  │                                                  │        │
│  │  计算要素   自然位数量             搜索量 × a        │        │
│  │            自然位ASIN数量         + 位置 × b        │        │
│  │            ASIN更替频率           + 曝光时长 × c    │        │
│  │                                                  │        │
│  │  告诉你     这个词好不好进入        你在这个词上       │        │
│  │            竞争激烈程度如何        实际拿到了多少流量  │        │
│  │                                                  │        │
│  │  用途       选词决策               效果评估          │        │
│  │            (投不投这个词)          (投了效果如何)     │        │
│  │                                                  │        │
│  └──────────────────────────────────────────────────┘        │
│                                                              │
│  ⭐ 两者配合使用：                                            │
│  滚动率 → 判断"值不值得打" → 选词阶段使用                      │
│  SIF → 判断"打得好不好" → 投放后评估使用                       │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 2.2 SIF加权因子详解

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  📐 SIF的三大加权因子                                          │
│                                                              │
│  SIF = 自然关键词流量 × a + 曝光时长 × b + 位置前后 × c        │
│                                                              │
│  ┌──────────────────────────────────────────────────┐        │
│  │                                                  │        │
│  │  加权因子①：自然关键词流量 × 常量a                  │        │
│  │  ┌──────────────────────────────────────┐        │        │
│  │  │ 含义：该关键词的搜索量大小               │        │        │
│  │  │ 权重逻辑：                              │        │        │
│  │  │ • 搜索量越大 → 流量池越大                │        │        │
│  │  │ • 即使你位置一般，大词的绝对流量也可观     │        │        │
│  │  │ • 常量a决定了搜索量在SIF中的权重          │        │        │
│  │  │                                      │        │        │
│  │  │ 💡 你不能改变搜索量                     │        │        │
│  │  │ 但你可以选择搜索量大的词来投放            │        │        │
│  │  └──────────────────────────────────────┘        │        │
│  │                                                  │        │
│  │  加权因子②：曝光时长 × 常量b                       │        │
│  │  ┌──────────────────────────────────────┐        │        │
│  │  │ 含义：你在某个位置上待了多长时间           │        │        │
│  │  │ 权重逻辑：                              │        │        │
│  │  │ • 24小时中在首位待了22小时 vs 6小时       │        │        │
│  │  │ • 同样位置，时长差异导致流量差异巨大       │        │        │
│  │  │ • 常量b决定了时长在SIF中的权重            │        │        │
│  │  │                                      │        │        │
│  │  │ 💡 曝光时长是你最能影响的因子              │        │        │
│  │  │ 通过稳定出单+合理广告预算来延长           │        │        │
│  │  └──────────────────────────────────────┘        │        │
│  │                                                  │        │
│  │  加权因子③：位置前后 × 常量c                       │        │
│  │  ┌──────────────────────────────────────┐        │        │
│  │  │ 含义：你在搜索结果中的排名位置            │        │        │
│  │  │ 权重逻辑：                              │        │        │
│  │  │ • #1位的CTR >> #10位 >> #20位          │        │        │
│  │  │ • 位置越靠前 → 点击概率越高              │        │        │
│  │  │ • 位置的权重非线性递减                   │        │        │
│  │  │ • 常量c决定了位置在SIF中的权重            │        │        │
│  │  │                                      │        │        │
│  │  │ 💡 位置通过提升ECPM来改善                │        │        │
│  │  │ 提升CTR/CVR → ECPM↑ → 更好的位置      │        │        │
│  │  └──────────────────────────────────────┘        │        │
│  │                                                  │        │
│  └──────────────────────────────────────────────────┘        │
│                                                              │
│  📊 SIF vs 自然流量份额占比 vs 自然位赢得率                     │
│                                                              │
│  ┌──────────┬─────────────────────────────────────┐          │
│  │ SIF       │ 综合流量获取效率（三因子加权）         │          │
│  │ (综合)    │ = 量+位置+时长的综合评分              │          │
│  ├──────────┼─────────────────────────────────────┤          │
│  │ 自然流量   │ 你通过自然排名获得的流量               │          │
│  │ 份额占比   │ 占该关键词总流量的比例                 │          │
│  │ (占比)    │ = 你的自然点击 ÷ 该词总搜索量         │          │
│  ├──────────┼─────────────────────────────────────┤          │
│  │ 自然位    │ 你的ASIN在该词的自然位上               │          │
│  │ 赢得率    │ 出现的频率/占比                       │          │
│  │ (频率)    │ = 你出现在自然位的次数 ÷ 总监测次数    │          │
│  └──────────┴─────────────────────────────────────┘          │
│                                                              │
│  ⭐ 三者关系：                                                │
│  SIF是最综合的指标（考虑了量+位+时长）                           │
│  自然流量份额 = SIF的"结果表现"                                │
│  自然位赢得率 = SIF的"过程表现"                                │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

# 📘 Skill 4：算法打分体系 — 5大评分维度

## 4.1 五维评分模型

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  📐 关键词算法打分 — 五维评分模型                               │
│                                                              │
│  ┌──────────────────────────────────────────────────┐        │
│  │                                                  │        │
│  │  综合得分 = f(商业价值, 广告选词, 点击转化率,       │        │
│  │              流量得分, 机会指数)                    │        │
│  │                                                  │        │
│  │  满分：100分                                      │        │
│  │                                                  │        │
│  └──────────────────────────────────────────────────┘        │
│                                                              │
│  ┌──────────────────────────────────────────────────┐        │
│  │                                                  │        │
│  │  维度①：商业价值得分 ⭐⭐⭐⭐⭐ (权重最高)           │        │
│  │  ┌──────────────────────────────────────┐        │        │
│  │  │                                      │        │        │
│  │  │  衡量：该关键词能带来多少商业回报         │        │        │
│  │  │                                      │        │        │
│  │  │  评分要素：                             │        │        │
│  │  │  • 搜索量（月均搜索量）                  │        │        │
│  │  │    → 搜索量越大 → 商业价值越高            │        │        │
│  │  │  • 客单价（该词下产品的平均售价）          │        │        │
│  │  │    → 客单价越高 → 单次转化利润越大        │        │        │
│  │  │  • 购买意图强度                          │        │        │
│  │  │    → "buy wireless earbuds" > "earbuds"│        │        │
│  │  │  • 竞争度（广告竞价水平）                │        │        │
│  │  │    → 竞争度适中 → 投入产出比最优          │        │        │
│  │  │                                      │        │        │
│  │  │  📊 评分范围：0~100分                    │        │        │
│  │  └──────────────────────────────────────┘        │        │
│  │                                                  │        │
```

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  📐 综合得分计算公式                                           │
│                                                              │

│  │                                                  │        │
│  │  综合得分 = 商业价值 × W1                          │        │
│  │           + 广告选词 × W2                          │        │
│  │           + 点击转化率 × W3                        │        │
│  │           + 流量得分 × W4                          │        │
│  │           + 机会指数 × W5                          │        │
│  │                                                  │        │
│  │  W1 + W2 + W3 + W4 + W5 = 100%                  │        │
│  │                                                  │        │
│  │  ════════════════════════════════════              │        │
│  │                                                  │        │
│  │  📊 建议权重分配：                                  │        │
│  │                                                  │        │
│  │  ┌──────────────┬────────┬───────────────────┐   │        │

│  │  ├──────────────┼────────┼───────────────────┤   │        │

│  │  │ 点击转化率 W3  │  20%  │ 流量质量             │   │        │
│  │  │ 流量得分 W4    │  15%  │ 流量规模             │   │        │
│  │  │ 机会指数 W5    │  10%  │ 突破可能性           │   │        │
```

## 2.2 SIF加权因子详解

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  📐 SIF的三大加权因子                                          │
│                                                              │
│  SIF = 自然关键词流量 × a + 曝光时长 × b + 位置前后 × c        │
│                                                              │
│  ┌──────────────────────────────────────────────────┐        │
│  │                                                  │        │
│  │  加权因子①：自然关键词流量 × 常量a                  │        │
│  │  ┌──────────────────────────────────────┐        │        │
│  │  │ 含义：该关键词的搜索量大小               │        │        │
│  │  │ 权重逻辑：                              │        │        │
│  │  │ • 搜索量越大 → 流量池越大                │        │        │
│  │  │ • 即使你位置一般，大词的绝对流量也可观     │        │        │
│  │  │ • 常量a决定了搜索量在SIF中的权重          │        │        │
│  │  │                                      │        │        │
│  │  │ 💡 你不能改变搜索量                     │        │        │
│  │  │ 但你可以选择搜索量大的词来投放            │        │        │
│  │  └──────────────────────────────────────┘        │        │
│  │                                                  │        │
│  │  加权因子②：曝光时长 × 常量b                       │        │
│  │  ┌──────────────────────────────────────┐        │        │
│  │  │ 含义：你在某个位置上待了多长时间           │        │        │
│  │  │ 权重逻辑：                              │        │        │
│  │  │ • 24小时中在首位待了22小时 vs 6小时       │        │        │
│  │  │ • 同样位置，时长差异导致流量差异巨大       │        │        │
│  │  │ • 常量b决定了时长在SIF中的权重            │        │        │
│  │  │                                      │        │        │
│  │  │ 💡 曝光时长是你最能影响的因子              │        │        │
│  │  │ 通过稳定出单+合理广告预算来延长           │        │        │
│  │  └──────────────────────────────────────┘        │        │
│  │                                                  │        │
│  │  加权因子③：位置前后 × 常量c                       │        │
│  │  ┌──────────────────────────────────────┐        │        │
│  │  │ 含义：你在搜索结果中的排名位置            │        │        │
│  │  │ 权重逻辑：                              │        │        │
│  │  │ • #1位的CTR >> #10位 >> #20位          │        │        │
│  │  │ • 位置越靠前 → 点击概率越高              │        │        │
│  │  │ • 位置的权重非线性递减                   │        │        │
│  │  │ • 常量c决定了位置在SIF中的权重            │        │        │
│  │  │                                      │        │        │
│  │  │ 💡 位置通过提升ECPM来改善                │        │        │
│  │  │ 提升CTR/CVR → ECPM↑ → 更好的位置      │        │        │
│  │  └──────────────────────────────────────┘        │        │
│  │                                                  │        │
│  └──────────────────────────────────────────────────┘        │
│                                                              │

│                                                              │
│  ┌──────────┬─────────────────────────────────────┐          │
│  │ SIF       │ 综合流量获取效率（三因子加权）         │          │
│  │ (综合)    │ = 量+位置+时长的综合评分              │          │
```

```
│  │           + 机会指数 × W5                          │        │
```

## 一、算法概述

  

本算法通过对竞品Listing进行全面维度评分，结合类目竞争环境，估算每个竞品的出单概率。核心逻辑是：竞品的表现力越好，其截获搜索流量并完成转化的概率越高；竞争越激烈，每个竞品分得的流量越少。算法最终输出两个关键指标：**竞品综合得分**（反映其“攻击力/防守力”）和**相对出单概率**（反映其在类目中的份额占比）。

| T08 | V | 有产品视频/主图视频， 红人视频，评论里视频，/视频广告计20分 |

  

### 3.3 产品力维度

  

| 编号 | 维度名称 | 评分标准 |

|------|----------|----------|

| P01 | 卖家属性 | 亚马逊自营计60分；FBA第三方计40分；FBM自发货计10分 |

| P02 | 可持续性特征 | 有CPF/Green认证计20分 |

| P03 | 独特卖点 | 是否有差异化特性（材质/功能/设计/黑科技）等，可自定1-5分 |

| P04 | 配件（是否含配件/安装工具） | 含配件计15分；无计0分 |

| P05 | 其他（如Brand Story完整性） | 品牌故事完整计10分 |

  

### 3.4 竞争代理维度

  

| 编号 | 维度名称 | 说明 |

|------|----------|------|

| C01 | BSR（实际排名数值） | 通过BSR转销量；BSR #100以内计60分；#100-1000计45分；#1000-5000计25分；#5000+计8分 |

| C02 | 评论增量速率（近期评论数） | 替代LTD/LTR计算；近30日评论>30条约计100分，以此类推 |

  

其中，LTD在用户列表中出现了两次，考虑到缩写通常指“Lightning Deal”而非评论增量，评论增量部分单列为C02。

  
  

## 四、出单概率计算步骤

  

### 步骤1：数据采集与预处理

  

通过亚马逊商品详情API（SP-API）或工具获取竞品全部维度的数据。然后将连续型指标统一Map到百分制：

  

- 评论数（类目标准化法）：该竞品评论数 ÷ 该搜索词第一页中评论最多的竞品评论数 × 100

- 价格评分：100 – (竞品价格 / 该搜索词第一页最高价格 × 100)，再根据类目毛利率适当修正

- 评分：直接使用（Amazon评分本身是百分制）

  

### 步骤2：得分与排名 两步建模

  

#### 第1步：逐竞品综合营销得分(S_i)计算

  

考虑用户未明确指定各维度权重，采用等权重简算（各子维度权重在该大类下平均分配）。维度越多表示越重要的原则（信任+产品该类维度密度大、天然权重大）。

  

各亚类维度得分按以下公式计算：每个竞品 i 的的营销力得分(M_i) = M01~M13共13项的算术平均值；与信任力得分(T_i) = T01~T08共8项的算术平均值；与产品力得分(P_i) = P01~P05共5项的算术平均值。

  

最后，**综合得分**计算公式为：**S_i = 0.35×M_i + 0.35×T_i + 0.15×P_i + 0.15×C_score**，其中C_score = C01×0.5 + C02×0.5（竞争代理维度中BSR评分与评论增量评分各占50%）。

  

#### 第2步：出单概率(P_i)计算

  

出单概率并非直接等于综合得分，而是**相对竞争力份额**。一个即便表现不错的竞品，如果处在超强竞争环境，其实际出单概率也会被压制。

  

出单概率计算公式为：**P_i = (S_i / ΣS_all) × C_category × 100%**

  

其中：

- ΣS_all是该类目第一页所有竞品综合得分之和（考虑目标关键字前20-30个竞品）

- C_category是类目调整系数，一般设定为0.85，如果该类目头部垄断度高的（前5名销量占比超过70%），下调为0.70

  

#### 第3步：类目竞争环境系数计算

  

类目竞争环境系数(C_category)采用三级评估：

  

1. **集程度**（HHI指数估算）：第1页前10的销量集中度，计算方式为头部卖家销量占类目搜索第一页总预览销售量之和的比例

2. **评论门槛**：第一页竞品的中位评论数

3. **品牌种类**：第1页结果中的品牌数量，4个以上为“分散”记1.0

  

最终C_category计算方法为：典型成熟类目取值0.85；当HHI > 70%，在0.85的基础上扣除0.15（即0.70）；当评论中位数超过500条的高壁垒市场，再扣除0.10；但最低不会低于0.50。

  

### 步骤3：修正模型——促销/季节性与库存

  

在上述基础概率基础上，加入修正因子：

  

促销活跃系数(f_promo) = 1.0 +（LTD×0.10 + BD×0.15 + DOTD×0.30 + Coupon×0.05），其中各促销类型取值为0或1。

  

季节因子(f_season) = 若处于淡季取0.85，旺季取1.15，平季取1.00；库存充足系数(f_stock) = 无库存仅取0.50。

  

最终每个竞品的**动态出单概率**为：**Final_P_i = f_promo × f_season × f_stock × P_i**

  

### 步骤4：每日预计销量 换算

  

每日预计销量(Estimated Daily Units) = Final_P_i × 类目日均搜索量 × 类目平均转化率参考值（典型值3%~8%，取4.5%基线）。类目平均转化率需要通过本类目top ASIN的转化率标定。

  
  

## 五、算法公式汇总

  

**S_i = 0.35×(ΣM/13) + 0.35×(ΣT/8) + 0.15×(ΣP/5) + 0.15×[(C01+C02)/2]（等权重）**

  

**P_i = (S_i / ΣS_all) × C_category**（竞争力份额）

  

**Final_P_i = P_i × f_promo × f_season × f_stock**（动态修正）

  

**Daily_Order ≈ Final_P_i × Daily_Search_Vol × 0.045**（销量换算）

  
  

## 六、实施建议

  

1. **聚焦核心**：监控前20-30个核心竞品（每个关键字页面1-2页），避免数据过载。专业团队通常采用“核心竞品（≤10）-次竞品（≤20）-边缘竞品”三级体系，重点深度追踪核心竞品不超过20个SKU。

  

2. **第三方工具配合**：Keepa（定价历史/促销频率）、Jungle Scout（销量预估+BSR曲线）、Helium 10 Cerebro（关键词数据）可自动抓取大量数据。

  

3. **多关键字加权**：重要的关键字需要给不同关键字位置的转化概率加权平均（如位置1-10、11-20等）。

  

4. **BSR-销量映射验证**：销量估算工具的误差率通常控制在±15%左右。Jungle Scout会结合BSR排名、历史销售曲线等8个维度建模。关键是要进行**三角验证**：将BSR趋势、评论增速和收入逻辑三者相互印证，而不仅仅依赖单一维度。

  

5. **定期更新**：BSR每小时更新一次，每日/周/月度循环监控竞品的价格、促销、评论变化。最新BSR算法除销量外还考虑转化能力、退货率、运营精细化程度和页面内容吸引力。

## 一、营销力维度（13项）

  

这些是竞品在搜索页面上能直接吸引点击和转化的营销信号。

  

### 1. 图片（主图数及质量）

- **是什么**：指商品详情页的图片数量和质量。亚马逊允许最多7-9张图片（含主图、附图、视频封面）。

- **判断标准**：7张满图 + 有视频 → 高分；只有1-3张基础图 → 低分。

- **影响逻辑**：图越多、质量越高，转化率越高，说明该竞品listing维护专业，出单能力更强。

  

### 2. 移动端缩略图（图片）

- **是什么**：在手机端搜索结果或详情页首屏，主图会被裁剪成正方形或长条缩略图。用户滑动时第一眼看到的就是这个。

- **判断标准**：缩略图上的产品主体是否清晰、信息是否突出（例如有简洁文字、场景化）。

- **影响逻辑**：移动端流量占比超60%，缩略图不清晰会极大降低点击率，导致几乎没有出单机会。

  

### 3. 价格

- **是什么**：当前实际售价（非划线价），美元显示。

- **判断标准**：与类目均价对比。低于均价10%以上为优势；持平为中性；高于20%以上为劣势。

- **影响逻辑**：价格直接影响转化率。低价常对应高销量，但也要结合品牌定位。

  

### 4. 折扣

- **是什么**：显示“List Price 被划掉，Sale Price 更低”的挂牌折扣比例（例如原价$29.99，现价$19.99，折扣33%）。

- **判断标准**：只要显示大幅折扣标志（通常≥20%），就加分。

- **影响逻辑**：大折扣标签能刺激冲动消费，提升转化。

  

### 5. 促销

- **是什么**：是否参与**LTD / BD / DOTD**三种限时促销活动（见后文详解）。注意此处的“促销”是统称，可能指代这些秒杀。

- **判断标准**：如果当前正参加任何秒杀，计分。

- **影响逻辑**：秒杀期间流量倾斜、转化率飙升，出单概率显著高于平时。

  

### 6. Prime价格（$）

- **是什么**：只有Prime会员才能看到的专享价，价格下方会显示“Prime Price”和蓝色徽章。

- **判断标准**：显示Prime专享价（通常比普通售价低几美元）。

- **影响逻辑**：Prime会员是核心购买群体，专享价能提高他们的转化率。

  

### 7. Coupon

- **是什么**：绿色优惠券标签，一般显示为“Save XX% with coupon”或直接减金额。

- **判断标准**：页面有可见的Coupon复选框。

- **影响逻辑**：Coupon有高辨识度，可带来额外点击和转化，且能提升搜索排名。

  

### 8. 标题

- **是什么**：商品标题，最多200字符（服装类等有不同限制）。包含核心关键词、品牌、属性、型号等。

- **判断标准**：是否超过200字符、是否包含高搜索量关键词、结构是否清晰。

- **影响逻辑**：标题是亚马逊搜索权重最高的文本元素，关键词缺失直接导致曝光少，出单概率极低。

  

### 9. 移动端的广告要素

- **是什么**：在移动端搜索结果页，该竞品是否通过广告（SP/SB/SBV/SD）占据“Sponsored”位置，以及出现在首页顶部等高转化位置。

- **判断标准**：有广告且在优质广告位（顶部、中部、详情页内）。

- **影响逻辑**：广告位置带来大量额外曝光，是主动抢单的手段，意味着该竞品在主动攫取流量，对其他自然位竞品威胁很大。

  

### 10. 品牌

- **是什么**：商品所属品牌的知名度和信任度。

- **判断标准**：安克、苹果等知名大牌；有一定搜索量的品牌；完全不知名品牌。

- **影响逻辑**：品牌知名度直接影响点击率和转化率，大牌自带流量，出单概率天然更高。

  

### 11. BD（Best Deal，超级镇店之宝/周秒杀）

- **是什么**：持续7~14天的促销活动，免费（不向普通卖家开放，通常需要招商经理邀请或系统推荐）。展示“Limited time deal”横幅，价格处无进度条。

- **判断标准**：当前正参与BD。

- **影响逻辑**：BD持续久，能稳定拉升销量和排名，是竞品长期霸榜的重要手段。

  

### 12. LTD（Lightning Deal，限时秒杀）

- **是什么**：持续4~6小时（Prime Day可达12小时）的快速秒杀，需付费（$150~$500/次）。有进度条和“XX% claimed”提示。

- **判断标准**：当前正参与LTD。

- **影响逻辑**：时效性极强，短时间内冲单量，能瞬间抢走同页大量订单。

  

### 13. DOTD（Deal of The Day，镇店之宝/每日秒杀）

- **是什么**：全站当日仅3个广告位，显示在Deals首页顶部，持续24小时，不向普通卖家开放，条件极苛刻。

- **判断标准**：竞品出现在“Today‘s Deals”黄金展位。

- **影响逻辑**：流量巨大，一个DOTD可能贡献数千单，会严重挤压同关键词下其他竞品的出单概率。

## 二、信任力维度（8项）

  

这些要素消除用户顾虑，是把流量转化为订单的“临门一脚”。

  

### 1. 评论数

- **是什么**：商品积累的总评论数量。显示为“XX ratings”或“XX global ratings”。

- **判断标准**：超过300条为高评论屏障；低于50条为新链接。

- **影响逻辑**：评论数是社会证明，数量越多，消费者越信任，转化越高。

  

### 2. 评分

- **是什么**：1到5星的平均分，显示在标题下方。

- **判断标准**：≥4.5为优；4.2-4.4为良；低于4.0风险上升。

- **影响逻辑**：评分直接影响转化率，低于4星会导致该竞品出单能力骤降。

  

### 3. 亚马逊销量标志

- **是什么**：指两种：①**Best Seller（BS）徽章**（橙色小标签，小类第一）；②**月度销量标签**如“10K+ bought in past month”（红色，非BS独有）。

- **判断标准**：有BS标识或高销量标签。

- **影响逻辑**：直接传递“很多人买”的信号，是极强的转化催化剂。

  

### 4. AC（Amazon’s Choice，亚马逊推荐）

- **是什么**：黑色徽章，显示“Amazon‘s Choice for [关键词]”。AI根据近期销量、评分、退货率等自动授予。

- **判断标准**：竞品在当前关键词下拥有AC标识。

- **影响逻辑**：AC链接在语音购物和推荐中占优，点击率和转化率远高于普通链接。

  

### 5. NR（New Release，新品热销）

- **是什么**：橙色徽章，标记在新品榜表现最好的商品上。

- **判断标准**：竞品带有“#1 New Release”或类似标签。

- **影响逻辑**：表明该新品冲量迅速，势头凶猛，未来可能成为主要威胁。

  

### 6. ABS（Amazon’s Brand Store，品牌旗舰店）

- **是什么**：商品标题下出现“Visit the XX Store”链接，可跳转到品牌旗舰店。

- **判断标准**：已建立品牌旗舰店并关联此ASIN。

- **影响逻辑**：代表品牌有备案、有一定投入，增加专业感，略提升转化。

  

### 7. A+（A+ Content，图文增强描述）

- **是什么**：在产品描述部分出现的图文模块（如对比图、场景图），替代纯文字。Premium A+更具互动性。

- **判断标准**：详情页是否有丰富的图文描述。

- **影响逻辑**：A+页面可提升转化率5%-15%，是该竞品精细化运营的标志。

  

### 8. V（Video，视频）

- **是什么**：指主图区的视频（第7张图位置）或相关视频短片。

- **判断标准**：主图区有播放按钮可播放产品视频。

- **影响逻辑**：视频能直观展示产品使用场景，极大提升停留时间和转化。

## 三、产品力维度（5项）

  

这些是产品本身和卖家服务的硬实力。

  

### 1. 卖家属性

- **是什么**：销售方是谁？可看“Ships from / Sold by”。

- **判断标准**：Amazon自营 > FBA第三方 > FBM自发货。

- **影响逻辑**：自营和FBA有Prime配送保障，转化率远高于自发货。

  

### 2. Sustainability features（可持续性特征）

- **是什么**：主要指标为**CPF（Climate Pledge Friendly，气候承诺友好）** 绿色叶子徽章，或其它环保认证。

- **判断标准**：有CPF标识即得分。

- **影响逻辑**：迎合环保理念，对部分用户群体有额外吸引力。

  

### 3. 独特卖点

- **是什么**：产品是否有差异化特性，例如独家专利功能、特殊材质、创新设计等。

- **判断标准**：通过标题、图片和A+内容定性判断。

- **影响逻辑**：有独特卖点的竞品难被替代，转化率高且价格敏感度低。

  

### 4. 有没有配件

- **是什么**：售卖时是否附带必需或增值的配件（如电子产品的充电器、安装工具、备用零件）。

- **判断标准**：查看附图或描述中是否展示所有配件。

- **影响逻辑**：套装组合常能提供更高感知价值，促进决策。

  

### 5. 其他

- **是什么**：您列表中“其他”可包含品牌故事完整性、产品说明书质量等。这里我将其定位为**Brand Story**（品牌故事模块）。

- **判断标准**：A+描述中是否有专门的“From the Brand”故事模块。

- **影响逻辑**：强化品牌认知，微转化提升。

## 四、竞争代理维度（C类）

  

用于把销量信号纳入得分，修正纯表面维度的评估。

  

### 1. BSR（Best Sellers Rank，畅销排名）

- **是什么**：每个商品在所属小类（及大类）下的销量排名，数值越小销量越大。

- **判断标准**：BSR #1-100为头部；#100-1000为腰部；#1000以上为长尾。

- **影响逻辑**：BSR直接反映近期销量速度，是预测出单最核心的代理变量。在算法里，我把“BS”徽章放在信任力，**BSR数值则作为竞争代理计算**，用来计算C01得分。

  

### 2. 评论增量速率（C02）

- **是什么**：近30天新增的评论数量，反映近期销量热度。

- **判断标准**：例如近30天增30+条评论 → 高分。

- **影响逻辑**：弥补BSR只能看排名不能看绝对销量的缺点。评论增量和销量高度正相关，能发现正在迅速起量的竞品。

根据亚马逊官方定义，`Sustainability features` 是指在产品生命周期中，经第三方认证的、有助于保护自然环境的属性。它主要以 **“气候友好承诺” (Climate Pledge Friendly, CPF)** 计划的形式呈现，这是一个认证聚合平台，产品需获得至少一项亚马逊认可的超过50种的第三方或自创认证。

  

### ⚙️ 与算法评分标准的关系

  

获得该标签的产品会在前台展示一个**绿色叶子**图标，并因此拥有**专属的流量入口**，可提升**10-30%的精准曝光**。

  

因此，在竞品分析算法中：

*   **直接影响**：在“**产品力**”维度评分，拥有此标签的竞品加 **20分**。

*   **间接影响**：高曝光会拉升点击率与转化率，间接提升其**广告力、信任力**维度的最终得分，从而显著提升其“**出单概率**”。

  

### 📜 认证与属性清单

  

*   **第三方认证**：逾50项全球标准，涵盖：

    *   **综合/化学品**：Climate neutral by ClimatePartner、SCS Global Services、Green Seal。

    *   **材料**：GRS (全球回收标准)、RCS (回收声明标准)、FSC (森林)、GOTS (有机纺织品)。

    *   **电子/节能**：ENERGY STAR (能源之星)、EPEAT、TCO。

    *   **家具/劳保**：BIFMA LEVEL、bluesign、Cradle to Cradle。

*   **亚马逊自有认证**：新锐自有标准涵盖：Compact by Design (紧凑包装)、Pre-owned Certified (二手认证)、Plant-Based Fiber Blends (植物纤维混纺)。

*   **覆盖站点**：已覆盖美、加、欧等 **14个** 国家站点。

  

### 🔍 视觉标识与消费者体验

  

在亚马逊购物时，可通过以下特征辨别CPF认证商品：

*   **搜索结果页**：产品标题下方显示绿色叶子图标，并伴随“可持续发展特性”文字标签。

*   **筛选方式**：搜索后，通过筛选器直接勾选“Climate Pledge Friendly”筛选所有认证商品。

*   **商品详情页**：五点描述和价格区块上方清晰展示绿色叶子标志，点击可查看该产品获得的具体认证名称（如GRS, Energy Star）及可持续特性（如有机成分、再生材料、低碳影响等）。
