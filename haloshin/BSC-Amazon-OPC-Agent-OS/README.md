# BSC OPC Agent OS — Personal Edition

Amazon 产品运营一站式工具：GPT Image-2 图片生成 + COSMO/Rufus 算法 Listing 优化。

## 功能

### 产品素材生成
- 输入 ASIN 自动采集 Amazon 产品图片
- 支持手动拖拽上传产品参考图
- 自动生成 5 组 GPT Image-2 提示词（主图 / A+ 场景 / 细节特写）
- 一键生成产品图片并下载 PNG / PSD
- 复制按钮在文本框右侧，点击直接复制

### Rufus & COSMO 专家建议
- **标题优化** — COSMO 结构评分 + 关键词缺口分析 + 优化建议
- **五点分析** — 每条 Bullet 独立 COSMO 评分 + 中英文优化建议
- **Q&A 建议** — 8 组 Rufus 友好的中英双语问答
- **卖点提炼** — COSMO 强度评估 + Top 3 核心卖点
- **数据洞察** — Listing 健康评分仪表盘 + 关键词覆盖 + 行动建议

### 系统功能
- 软件激活系统（免费试用 3 天 + 密钥激活 + 机器码绑定）
- API / MCP 连接测试（APIMart / SIF / Sorftime / 卖家精灵）
- 设置界面密钥脱敏显示 + 加密存储（AES-256-GCM）
- 系统初始化引导（注册链接 + 配置步骤）
- 缓存清除 + 任务进度计时器
- 微信客服二维码 + 公众号二维码 + 知识星球二维码

## 使用方法

### 运行
双击 `BSC-OPC-Agent.exe`，浏览器自动打开 `http://127.0.0.1:5173`。

### 首次使用
1. 弹出激活窗口 → 选择「免费试用 3 天」或输入激活密钥
2. 点击「系统初始化」→ 按步骤注册 API/MCP 服务
3. 在设置界面填入 API Key，测试连接
4. 输入 ASIN → 开始采集 → 生成图片

### 激活流程
用户: 复制机器码 → 发送给客服
客服: 生成密钥 → 发给用户
用户: 粘贴密钥 → 激活 → license.key 写入本
下次启动自动验证，无需重新激活
