我们内部做竞品研究，经常同时存在两份材料：一份是飞书里的方向模板，一份是几百张表堆出来的 HTML 报告。前者告诉你怎么讲，后者告诉你证据在哪。麻烦的是这两者经常对不上——报告越做越厚，上台却讲不出结构。

这篇文章分享一下我们是怎么用飞书那份方向模板去审查一份完整竞品 HTML 报告的，以及审下来发现模板还该补的四块。

先说清材料边界：飞书里那份是 SALIA GIRL 少女训练文胸的汇报导图，作用是方向模板和方法示例；HTML 是 adidas 美国站童鞋、研究 ASIN `B0CPS5LXXZ` 的研究报告，证据截至 2026-11-16。两个品类不是一回事，文胸案例里的数字只用来说明方法，不会被搬进童鞋报告。

## 一、竞品报告不是把数据堆完就结束

那份童鞋报告本身不算粗糙：59 张表、17,704 行、520 个 Google 周指数，十章结构也接近飞书的十段汇报。但第一版最大的问题不是数据不够，而是「讲不清」——口径散在第九章，结论散在各章末尾，一个听众听完记不住我们要验证什么、已经能说什么。

飞书模板解决的正是这件事：它不要求你多算，它要求你在每一段都同时写清「还要验证什么」和「现在能上台讲什么」。

## 二、飞书模板的骨架

**五条主线**：流量、趋势、变体、属性、毛利。所有分析最后都要回到这五条线上，不能停在中间某个有趣的数字上。

**十段汇报顺序**：开场结论；口径和数据范围；类目季节与需求；链接生命周期与流量结构；关键词战场；变体定价与畅销榜；六条对标与演进路线；VOC 与截词；两版毛利测算；建议与下一步。这个顺序的价值在于，听众先知道结论和边界，再听证据，不会在第一页就被口径问题带走。

**九宫格总表**：板块 / 要验证的问题 / 可拿出讲的结论。九个板块逐格填，填不满的地方就是这轮研究的缺口。这一步比写正文更有用，因为它逼你把假设和结论分开摆。

**几条证据纪律**，我们认为比任何图表都重要：

- Keepa 月销不是实际成交；
- 词数不等于花费；
- 转化分享率不是 CVR；
- Google Trends 只校验季节，不估算销量；
- 分析与测算分开，测算要写清假设；
- 只研究，不改预算、不改出价。

## 三、用童鞋 HTML 报告对照：哪里站住了，哪里还空着

先说站住的部分。2026-10 单 ASIN 流量同比 69.3%，Listing 同比 153.9%，近 12 个月 Listing 订单分档估值 75,300，增长这件事是有证据的。近 30 日 Listing 自然份额 98.5%，研究 ASIN 自然份额 100%，但**研究 ASIN 只占整条 Listing 流量的 5.7%**；近 30 日流量第一的变体是 `B0CCQ12NRH`，占 26.6%，不是我们研究的这一条。这就把「增长发生在哪里」讲清楚了：增长在 Listing 族，不在单个 ASIN。

再往下是获客成本。两个头词的市场建议 CPC 分别是 1.06 和 1.53 美元，而按 30% 毛利情景算出来的盈亏平衡点大约只有 0.10 和 0.13 美元；按市场平均转化率折算，隐含 ACOS 超过 300%。所以判断只能写「继续研究，不直接放量」——不是这个品不能做，而是用头词的正价去起量，账算不过来。

空着的结构也很明确：

- 没有本品快照卡，售价、星级、评论数、BSR、变体规模散在各处；
- 口径压在第 09 章，听众要读到后面才明白哪些数不能混算；
- 缺流量阶段叙事，只有同比和月度曲线，说不清哪一段是自然起量、哪一段广告占比抬高；
- 流量没有按「自然 / SP 常规 / SP 推荐 / SB / SBV」拆开；
- 没有词簇，只有词表；
- 多变体自然位只有一个附加结论，没有独立成板块；
- VOC 是空的（报告明确拒绝编造痛点，这点做得对，但缺口要写出来）；
- 毛利只有一次 CPC 压力测试，没有两版费用假设。

## 四、模板还要补的四块

对照下来，飞书模板本身也在迭代。这次我们把四块方法补了进去。

**第一块，卖家后台 V3 属性底表。**

V3 指的是卖家后台商品类型（Product Type）的官方属性，不是前台标题和五点描述的同义词。做法是先出「字段完整率 / 与前台冲突率」两张表，再做「ASIN × 关键字段」矩阵。和前台冲突的地方并列写，不偷偷选一边。

文胸那份的交付结构是 53 个 ASIN、67 个顶层字段、4074 条取值明细——这是交付结构的示例，不是童鞋的数据；童鞋要按自己的实际导出重做。童鞋侧优先核对：性别定位、年龄段、尺码体系（Infant / Toddler）、闭合方式、趾型与鞋头、鞋面材料、Wide 等特殊尺寸、用途。包装短边留给 FBA 尺寸分段，鞋类要按鞋类规则核，不能套服装阈值。

**第二块，两条聚类线，结果不能混。**

属性聚类服务产品路线：用核过的 V3 分水岭字段，把主力变体和头词竞品聚成少数路线（常规 Court 轮廓、宽头 / 赤足、通用运动、一脚蹬、偏男 / 偏女等），输出「簇 — 代表 ASIN — 价格带 — 规模 — 自然份额线索」，再画一张价格 × 路线的散点。这张图直接回答「真正分开对手的是哪条属性，而不是哪个价格带」。

词聚类服务战场：把近 7 日自然流量词和 SP 广告搜索词分开聚，分成类目核心词、人群 / 场景词、泛词、品牌词、可能串类目的词。每簇给词数、贡献占比、代表词。分母是该窗口该渠道的总贡献，不是全部流量，更不是花费。文胸案例把那 149 个 SP 常规广告搜索词按核心词、通用词、大词、品牌词上色，方法可以照搬，但要换成童鞋自己的词表。

**第三块，广告竞争难易程度。**

现在报告里只有两个头词的压力测试，方向对，但还不够叫「类目广告难易」。要升级成一张核心词清单，并且把三个口径分列，禁止混算：

- 类目核心关键词 CPC：来自广告后台的建议出价或竞价参考，不是竞品真实花费；
- 广告点击转化率：广告点击到购买的转化，不是自然转化；
- 类目平均转化率：来自商机探测器的市场平均，通常只含搜索页直接点击和购买、24 小时归因、同时含自然和广告。

盈亏平衡 CPC 的计算不复杂：售价 × 假设毛利率 × 所用的转化率。关键是**用哪个转化率必须写死在表头**——诊断广告好不好打，优先用广告点击转化率；没有的话才用类目平均，并标明这是压力测试，不是本品表现。

难易只分「易 / 中 / 难」，并且给判定规则。童鞋这两个头词按市场平均转化率折算，隐含 ACOS 已经超过 300%，归「难」。文胸案例里也能看到类似的方法论：`bralette` 搜索量大但市场平均转化率 2.83%，`girls bras` 搜索量小、转化率 5.19%——大词不等于好战场。这个结论只用于说明方法，数字不往童鞋报告里搬。

**第四块，品类类目诊断七问。**

把需求、供给、属性簇和广告难易收成一页，每问都写「已证实 / 待验证 / 建议」：

1. 战场有没有用对——不能拿过大的父类目判断机会；
2. 需求是否持续，季节怎么用；
3. 价格带和供给——小类畅销榜、价格中位数；
4. 集中度与品牌壁垒——兄弟变体已经占住头词自然位，不等于没有壁垒；
5. 属性白区——哪条路线拥挤，哪条还只有标题线索；
6. 广告好不好打——引用上一节的难易表，头词难不代表所有词簇都难；
7. 进入建议怎么收口。

## 五、还缺哪些导出，以及现在能说什么

要补齐上面四块，至少需要这些材料：卖家后台 V3 属性全量归纳（研究 Listing 主力变体 + 头词主要竞品）；广告后台的类目核心词 CPC 与广告点击转化率；商机探测器里的核心词转化率和推荐竞价；VOC 原始评论（带样本和分母）；以及真实费用（采购、头程、FBA、退货、汇率）。可选但很有用的还有流量位竞品数、小类畅销榜和前台变体表。

在这些东西进来之前，我们不会把结论往上调。现在能说的是：增长已经发生，进入难点在变体承接与获客成本，判断是**继续研究，不直接放量**。

补证之后，这个判断大概率还是它。真正会变的是我们能回答的问题变具体了：该打哪一个小类和词簇、新品该对标哪几个变体和哪条属性路线、哪些相关词值得用更严的费用假设做小规模验证。而不是拍一句「可以进」。

模板的价值不在于让报告更长，而在于让每一段都能回答：要验证什么，现在能讲什么。
