# 6. ｜Shopify与WordPress 独立站卖家的GEO技术基建指南

大家好，我是饼干哥哥。

我遇到过一个做高端宠物用品的卖家，他在Shopify上的产品页设计得精美绝伦，图片全是4K高清大片，视频拍得像电影。他觉得自己的品牌溢价很高，应该被AI优先推荐。

但是，当他在ChatGPT里输入 **推荐一款适合大型犬的防爆冲胸背带** 时，AI推荐的全是他的竞品。更让他崩溃的是，当他强制把自己的产品链接发给AI让其分析时，AI竟然给出了一个致命的评价：**该产品退货政策不明，发货时效未知，建议谨慎购买。**

他当时就气炸了，指着屏幕吼道：**我的退货政策明明写在页脚啊！全站包邮明明写在公告栏啊！这AI是不是瞎？**

**在AI眼里，你的产品就是残次品。**

AI看不懂你精美的图片，也看不懂你写在页脚的那些为了应付法律合规的小字。在AI的视觉系统里，你的网页不是像素，而是一行行代码。如果你的退货政策只是写在页脚的一段文本，而不是写在代码里的**结构化字段**，AI就是看不见。

**字段缺失就等于信息不透明，信息不透明就等于低置信度，低置信度就等于不推荐。**

上一篇我们讲了如何通过**统计数据**和**权威引用**来优化你的文案内容。今天这篇，我们要进入更底层的技术深水区。我们要解决的是身份确认的问题。你需要掌握两门机器语言：**Schema结构化数据** 和 **Feed数据流**。

无论你是用Shopify还是WordPress，这套逻辑都是通用的。这是你给AI发的一张**数字身份证**。

### 你的网页在AI眼里只是一行行代码

很多人以为AI推荐商品是像人一样在逛淘宝，看谁的图好看。大错特错。

AI推荐商品的底层逻辑，主要依赖于**Google Shopping Graph**和**知识图谱（Knowledge Graph）** (1)(2)。这是一个庞大的数据库，里面存储着数十亿产品的属性。

当用户问AI问题时，AI不是去现场爬你的网页，而是去这个数据库里调取数据。如果你的数据在Graph里是残缺的，比如缺少GTIN码，缺少退货字段，AI就会认为你是一个**信息不全的高风险商家** (3)。

你需要做的是**实体消歧（Entity Disambiguation）和建立信任（Trust）**。

你需要用代码明确告诉AI：**我是谁，我卖什么，我的服务承诺是什么。**

### Schema实战：给AI发一张数字身份证

Schema，也就是结构化数据，是搜索引擎和AI都能读懂的通用语言。它把**给人看的信息**翻译成**给机器看的信息**。

比如，把网页上写的**30天无理由退货**翻译成代码 `returnWindow: P30D`。

对于独立站卖家，你必须配置以下三个核心Schema。

#### Organization Schema：品牌身份认证

这是告诉AI**我是谁**的关键。很多品牌名字很普通，容易和别的东西混淆。比如你的品牌叫 **Apple**，你不做Schema，AI怎么知道你是卖水果的还是卖手机的？

**关键配置：**

- **@type**: Organization

- **name**: 你的品牌全名

- **logo**: 品牌Logo的绝对路径URL

- 

- **sameAs**: 这是核心中的核心 (4)。

- 

GEO技巧：

利用 sameAs 属性，把你所有的社交媒体（Facebook, Instagram, LinkedIn）、维基百科条目、Crunchbase链接都填进去。这叫实体消歧。你是在告诉AI：这个Facebook账号、这个Wiki页面、这个官网，都是同一个实体。 5

这样AI在全网搜集关于你的评价时，就不会张冠李戴。

#### Product Schema：产品参数表

这是告诉AI**我卖什么**。

**关键配置：**

- **@type**: Product

- **name**: 产品名称

- **description**: 产品描述

- **sku**: 库存单位

- **brand**: 品牌

- **gtin**: 全球贸易项目代码（UPC/EAN）。**注意，这是Google和AI识别产品的唯一身份证。**如果没有GTIN，你的产品在Shopping Graph里就是黑户 (6)。

**WordPress（WooCommerce）避坑指南：**

WooCommerce默认生成的Schema往往缺胳膊少腿。它可能只生成了最基础的字段，缺了 gtin 和 mpn。你需要安装专业的SEO插件，如 Rank Math 或 Yoast SEO，并进入设置页面，手动开启并补齐这些字段 78。

**Shopify避坑指南：**

Shopify最容易出问题的是多变体（Variants）产品。比如你有一件衣服，红色卖99元，蓝色卖109元。

很多默认的主题代码只会抓取一个主价格。导致AI抓取的信息是红色衣服卖99元，结果用户点进去选蓝色发现是109元。这会被Google判定为价格欺诈 9。

你必须修改 `product.liquid` 代码，使用 `for` 循环遍历每一个 Variant，为每一个变体生成一个独立的 **Offer** 对象 (10)。

代码逻辑如下：

Code snippet

```
"offers": [
  {% for variant in product.variants %}
  {
    "@type": "Offer",
    "price": "{{ variant.price | money_without_currency }}",
    "priceCurrency": "{{ shop.currency }}",
    "sku": "{{ variant.sku }}",
    "availability": "http://schema.org/{% if variant.available %}InStock{% else %}OutOfStock{% endif %}"
  }{% unless forloop.last %},{% endunless %}
  {% endfor %}
]
```

只有这样，AI才能精准地回答：**这款衣服红色99元，有货；蓝色109元，缺货。**

#### 商业信誉：用代码证明你靠谱

AI为什么不敢推荐你？因为怕被用户骂。如果AI推荐了一个不发货或者不退款的商家，用户会怪AI不智能。

所以，AI极度看重 **MerchantReturnPolicy（退货政策）** 和 **ShippingDetails（物流详情）** (11)(12)。

退货政策配置：

不要只把退货政策写在Terms页面里。要在 Product Schema 里嵌套 MerchantReturnPolicy 对象。

你需要明确写入：

- **returnFees**: 退货费用（是免费还是消费者承担）

- **returnMethod**: 退货方式（邮寄还是到店）

- **returnWindow**: 退货窗口期（比如P30D代表30天）

物流时效配置：

AI会根据用户的IP地址（比如用户在纽约）来回答到货时间。你需要配置 ShippingDeliveryTime。

把网页上模糊的 3-5 days 变成可计算的结构化数据：

- **handlingTime**: 发货处理时间

- **transitTime**: 运输路途时间

当你的代码里有了这些数据，AI就敢信誓旦旦地告诉用户：**这家店支持30天退货，发货到纽约只需要3天。** (13)

### Feed进阶：Feed不仅是广告，它是AI的实时库存

很多卖家以为 Google Merchant Center (GMC) Feed 只是用来投Google Shopping广告的。

错。Feed 是 **Google Shopping Graph** 的最主要数据源。Gemini 和 SGE 生成的商品推荐，80% 来自这里 (14)。

**数据一致性（Data Consistency）是GEO的红线** (15)(16)。

如果你的网页上写价格 $99，但Feed里因为更新延迟写着 $89，或者Schema里写着 $109。Google会认为你在欺诈，直接给你降权，甚至封号。

**确保 Schema ↔ Feed ↔ 页面文案 三位一体，是AI信任你的基础。**

Shopify实战：

不要用第三方的不知名插件。直接使用Shopify官方的 Google & YouTube Channel App 17。它是最稳定的管道。

注意： 安装了不等于做好了。你必须进入App内部，手动配置 Google Product Category。AI需要这个分类来理解你的产品到底属于哪一类。如果你不填，AI可能会把你的**苹果（手机）归类到苹果（水果）**里去。

WordPress实战：

使用 WooCommerce Google Listings & Ads 官方插件 18。

重点检查：GTIN 和 MPN 字段是否为空。WooCommerce后台默认可能隐藏了这些字段，你需要把它们调出来填好。没有GTIN的Feed，在AI眼里就是垃圾数据。

### 防守策略：管理你的AI访问权

做好了数据，还要管好门。不是所有爬虫都是好人。

有些AI爬虫是来偷你的数据去训练模型的（比如Common Crawl），有些是来给你送流量的（比如Googlebot, Bingbot）。

你需要精细化管理 **robots.txt**。不要一刀切地屏蔽所有AI，那样你就真的隐身了。你需要利用 **AI Traffic Control Center** 这样的插件（针对WP）或者手动修改文件，允许 **GPTBot** 和 **Google-Extended** 访问你的高价值页面 (19)(20)。

llms.txt：未来的标准

这是一个新兴的标准文件，专门写给LLM看的 21。

你可以创建一个 yourdomain.com/llms.txt，在里面列出你最希望AI读取的页面URL列表（如：品牌故事、核心产品页、FAQ）。

这相当于给AI发了一份官方阅读指南。你告诉AI：别瞎逛了，精华都在这儿，读这些就够了。

### 从网页到API：认知的升级

做好了Schema和Feed，你的网站就不再只是一个给人看的**网页**，而变成了一个给机器读的**API接口** (22)(23)。

在AI时代，**可读性 = 可见性**。

只要你的字段够全、数据够准，AI就会把你当成最可信的**事实源（Source of Truth）**，在合成答案时优先调用你的数据。

文字和数据我们都搞定了。

但是，DTC品牌最吸引人的往往不是冷冰冰的参数，而是**视觉冲击**。

你的那些精美的产品图，你的那些充满激情的开箱视频，AI能看懂吗？如果AI是个盲人，你的视觉资产就浪费了。现在的多模态模型（Multimodal Models）已经具备了看图和看视频的能力，但它们需要你的引导。
