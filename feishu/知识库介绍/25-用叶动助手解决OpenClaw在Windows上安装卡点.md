### 4.常见问题及解决方案

#### 问题一：npm error code 128

**错误信息：**

npm error code 128

npm error An unknown git error occurred

npm error command git --no-replace-objects ls-remote ssh://git@github.com/whiskeysockets/libsignal-node.git

npm error git@github.com: Permission denied (publickey).

npm error fatal: Could not read from remote repository.

**原因：**

- OpenClaw 的依赖包 `libsignal-node` 使用 SSH Git URL ( `ssh://git@github.com/...` )

- 系统未配置 GitHub SSH 密钥，导致权限被拒绝

> **解决方案：**

# 方案1：配置 Git 使用 HTTPS 替代 SSH

> git config --global url."https://github.com/".insteadOf "ssh://git@github.com/"

> git config --global url."https://github.com/".insteadOf "git@github.com:"

# 然后重新安装

> npm install -g openclaw

---

#### 问题二：安装超时

**错误信息：**

Error: Timeout

**原因：**

- 网络连接缓慢

- 依赖包较多，下载时间过长

> **解决方案：**

# 方案1：使用国内镜像

> npm install -g openclaw --registry=https://registry.npmmirror.com

# 方案2：配置 npm 镜像

> npm config set registry https://registry.npmmirror.com

> npm install -g openclaw

---

#### 问题三：安装后命令不可用

**错误信息：**

'openclaw' 不是内部或外部命令，也不是可运行的程序

或批处理文件。

**原因：**

- npm 全局模块路径未添加到系统 PATH 环境变量

- 安装未成功完成

> **解决方案：**

# 检查 npm 全局路径

> npm root -g

> 输出通常是：C:\Users\<用户名>\AppData\Roaming\npm

> 将以下路径添加到系统 PATH：

> C:\Users\<用户名>\AppData\Roaming\npm

# 或者重新安装

> npm install -g openclaw

---

#### 问题四：安装过程出现弃用警告

**错误信息：**

npm warn deprecated safe-buffer@5.2.1...

**原因：**

- 部分依赖包使用了已弃用的 API

- 这是警告，不影响安装和使用

> **解决方案：**

- 可忽略这些警告

- 或使用 `--legacy-peer-deps` 参数安装：

> npm install -g openclaw --legacy-peer-deps
