## 前言：

## 为什么要学定时任务？

想象一下这些场景：

- **场景1 **：你每天早上都要手动让 AI 帮你整理新闻，忘记了就错过重要信息

- **场景2 **：你想让 AI 每2小时提醒你喝水，但总是忘记发指令

- **场景3 **：你睡前给 AI 布置了一个复杂任务（比如分析100篇文章），希望明早起来看到结果

**如果 AI 能像闹钟一样，到点就自动执行，该多好？**

好消息是：OpenClaw 的定时任务就是这么简单！ **不需要写代码，只需要自然语言即可，就像跟真人讲话一样。**

---

## 一、定时任务是什么？（超简单理解）

### 1.1 一句话解释

**定时任务 = 给 AI 设闹钟**

你给手机设过闹钟吗？

- 早上7点 → 闹钟响 → 叫你起床

- 每周一早上9点 → 闹钟响 → 提醒你开会

OpenClaw 的定时任务完全一样：

- 早上8点 → AI 自动发送新闻简报 → 推送到你的 Telegram

- 每30分钟 → AI 提醒你喝水 → 发送消息给你

- 明天凌晨3点 → AI 分析数据 → 早上你醒来看到结果

### 1.2 定时任务能做什么？（超实用清单）

| 场景 | 定时任务效果 |
|---|---|
| 早安简报 | 每天早上8点，AI 自动抓取新闻+天气+日程，发给你 |
| 健康提醒 | 每2小时提醒喝水、每小时提醒休息眼睛 |
| 数据日报 | 每天晚上10点，AI 自动分析当天数据，生成报告 |
| 信息监控 | 每小时检查竞争对手动态，有变化立即通知 |
| 日程提醒 | 每周五下午5点，AI 生成本周工作总结 |

**最酷的是 **：这些任务创建后，AI 会在后台自动运行。 **你睡觉的时候，AI 也在工作。**

## 二、定时任务的工作原理

在动手创建任务之前，先花1分钟了解一下定时任务是怎么工作的。这样遇到问题你能知道原因。

---

### 2.1 心跳机制：定时任务的"脉搏"

#### 通俗理解

想象 Gateway 是一个 **值班室 **：

- 定时任务是写在值班室黑板上的 **任务清单**

- **心跳 **= 值班室每隔几秒敲一次锣，告诉大家"我还在值班！"

**为什么需要心跳？**
 如果没有心跳（值班室不敲锣了），即使任务时间到了，也 **没人去执行任务 **。

#### 心跳与定时任务的关系

| 场景 | 有心跳 | 没心跳 |
|---|---|---|
| Gateway 运行中 | ✅ 任务准时执行 | - |
| Gateway 崩溃了 | - | ❌ 任务不会执行，且你不知道 |
| 电脑休眠了 | - | ❌ 任务错过执行时间 |
| 网络断开了 | - | ❌ 任务无法投递 |

#### 检查心跳状态

**你问 AI：**

```
请帮我检查 Gateway 的心跳状态是否正常
```

**AI 会显示：**

![](assets/17-%E5%AE%9A%E6%97%B6%E4%BB%BB%E5%8A%A1%E4%B8%8E%E8%87%AA%E5%8A%A8%E5%8C%96%EF%BC%9A%E8%AE%A9%20AI%20%E5%9C%A8%E4%BD%A0%E7%9D%A1%E8%A7%89%E7%9A%84%E6%97%B6%E5%80%99%E4%B9%9F%E8%83%BD%E5%B7%A5%E4%BD%9C_X24kblhMZo.jpg)

**如果心跳异常，AI 可能会提示：**

```
⚠️ Gateway 心跳异常

可能原因：
1. Gateway 已停止运行
2. 系统资源不足
3. 配置文件错误

建议操作：重启 Gateway
```

### 2.2 文件存储：任务存在哪里？

OpenClaw 把定时任务信息保存在两个地方：

| 文件/目录 | 存放内容 | 类比 |
|---|---|---|
| `~/.openclaw/cron/jobs.json` | 所有任务的配置（时间、内容、模式） | 闹钟的"设置界面" |
| `~/.openclaw/cron/runs/` | 每次任务的执行记录和日志 | 闹钟的"历史记录" |

![](assets/17-%E5%AE%9A%E6%97%B6%E4%BB%BB%E5%8A%A1%E4%B8%8E%E8%87%AA%E5%8A%A8%E5%8C%96%EF%BC%9A%E8%AE%A9%20AI%20%E5%9C%A8%E4%BD%A0%E7%9D%A1%E8%A7%89%E7%9A%84%E6%97%B6%E5%80%99%E4%B9%9F%E8%83%BD%E5%B7%A5%E4%BD%9C_UYUwbz79Ro.jpg)

**为什么需要知道？**
 如果任务没执行，你可以直接查看这些文件，排查问题。

## 四、两种定时任务类型（用自然语言告诉 AI 就行）

OpenClaw 的定时任务分两种，你可以直接跟 AI 说，不需要记命令。

---

### 3.1 一次性任务（像手机闹钟，只响一次）

**场景 **：30分钟后提醒我喝水、1小时后提醒我开会

**你跟 AI 这样说 **：

```
请帮我创建一个定时任务：30分钟后提醒我喝水，内容是"该喝水了！起来活动一下吧"
```

**AI 会回复你 **：

```
✅ 一次性任务创建成功！

任务详情：
- 名称：喝水提醒
- 类型：一次性任务
- 执行时间：30分钟后（15:30）
- 提醒内容：该喝水了！起来活动一下吧
- 任务ID：job-xyz789

⏰ 30分钟后我会准时提醒你！
```

**常用时间说法（直接跟 AI 说） **：

| 你跟 AI 说 | AI 理解的意思 |
|---|---|
| "5分钟后" | 5分钟后执行 |
| "30分钟后" | 30分钟后执行 |
| "1小时后" | 1小时后执行 |
| "明天早上8点" | 明天8:00执行 |
| "今天下午3点" | 今天15:00执行 |

---

### 3.2 周期性任务（像每天早上的闹钟，重复执行）

**场景 **：每天早上8点推送新闻、每周一生成周报

**你跟 AI 这样说 **：

```
请帮我创建一个每天早上8点的周期性任务：
任务名称叫"早安简报"，
内容是"搜索今天的AI行业新闻，整理成简报发给我"
```

**AI 会回复你 **：

```
✅ 周期性任务创建成功！

任务详情：
- 名称：早安简报
- 类型：周期性任务（每天重复）
- 执行时间：每天早上 8:00
- 执行内容：搜索AI行业新闻并整理简报
- Cron表达式：0 8 * * *
- 任务ID：job-morning123
- 状态：active（已激活）

📅 从明天开始，每天早上8点我会准时给你发送简报！
```

---

### 3.3 时间表达式的秘密

你可能好奇，AI 是怎么理解"每天早上8点"的？

其实 AI 内部把自然语言转换成了 **Cron 表达式 **——用5个数字表示时间规则。

| 自然语言 | AI 转换的 Cron 表达式 |
|---|---|
| 每天早上8点 | `0 8 * * *` |
| 每天晚上10点 | `0 22 * * *` |
| 每周一早上9点 | `0 9 * * 1` |
| 每小时整点 | `0 * * * *` |
| 每30分钟 | `*/30 * * * *` |

**口诀（了解一下就行） **：

```
分 时 日 月 周
0  8  *  *  *
│  │  │  │  │
│  │  │  │  └─ 周几 (0=周日, 1=周一...)
│  │  │  └──── 月份
│  │  └────── 几号
│  └──────── 小时
└────────── 分钟
```

> 💡 **重要 **：你不需要自己写这个！直接跟 AI 说"每天早上8点"就行，AI 会自动帮你转换。

## 六、进阶：隔离模式（不影响聊天的后台任务）

### 1、什么时候用隔离模式？

**主会话模式的问题 **：

- AI 执行过程会显示在你的聊天窗口，打断正常对话

- 长任务执行时，你看不到进度，很着急

**隔离模式的好处 **：

- AI 在"后台"执行，不打扰你的正常聊天

- 完成后只把结果发给你

- 适合长时间运行的任务

## 十二、为什么 OpenClaw 的定时任务很强大？

对比一下你就明白了：

| 功能 | 其他 AI 工具 | OpenClaw 定时任务 |
|---|---|---|
| **设置方式** | 需要写代码/配置复杂系统 | **说人话就行，AI 帮你配置** |
| **设置难度** | 需要记命令参数 | **自然语言描述需求即可** |
| **运行环境** | 需要自己搭建服务器 | **Gateway 自带，开箱即用** |
| **任务类型** | 只有周期性任务 | **一次性 + 周期性，更灵活** |
| **执行模式** | 只有一种模式 | **主会话 + 隔离，场景全覆盖** |
| **投递方式** | 只能发邮件/短信 | **直接投递到聊天窗口，即时可见** |
| **上下文** | 无 | **主会话模式保留完整对话历史** |

**核心优势总结 **：

1. **零代码+零记忆 **：不需要会编程，不需要记命令，说话就能创建定时任务

1. **透明可追溯 **：任务配置存储在 `~/.openclaw/cron/jobs.json` ，执行日志在 `runs/` 目录，随时可查

1. **超灵活 **：一次性/周期性、主会话/隔离模式，各种场景都能满足

1. **即时投递 **：结果直接发到你常用的聊天工具（Telegram/WhatsApp等）

1. **智能上下文 **：主会话模式能记住你们的对话历史，执行更精准

1. **安全可靠 **：Gateway 稳定运行，任务不会遗漏
