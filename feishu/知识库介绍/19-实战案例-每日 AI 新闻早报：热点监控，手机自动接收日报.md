## 🔗 第二部分：配置阿亮使用 skill（软链接方式）

**⚠️ 小白注意 **：这部分涉及"软链接"概念，不理解没关系，跟着做就行！

**💻 Mac/Windows 差异说明 **：

- **Mac **：使用 `ln -s` 创建软链接

- **Windows **：有两种方法
  - 方法1（推荐）：直接 **复制文件夹 **（最简单，小白首选）
  - 方法2：使用 `mklink` 创建软链接（需要管理员权限）

### 2.1 什么是软链接？为什么需要？

**简单理解 **：软链接就像桌面上的"快捷方式"，指向真实的文件位置。

**为什么需要 **：根据官方文档， `<workspace>/skills` 优先级最高。我们在阿亮工作区创建软链接（或复制），让阿亮 **优先使用 **这个 skill。

### 2.2 创建 skills 目录

**Mac 用户 **：

```
mkdir -p ~/.openclaw/agents/researcher/workspace/skills
```

**Windows 用户 **：

```
New-Item -ItemType Directory -Force -Path ~/.openclaw/agents/researcher/workspace/skills
```

### 2.3 将 skill 软链接到阿亮工作区

#### 创建软链接（Mac/Linux 推荐，Windows 需要管理员权限）

**Mac 用户 **（推荐）：

```
ln -s ~/.openclaw/skills/news-aggregator-skill \
  ~/.openclaw/agents/researcher/workspace/skills/news-aggregator-skill
```

**Windows 用户 **（需要管理员权限）：

```
# 以管理员身份运行 PowerShell，然后执行：
cmd /c mklink /D `
  %USERPROFILE%\.openclaw\agents\researcher\workspace\skills\news-aggregator-skill `
  %USERPROFILE%\.openclaw\skills\news-aggregator-skill
```

### 2.4 验证是否成功

**Mac 用户 **：

```
ls -la ~/.openclaw/agents/researcher/workspace/skills/
```

## ⚙️ 第三部分：配置阿亮的工具权限

### 3.1 编辑全局配置文件

步骤1：打开配置文件： `openclaw.json`
 步骤2：在文件中找到 `researcher` 的配置，添加 `tools` 部分：

```
{
  agents: {
    list: [
      {
        id: "researcher",
        name: "阿亮",
        workspace: "~/.openclaw/agents/researcher/workspace",
        // 添加下面这段（注意逗号）
        tools: {
          allow: [
            "exec",
            "read", 
            "write",
            "message"
          ]
        }
      }
    ]
  }
}
```

![](assets/19-%E5%AE%9E%E6%88%98%E6%A1%88%E4%BE%8B-%E6%AF%8F%E6%97%A5%20AI%20%E6%96%B0%E9%97%BB%E6%97%A9%E6%8A%A5%EF%BC%9A%E7%83%AD%E7%82%B9%E7%9B%91%E6%8E%A7%EF%BC%8C%E6%89%8B%E6%9C%BA%E8%87%AA%E5%8A%A8%E6%8E%A5%E6%94%B6%E6%97%A5%E6%8A%A5_FtZ2b1N1xo.jpg)

**⚠️ 注意格式 **（容易出错的地方）：

- 每个配置项之间要有逗号 `,`

- `tools` 前面的 `{` 和后面的 `}` 要配对

为了方便调试，可以Ctrl+C终止，然后再启动：

## 📝 第四部分：配置阿亮的 SOUL.md

**什么是 SOUL.md **：这是阿亮的"行为准则"，告诉它应该怎么做。

打开 SOUL.md 文件， 添加新闻采集工作流

添加以下内容：

```
---

## 每日新闻采集工作流

每天早上7点采集全网AI新闻并生成日报。

### 执行步骤

1. **使用 news-aggregator-skill 采集**
   - 进入 skill 目录执行脚本
   - 使用提示词获取指定内容

2. **采集范围**
   - Hacker News、Product Hunt
   - 36氪、腾讯新闻
   - GitHub Trending
   - Agent & LLM 最新进展

3. **生成日报**
   - 读取 reports/日期/ 目录下的报告
   - 使用 emoji 美化
   - 分板块展示

4. **发送用户**
   - 使用 message 工具发送
   - 确保格式美观

### 使用提示词

执行时发送以下提示词给 skill：

帮我看看 Hacker News 和 Product Hunt 最近有什么 AI 新闻？
36氪和腾讯新闻今天有什么科技大瓜？
GitHub 上最近火的项目是啥？
全网扫描一下关于 Agent 和 LLM 的最新进展。

### 日报格式

📰 AI日报 - 日期
━━━━━━━━━━━━━━━━━━━━━━

🚀 Hacker News 精选
🎯 Product Hunt 新品
🇨🇳 国内科技动态
🐙 GitHub 热门
🤖 Agent & LLM 前沿
```

## 🚀 第六部分：创建定时任务（一条命令）

### 定时任务明确指定 Telegram ID

**替换 ****`"7601425554"`** **为你的实际 ID **：

```
openclaw cron add \
  --name "news-aggregator-daily" \
  --cron "0 7 * * *" \
  --tz "Asia/Shanghai" \
  --session isolated \
  --agent researcher \
  --message "执行每日新闻采集任务。使用 news-aggregator-skill 采集全网AI新闻并生成日报发送给用户。" \
  --timeout-seconds 1800 \
  --announce \
  --channel telegram \
  --to "7601425554"
```

- 每行末尾的 `\` 表示"这行还没结束，下一行继续"

- 最后一行不要有 `\`
