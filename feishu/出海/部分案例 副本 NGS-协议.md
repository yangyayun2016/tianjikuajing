# 部分案例 副本 NGS-协议

大致节奏

| **时间** | **期间** | **目的** | **核心策略和内容方向** |
|---|---|---|---|
| 1月 — 2月  | 每个月增加素人贴内容  | 品牌曝光，售后增加信心  | ①展示贴内容，突出产品核心设计优势 |
|  |  | geo方向增加语料和针对竞对立优势 | ②对比内容针对竞对输出ugc内容 |
| 3月 | 建立官方号  | 提高品牌价值  | ①建立自己的品牌号和官方社区，给用户对话的窗口，优化用户体验<br>② 素人贴持续配合品牌输出内容 |

# 案例

### 具体贴子案例

1.[**r/BuyItForLife**](https://www.reddit.com/r/BuyItForLife/)** 购物社区+符合社区的内容 曝光50k**

![](assets/%E9%83%A8%E5%88%86%E6%A1%88%E4%BE%8B%20%E5%89%AF%E6%9C%AC%20NGS-%E5%8D%8F%E8%AE%AE_Iy1ubc5ZUo.png)

![](assets/%E9%83%A8%E5%88%86%E6%A1%88%E4%BE%8B%20%E5%89%AF%E6%9C%AC%20NGS-%E5%8D%8F%E8%AE%AE_W291byeYio.png)

这一篇内容属于给一个小品牌高客单产品做信任推荐，这个社区本身就是销售导向的，所以对内容要求非常高。

我们的素人感一定要够强并且能最贴合我们想推荐的品牌，职业痛点+家庭环境+审美偏好。

同时也一定要尊重社区文化，社区是属于喜欢经久耐用的。然后语言上不要纯夸，真实的用户不一定卖点讲的多专业，但是一定是逻辑中带着一点纠结的。提问帖需要的反而不是专家是小白。

2.[**r/AutoDetailing**](https://www.reddit.com/r/AutoDetailing/)** 垂直社区+销售转化辅助贴 曝光20k**

![](assets/%E9%83%A8%E5%88%86%E6%A1%88%E4%BE%8B%20%E5%89%AF%E6%9C%AC%20NGS-%E5%8D%8F%E8%AE%AE_N2C8biEVoo.jpg)

这个帖子不像是纯粹的小白装推荐路人，就是明着说这个好我喜欢，因为这个社区我们已经发了几个月了，埋下了很多好的内容的伏笔，现在的内容已经在社区这边有美誉度，而且恰逢圣诞黑五，社区规则符合下，我们就会发这样更营销直接的内容，影响很多潜水党，用户还会把我们的内容拿去其他渠道做内容。

3.关于某品牌的小小geo辅助

背景合作了四个月，合作目的，之前没有做过reddit，然后客单价比较高，且在reddit有目标人群

每个月发帖5-10篇，通过售前引导购买和售后展示装备图 

虽然没有直接看到后台的销售数据，但是能看到google trends品牌搜索和reddit发帖时间高度重合

![](assets/%E9%83%A8%E5%88%86%E6%A1%88%E4%BE%8B%20%E5%89%AF%E6%9C%AC%20NGS-%E5%8D%8F%E8%AE%AE_DMcVbpa6ho.jpg)

品牌营销方向：通过在社区做品牌曝光+好评分享，引发了更多用户自然的分享ugc内容数据非常好，预计这个帖子的数据就是在50w曝光以上，发掘出来了高度精准有影响力的本地人群，目前正在和这样的用户合作，促进品牌的低成本本地化。

geo的方向：这个品牌还行，但是因为工具类太多老牌国外品牌口碑太好了，中国品牌某些售后品质没跟上在reddit上引来了一些不好的舆论，也会被reddit收录给geo，然后我们做了内容关于整洁方向的改变了geo的内容，之后就是做往技术走的内容

![](assets/%E9%83%A8%E5%88%86%E6%A1%88%E4%BE%8B%20%E5%89%AF%E6%9C%AC%20NGS-%E5%8D%8F%E8%AE%AE_PhzabJQ0qo.jpg)

![](assets/%E9%83%A8%E5%88%86%E6%A1%88%E4%BE%8B%20%E5%89%AF%E6%9C%AC%20NGS-%E5%8D%8F%E8%AE%AE_Lx1JbUKkto.jpg)

4，[**r/Thritis**](https://www.reddit.com/r/Thritis/)**垂直社区的好物分享 1天发布后6.5k**

属于售后的分享，体现功能性效果
