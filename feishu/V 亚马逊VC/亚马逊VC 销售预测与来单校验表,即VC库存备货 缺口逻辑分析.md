# 亚马逊VC 销售预测与来单校验表,即VC库存备货 缺口逻辑分析

VC库存备货 缺口逻辑分析 销售预测与来单校验表

### 文档内容总结

---

#### **数据表结构及核心逻辑**

1. **数据列说明**
  - **A列**：站点国家代码（如德国为`DE`），无公式。
  - **B列**：ASIN（亚马逊商品唯一编码），无公式。
  - **C列**：截至2月24日的海外仓/云仓可用库存量（无公式）。
  - **D列**：截至2月24日的海外仓/云仓在途库存（无公式）。
  - **E列**：海外仓/云仓预计周转天数，公式为 `=(D列 + C列) / I列`，通过总库存计算覆盖周期。
  - **F列**：建议下批发运数量，公式为 `=(K列 - D列 - C列) + 6*I列`，需补足VC缺口并覆盖6周周转需求。
  - **G列**：截至2月24日的VC仓库在途库存量（无公式）。
  - **H列**：截至2月24日的VC仓库可用库存量（无公式）。
  - **I列**：未来8周FC（Fulfilment Center，亚马逊仓库）均销量，公式为 `=L列 / 8`。
  - **J列**：FC预计周转天数，公式为 `=(G列 + H列) / I列`，反映VC库存覆盖未来需求的周数。
  - **K列**：VC库存缺口，公式为 `=(8 - J列) * I列`，需补足至未来8周的预期销量。
  - **L列**：未来8周FC销量预测（基于W9数据），无公式。
  - **M列**：数据验证（W9来单确认），无公式。

---

#### **关键逻辑解析**

1. **库存调节核心目标**
  - 确保VC仓库库存缺口（K列）被覆盖，并同步维持海外仓未来6周的周转需求（`6*I列`）。
  - 若VC库存缺口较小或周转能力足够（即`J列 ≥8`），则无需补货。

1. **示例说明（以数据表为例）**
  - **ASIN ****`B0BTKX5BWN`****（DE站点）**： 
    - 海外仓可用库存190，VC库存缺口50。
    - 建议发运量为 `(50-0-190) +6*20 = -140+120 = -22`，负值表明当前海外仓库存过剩需消化。
  - **ASIN ****`B0C7BWNSX8`****（DE站点）**： 
    - 海外仓可用库存32，VC库存缺口104。
    - 建议发运量为 `(104-96-32)+6*24= (-24)+144=16`，需通过发运补足VC缺口。

1. **异常与注意事项**
  - **重复行问题**：ASIN `B0C6G792H8` 出现两次，可能为数据错误。
  - **负发运数量**（如`-22`、`-54`）：表明海外仓库存超量，需优先消耗现有库存再补货。
  - **空值处理**：部分行“数据验证-W9来单”为空（如ASIN `B09DSV9KQM`），需人工确认数据准确性。

---

#### **核心公式总结**

1. **发运策略公式**

```
下一批发运量 = (VC缺口 - 海外仓在途库存 - 海外仓可用库存) + 海外仓未来6周销量需求
```

1. **目的**：平衡VC仓库库存缺口与海外仓周转保底量。

1. **动态调整依据**
  - **VC库存缺口**：基于未来8周销量预测（L列）与当前VC库存（在途+可用）计算需补货量。
  - **周转能力**：通过`6*未来8周均销（I列）`动态规划海外仓需提前存储的周转量。

### **一、误差影响的关键环节**

1. **核心传导路径**
  - **预测偏差直接导致**：I列（8周均销）的计算错误 → 周转天数（E、J列）、VC缺口（K列）、建议发运量（F列）均受影响。
  - **示例**：若L列预测高估20%，I列均销将被高估 → 发运量公式（F列）中的`6*I列`会额外增加发运量，可能导致库存积压。

1. **可能风险场景**
  - **预测过高**：过量补货 → 库存周转率下降，仓储成本上升。
  - **预测过低**：补货不足 → 断货风险，影响销售机会。

### **二、策略调整方向**

1. **提升预测容错性**

- **加权滚动预测**
 将L列的“未来8周FC-W9”改为**滚动预测**，例如每周更新后6周数据（而非固定W9），增加近期的销售权重（如最近1周占30%）。
*操作示例*：

```
L列新公式 = (最近1周销量 * 3) + (后7周原预测 * 7) / 10  
```

- **安全系数修正**
 在L列基础上增加偏差容忍范围： 
  - 悲观场景：L列预测值 × 90%
  - 乐观场景：L列预测值 × 110%
 根据历史误差率设定系数，生成最小/最大建议发运量区间。

1. **动态库存缓冲机制**

- **安全库存层**
 在计算公式中叠加安全库存阈值，例如：

```
VC库存缺口（K列）公式调整为：  
K列 = MAX( (8 - J列)*I列 , 安全库存最小值 )
```

-  确保即使预测偏低，仍有基础库存兜底。

- **按偏差分阶补货**
 定义误差容忍区间（如±15%），不同区间执行不同策略： 
  - 偏差≤15%：按原发运量补货；
  - 偏差>15%：发运量 = 原建议值 × (实际销量/预测销量)。

1. **敏捷补货与监控**

- **分批发运**
 将单次发运改为分批次执行： 
  - 首批按70%建议量发运，后续根据实际销售再补30%。

- **实时销量追踪与修正**
 设置监控阈值（如连续3天销量超预测20%），触发预警并手动修正L列数据，触发公式重新计算。

**未来8周均销FC的计算方式及理解：**

1. **基本公式解析**
  - **数据来源**：基于L列“未来8周FC-W9”（总销量预测值）。
  - **计算公式**：
```
未来8周均销FC（I列） = L列（未来8周预测总销量） / 8  
```

  -  例如，若L列为160，则均销为20；若L列为200，则均销为25。

1. **设计逻辑与业务意义**
  - **平滑销售波动**：8周均销通过平均化短期波动，反映中期销售趋势，避免因单周销量突变（如促销、缺货）导致库存策略失真。
  - **补货周期对齐**：可能与供应链的补货周期（如海运时效约6-8周）挂钩，确保均销预测覆盖订单交付期的需求。
  - **目标应用场景**： 
    - **周转计算**（E列、J列）：判断库存是否足以支撑未来销售周期。
    - **补货建议**（F列、K列）：结合库存缺口和未来需求提前备货。

1. **对下游公式的影响**
  - **海外仓周转天数**（E列）：
```
（海外仓在途 + 可用库存）/ 均销 = 预计可支撑的周数  
```

  -  若均销高低直接影响库存周转能力评估。
  - **VC库存缺口**（K列）：
```
（8周需求 - VC库存可覆盖周数）* 均销  
```

  -  若均销高估，缺口计算偏大 → 建议发运量冗余；反之可能引发断货风险。
  - **建议发运数量**（F列）：
